# 深圳大学347心理学保命手册三科全范围复核报告V22

## 复核原则

- 以三科速背手册为正文采分点的首要来源，一本通用于核对、补充考纲直接收录而速背未单列的内容以及编制圆括号扩容。
- 考纲用于确定知识范围，深大真题用于判断命题风格和优先级；不因考纲未在某一科目标题下单列，就机械删除具有本科目独特方法或实验逻辑的内容。
- 未独立设题的源内容必须有明确去向：已在其他题目覆盖、作为扩容覆盖、跨科完整覆盖，或因无法形成合适主观题而有依据地不独立设题。
- 不编实验设计题；保留“结合经典实验阐述理论、比较理论或说明研究范式”等深大偏好的题型。

## 普通心理学

- 结论：十四章及补充学习理论章均已有主体题、同章合并题或扩容去向，没有发现整章截断。
- 生理性动机在速背手册中只有定义性内容，已放入动机分类扩容，不强行凑成容量不足的简答题。
- 权力动机、交往动机和兴趣属于社会性动机的补充类型，现有高优先题聚焦考纲和真题信号更强的成就动机、归因与学习动机，不另设低容量题。
- 智力测量的具体工具已由测量分册系统覆盖，普心保留智力含义和理论，不重复堆砌相同答案。
- 处理结果：保留V21逐题精修正文，另生成V22全范围复核版。

## 实验心理学

- 发现问题：旧版只保留绪论、实验研究基本问题、反应时和心理物理学，生成计划把教材第三章及第六至第十章整体排除，属于范围筛选过严。
- 已恢复第三章“如何读和写心理学实验报告”，依据一本通和现行考纲编入核对清单阅读法及APA实验报告结构。
- 已补入第六章“注意”：选择性注意理论、资源限制理论、特征整合理论和注意研究范式。
- 已补入第七章“知觉”：直接与间接知觉、无觉察知觉及斯特鲁普启动实验。
- 已补入第八章“记忆与学习”：传统研究方法、内隐记忆理论与方法、内隐学习。
- 已补入第九章“思维”：思维研究方法、概念形成实验；决策理论因普心已有完整主体答案，不在实验分册重复。
- 已补入第十章“情绪”：情绪产生与获得的经典实验、情绪与认知研究、情绪测量。
- 反应时研究历史保留为不独立设题：内容偏历史叙述，难以形成稳定主观题；反应时方法和新进展均已完整覆盖。
- 处理结果：实验分册由25题增至39题，新增内容均可追溯到实验速背手册或一本通。

## 心理与教育测量

- 全量复核发现：旧版虽覆盖速背手册各核心章，但一本通中的“心理与教育测量简史”“能力测验（下）”和“测量应用实务”被整章排除；本轮不再仅以真题信号较弱为由整章删除。
- 已恢复第二章“心理与教育测量简史”，编入高尔顿、卡特尔、比内、推孟和桑代克等代表人物及贡献。
- 已恢复第十二章“能力测验（下）”，编入能力倾向测验的特点和吉尔福特发散思维测验。
- 已恢复第十五章“测量应用实务”，编入心理测量在人事测评、心理诊断和教育评价中的应用。
- 猜测问题已并入多重选择题项目分析，分数分界点已并入目标参照测验质量评价，不再重复设题。
- 陆军测验属于团体智力测验的历史性工具，现有能力测验重点保留比内、韦克斯勒和瑞文，不另设低可考性题。
- 职业兴趣、品德和教育测量应用不再无声删除，已在“测量应用实务”题中按应用领域归类保留。
- 处理结果：测量分册由45题增至48题，新增内容均可追溯到测量一本通。
