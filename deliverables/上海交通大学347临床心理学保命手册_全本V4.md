# 第一章 绪论

## 一、临床心理学的含义、性质与工作范围【★★】

### 押题1【简答】简述临床心理学的含义、学科性质与主要工作范围。

临床心理学是运用心理学知识来**理解、促进和改善个体或群体的身心健康和社会适应**的一门学科。（其核心工作强调**临床心理评估、心理咨询和治疗、心理病理问题的防治**。）【名词解释：临床心理学】

临床心理学的学科性质与工作范围主要包括：

1. **学科性质**：临床心理学是**心理学与医学的交叉学科**，以心理学知识和研究成果增进人的健康。

2. **思考方式**：临床心理学家通过对人类行为进行**描述、解释、预测和改变**来理解和处理临床问题。

3. **工作范围**：主要包括**研究、评估、治疗、教学、咨询和管理**等。

4. **相关学科**：与咨询心理学、学校心理学和精神病学联系密切。（咨询心理学侧重心理咨询过程、原则、技巧和方法；学校心理学关注学生在教育环境中的成长与适应；精神病学侧重精神障碍的医学诊断和治疗。）

综上，临床心理学兼具心理学与医学属性，并通过研究、评估和干预等工作促进个体或群体的身心健康和社会适应。

## 二、临床心理学研究设计【★★】

### 押题1【论述】论述临床心理学常用研究设计及其选择原则。

临床心理学研究设计是围绕临床问题制定的资料收集、变量控制和结果解释方案，其目的在于描述心理问题、检验影响因素并评价干预效果。

临床心理学常用研究设计如下：

1. **个案研究**：对单个来访者进行全面、深入和连续的观察与分析。（优点是资料丰富、适合少见病例和形成假设；局限是研究者主观影响较大，结论不易推广。）【名词解释：个案研究】

2. **相关研究**：考察两个或多个变量共同变化的方向和程度。（它适合研究不能人为操纵的临床变量，但相关不能直接证明因果，还可能存在方向性和第三变量问题。）

3. **横断研究**：在同一时间比较不同年龄、病程或特征群体，效率较高，但容易混入群体背景差异。

4. **纵向研究**：在较长时期内重复追踪同一批被试，能够描述变化轨迹和时间先后，但耗时较长并可能发生被试流失。

5. **组间实验设计**：比较接受不同处理的群体，随机分配能够减少组间原有差异。（随机临床试验是评价干预疗效的重要设计。）

6. **单个案实验设计**：将被试置于系统安排的基线和处理条件中，反复测量心理功能变化。（常用A-B-A-B设计和多基线设计，适合个体化干预效果评价。）

7. **流行病学研究**：调查心理问题在人群中的发生、分布及相关因素，可采用现况调查、病例对照和队列研究。（该类研究有助于识别危险因素并制定预防策略。）

研究设计的选择应遵循以下原则：

1. **问题匹配**：描述现状、预测关系、解释机制和验证疗效需要采用不同设计。

2. **控制与真实性平衡**：实验控制有助于因果推断，真实临床情境有助于结果推广，应依据研究目的权衡内部效度和外部效度。

3. **伦理与可行性**：不能为了研究需要使被试暴露于不必要风险，必须保证知情同意、退出自由和隐私保护。

综上，临床心理研究没有单一的最佳设计，应根据研究问题、证据强度、伦理和现实条件选择，并通过多方法证据提高结论可信度。

# 第二章 临床心理学的理论模式

## 一、心理动力学模式【★★★】

### 押题1【论述】论述心理动力学模式的核心观点，并评价其临床意义。

心理动力学模式认为，人的心理和行为受到**潜意识过程、早期经验与内在冲突**的持续影响，症状是人格结构和心理冲突的外在表现。（经典精神分析由弗洛伊德创立，后来发展出自我心理学、客体关系理论等取向。）【名词解释：心理动力学模式】

心理动力学模式的核心观点如下：

1. **潜意识决定作用**：大量欲望、情感和冲突处于意识之外，却能够通过梦、口误、症状和人际模式影响行为。

2. **人格结构冲突**：本我遵循快乐原则，自我遵循现实原则，超我遵循道德原则；三者冲突会引起焦虑。（健康人格依赖自我对本能、现实和道德要求的协调。）

3. **早期经验作用**：童年依恋、亲子互动和心理性欲发展经历会塑造人格及以后的人际关系。（未解决的早期冲突可能在成人关系中重复出现。）

4. **防御机制**：自我通过压抑、否认、投射、反向形成和升华等防御减轻焦虑。（防御具有保护作用，但僵化、过度使用会妨碍现实适应。）

5. **症状意义**：症状不是孤立表现，而可能是潜意识冲突的妥协性解决，既表达被压抑的欲望，也帮助个体回避焦虑。

6. **治疗关系**：来访者会把过去重要关系中的情感和期待转移到治疗者身上，治疗者通过治疗同盟、移情分析和阻抗处理促进领悟。

心理动力学模式的评价如下：

1. **主要贡献**：揭示无意识、早期经验、人格动力和治疗关系的重要性，为理解复杂、长期心理问题提供深层框架。

2. **主要局限**：部分概念难以操作和实证检验，经典治疗周期较长，对治疗者和来访者要求较高。（现代心理动力治疗已更重视关系、现实适应和实证评价。）

综上，心理动力学模式重在理解症状背后的潜意识冲突和重复性关系模式，其价值在于深化个案理解，而应用时需结合实证证据和来访者条件。

## 二、行为和认知模式【★★★】

### 押题1【论述】论述行为与认知模式解释心理问题的主要观点及干预启示。

行为和认知模式认为，异常行为可以通过学习形成并维持，个体对事件的不合理解释和信息加工偏差也会引起持续的情绪与行为问题。

行为模式的主要观点如下：

1. **经典性条件反射**：原本中性的刺激与引起强烈反应的刺激反复配对后，也能引起条件反应。（恐惧可能由条件作用获得，消退、反条件作用和暴露可用于削弱恐惧。）

2. **操作性条件反射**：行为后果会改变该行为以后出现的概率，强化增加行为，惩罚减少行为。（回避行为因暂时减轻焦虑而受到负强化，可能长期维持焦虑障碍。）

3. **社会学习理论**：个体通过观察榜样及其行为后果形成新行为，学习过程受到注意、保持、动作再现和动机影响。（治疗可使用示范、角色扮演和行为练习。）

4. **功能分析**：行为治疗重视前因—行为—后果关系，分析症状在具体环境中如何被诱发和维持。（同一种症状可能具有不同功能，干预必须依据个案功能制定。）

认知模式的主要观点如下：

1. **认知中介**：事件本身并不直接决定情绪和行为，个体对事件的解释和评价具有中介作用。

2. **不合理信念**：埃利斯认为绝对化要求、过分概括和糟糕至极等不合理信念会引起情绪困扰。（ABCDE模式通过辩论不合理信念建立有效的新观念。）

3. **自动思维和图式**：贝克认为负性图式会产生消极自动思维和系统性认知歪曲，进而维持抑郁、焦虑等问题。

4. **认知行为改变**：治疗通过识别自动思维、检验信念、行为实验和技能训练，帮助来访者形成更现实、适应的认知行为方式。

行为与认知模式的关系如下：

1. **共同点**：都关注当前问题、可观察变化和结构化干预，并强调对治疗效果进行测量。

2. **主要区别**：行为模式侧重学习历史、环境条件和行为功能，认知模式侧重信念、自动思维和信息加工；认知行为治疗则把二者整合。

综上，行为和认知模式分别从学习机制与认知中介解释心理问题，并共同形成目标明确、可操作和可检验的干预体系。

## 三、人本主义模式【★★】

### 押题1【简答】简述人本主义模式的核心观点及治疗关系要求。

人本主义模式强调人的**主体性、自由选择、成长潜能和自我实现倾向**，认为心理问题常与真实经验被否定、自我概念不协调有关。

1. **人的成长潜能**：人具有维持、发展和实现自身潜能的基本倾向，不能只把人看作本能冲突或环境塑造的被动产物。

2. **现象学立场**：理解来访者应从其主观经验世界出发，关注“这个人如何体验自己和环境”。

3. **自我概念与经验一致性**：真实经验与自我概念越一致，个体越能开放地生活；重要他人的有条件接纳会使个体否认不符合评价条件的经验。

4. **真诚一致**：治疗者应在专业边界内真实、透明，其外在表达与内在体验保持一致。

5. **无条件积极关注**是治疗者不以满足某种条件为前提地尊重和接纳来访者，使其能够安全探索被否定经验的治疗态度。（有条件接纳可能使个体否认真实经验并扩大自我不协调。）【名词解释：无条件积极关注】

6. **共情理解**：治疗者准确进入来访者的主观世界，并把理解传达给来访者，同时保持“仿佛”的界限。（共情不是赞同所有行为，而是理解其经验和意义。）【名词解释：共情】

综上，人本主义模式通过真诚、无条件积极关注和共情建立促进性关系，使来访者恢复对经验的开放并发挥成长潜能。

## 四、生物—心理—社会模式【★★★】

### 押题1【论述】论述生物—心理—社会模式，并结合实例说明其临床应用。

生物—心理—社会模式认为，健康与疾病是**生物因素、心理因素和社会因素相互作用**的结果，临床评估与干预不能只依赖单一层面的解释。（该模式为综合评估、个体化干预和跨专业合作提供了统一框架。）【名词解释：生物—心理—社会模式】

该模式包含以下三个基本层面：

1. **生物因素**：包括遗传、神经递质、脑功能、内分泌、躯体疾病、睡眠和药物等。（生物易感性会影响心理问题发生风险，但通常不是唯一原因。）

2. **心理因素**：包括认知评价、情绪调节、人格特点、应对方式、学习经历和行为习惯等。

3. **社会因素**：包括家庭关系、社会支持、文化规范、经济压力、工作学习环境和重大生活事件等。

三个层面的关系如下：

1. **相互影响**：生物状态会改变情绪和认知，心理压力会通过神经内分泌影响身体，社会处境又会改变压力暴露和应对资源。

2. **易感—压力作用**：个体的生物和心理易感性在社会压力作用下可能表现为症状，保护因素则能缓冲风险。（相同压力对不同个体产生不同结果，体现易感性与资源差异。）

3. **多层次维持**：症状形成后可能受到睡眠紊乱、灾难化认知、回避行为和家庭过度保护等因素共同维持。

该模式的临床应用如下：

1. **综合评估**：以抑郁为例，应同时了解躯体疾病和药物、负性认知与情绪调节、生活事件与社会支持。

2. **整合干预**：依据需要结合药物或躯体治疗、心理治疗、行为激活、家庭和社会支持。（具体方案应根据主要维持因素和来访者偏好确定。）

3. **连续预防**：既处理当前症状，也改善睡眠、应对方式和社会环境，减少复发风险。

综上，生物—心理—社会模式用多层次相互作用代替单一病因解释，为全面评估、个体化干预和跨专业合作提供框架。

# 第三章 心理评估概述

## 一、心理评估的含义、目的与方法【★★★】

### 押题1【简答】简述心理评估的含义、目的及常用方法。

心理评估是运用多种方法系统收集、分析和解释个体心理与行为资料，以描述问题、作出临床判断并指导干预的过程。（心理评估强调多方法、多来源和动态验证，不能等同于单次心理测验。）【名词解释：心理评估】

心理评估的主要目的包括：

1. **问题描述**：明确症状表现、严重程度、持续时间、诱发情境和对功能的影响。

2. **分类与诊断**：将收集到的资料与诊断标准或常模比较，形成诊断和鉴别诊断假设。（诊断应服务于理解和干预，避免简单贴标签。）

3. **个案概念化**：分析问题的易感、诱发、维持和保护因素，形成对个案的整体解释。

4. **干预决策**：确定治疗目标、方法和优先顺序，评估风险与资源。

5. **疗效监测**：在治疗前、中、后重复测量，判断症状和社会功能变化并及时调整方案。

心理评估的常用方法包括：

1. **临床访谈**：通过结构化、半结构化或非结构化交谈获取主诉、病史和心理社会资料。

2. **行为观察**：在自然或设置情境中记录行为的频率、强度、持续时间和前因后果。

3. **心理测验**：用标准化工具测量智力、人格、症状和神经心理功能。（测验结果必须结合常模、信效度和被试状态解释。）

4. **临床评定量表与档案资料**：由本人或知情者评定症状，并结合病历、学校和家庭资料进行交叉验证。

综上，心理评估通过多种方法回答“问题是什么、为何发生、如何干预以及是否改善”，是临床决策的基础。

## 二、标准化测验与行为样本【★★★】

### 押题1【论述】论述心理测验标准化的主要内容，并说明如何保证测验结果可解释。

心理测验是依据心理学原理和程序，对人的认知、行为和情感等心理特征进行数量化测量的工具。（测验测到的是个体在特定条件下的一组**行为样本**，而非全部心理特征。）【名词解释：心理测验】

行为样本是从个体全部可能行为中抽取、能够代表所测心理特质的一组行为表现。（行为样本的代表性决定测验分数能否推论到目标心理特征。）【名词解释：行为样本】

测验标准化是使测验的编制、施测、评分和解释按照统一程序进行，以保证不同受测者结果可以比较的过程。（其主要内容包括测验材料、实施程序、评分规则和常模解释的标准化。）【名词解释：测验标准化】

心理测验标准化的主要内容包括：

1. **内容标准化**：明确测验目的和构念，保证项目能够代表目标行为领域。（内容不足会造成代表性缺失，内容混入则会测到无关特征。）

2. **施测标准化**：统一指导语、时间、环境、材料呈现和主试行为，减少情境差异造成的误差。

3. **评分标准化**：建立客观、明确的评分规则和计分程序，必要时检验评分者一致性。

4. **常模标准化**：从目标总体抽取有代表性的常模样本，建立原始分数转换和比较标准。（常模必须说明适用人群、建立时间和抽样方式。）

5. **信度**：评价测量结果的一致性和稳定性，信度越高，随机测量误差通常越小。

6. **效度**：评价测验分数是否支持预定解释和用途，包括内容、效标关联和构念等证据。（高信度是高效度的必要而非充分条件。）

保证测验结果可解释还应注意：

1. **结合测验情境**：检查被试动机、理解、疲劳、作答态度和施测异常。

2. **使用适当常模**：不能把不适用于该年龄、文化或临床群体的常模用于比较。

3. **多源整合**：测验分数应与访谈、观察和其他资料相互验证，不能凭单一分数作重大判断。

综上，标准化使测验结果具有可比性，行为样本代表性、信效度、常模适切性和多源资料共同决定分数解释质量。

## 三、心理评估过程与初次接待【★★★】

### 押题1【论述】结合初次接待，论述心理评估的基本过程及应收集的信息。

心理评估是一个从明确问题、系统收集资料到形成个案概念化和反馈建议的连续过程，初次接待的核心是建立关系、澄清主诉并完成安全评估。

心理评估的基本过程如下：

1. **明确转介问题**：了解来访者为何此时求助、由谁转介以及希望解决什么问题。（把笼统的“很难受”转化为可以评估的症状、情境和功能目标。）

2. **建立专业关系**：说明评估目的、流程、保密原则及其例外，取得知情同意，采用尊重、接纳和中立态度。

3. **收集资料**：围绕当前问题、个人发展、家庭关系、教育职业、身体健康和社会支持等方面获取信息。

4. **选择评估方法**：依据假设选择访谈、观察、测验和临床量表，不做与问题无关的过度测验。

5. **整合和验证**：比较不同来源资料是否一致，提出多个可能解释，并继续收集证据进行鉴别。

6. **形成个案概念化**：说明问题的表现、易感因素、诱发因素、维持因素和保护因素，评估资源和改变条件。

7. **反馈与计划**：用来访者能够理解的语言反馈主要发现，讨论目标、干预方案、转介和复评安排。

初次接待应重点收集以下信息：

1. **人口学与基本资料**：年龄、性别、教育、职业、婚姻家庭、联系方式和重要文化背景。

2. **主诉与现病史**：症状表现、起病时间、发展过程、频率强度、诱因、缓解因素和功能损害。

3. **既往史**：既往心理问题、精神科和躯体疾病、治疗及用药、住院和复发情况。

4. **个人成长史**：出生发育、家庭教养、依恋关系、重要创伤、学习工作和亲密关系经历。

5. **家族与社会资料**：家族精神疾病和自杀史、家庭互动、经济压力、社会支持及近期生活事件。

6. **精神状态检查**：观察外表行为、意识、定向、言语、情绪、思维、知觉、认知、洞察和判断。

7. **风险评估**：直接了解自伤、自杀、伤人、虐待、冲动和严重自我照料困难，并评估计划、手段、既往行为和保护因素。（高风险时应优先采取安全措施和必要转介。）

综上，初次接待既要充分收集问题与背景资料，也要建立合作关系和完成风险判断，为后续诊断、概念化和干预奠定基础。

# 第四章 智力评估

## 一、智力的含义与主要理论【★★★】

### 押题1【论述】论述智力的含义、主要理论及其对智力评估的启示。

智力是在实践中学习、实际解决问题和适应环境的能力。（它包括抽象思维、逻辑推理和记忆等核心成分；学习、解决问题和适应是其基本机能。）【名词解释：智力】

智力的主要理论如下：

1. **二因素论**：斯皮尔曼认为智力包括所有活动共同需要的一般因素G和完成特定任务所需的特殊因素S。（个体完成任何智力任务都同时受到G和相应S影响。）

2. **群因素论**：瑟斯顿提出言语理解、语词流畅、数字、空间、联想记忆、知觉速度和一般推理等基本心理能力。

3. **流体与晶体智力理论**：卡特尔把智力分为流体智力和晶体智力；前者依赖神经生理基础，后者主要由教育与经验形成。（流体智力成年后较早下降，晶体智力可随经验继续发展。）

4. **智力结构模型**：吉尔福特从操作、内容和产品三个维度构成智力结构，强调智力具有多种相对独立能力。

5. **智力层次结构理论**：把一般智力、较广泛的能力和特殊能力安排为不同层次，兼顾一般因素与多种能力。

6. **智力三元理论**：斯腾伯格认为智力包括**成分性智力、经验性智力和情境性智力**。（三者分别体现信息加工、应对新任务与自动化、适应和塑造环境的能力。）【名词解释：智力三元理论】

7. **多元智力理论**：加德纳认为人的智力由多种相对独立的能力构成，如语言、逻辑数学、空间、音乐、身体运动、人际和自知智力等。

主要评估启示如下：

1. **综合解释**：智力不是单一分数，既要看总水平，也要看各能力之间的结构差异。

2. **联系现实功能**：评估应结合学习、解决问题和环境适应，不能脱离教育文化背景解释。

3. **多方法评价**：标准化智力测验能够提供可比较分数，但还应结合访谈、行为观察和日常功能资料。

综上，智力理论从一般能力、多因素结构到现实适应不断扩展，智力评估也应由单一总分转向总水平、能力结构和实际功能的综合判断。

## 二、常用智力评估量表【★★】

### 押题1【简答】比较韦氏智力量表、比奈量表和瑞文推理测验的主要特点。

韦氏智力量表、比奈量表和瑞文推理测验都是常用智力评估工具，但在适用对象、测验结构和语言文化要求上有所不同。

1. **韦氏智力量表**：由韦克斯勒编制，包括成人、儿童和幼儿版本，采用分测验结构评估多方面认知能力。（其结果可同时提供总体水平和不同能力指数，有利于分析认知优势与弱点。）【名词解释：韦氏智力量表】

2. **比奈量表**：以比奈—西蒙量表为起点，早期按年龄量表编排题目并使用心理年龄概念。（斯坦福—比奈量表后来采用离差智商，使不同年龄个体的分数可以比较。）【名词解释：比奈量表】

3. **瑞文推理测验**：使用非文字图形矩阵考察类比和推理，语言要求较低，可用于不同文化和言语能力受限人群。（非文字并不意味着完全不受教育和文化经验影响。）【名词解释：瑞文推理测验】

三种量表的联系和区别如下：

1. **联系**：三者都采用标准化任务估计一般认知能力，结果均需结合常模、信效度和受测者状态解释。

2. **结构不同**：韦氏量表由多个分测验构成，重视能力结构；比奈量表具有年龄量表传统；瑞文主要使用单一形式的图形推理任务。

3. **适用条件不同**：韦氏适合较全面的临床认知评估，比奈适合发展和一般智力评价，瑞文适合快速团体筛查或降低语言要求。

综上，三种工具各有测量重点，选择时应依据评估目的、年龄、语言文化条件和个体特点，不能仅凭一个智商分数作结论。

# 第五章 神经心理测验

## 一、神经心理评估的含义、目的与方法【★】

### 押题1【简答】简述神经心理评估的含义、主要目的和常用方法。

神经心理评估是通过标准化测验和行为观察，考察脑功能与认知、情绪和行为表现关系的临床评估过程。（它既用于发现认知损害，也用于分析保留功能和制定康复计划。）【名词解释：神经心理评估】

神经心理评估的主要目的包括：

1. **筛查认知损害**：判断注意、记忆、语言、执行和视空间等功能是否偏离正常范围。

2. **描述功能模式**：分析受损和保留能力，形成个体认知功能剖面。（现代评估不宜只根据单个测验简单定位脑损伤部位。）

3. **辅助鉴别诊断**：为脑损伤、神经退行性疾病和部分精神障碍的鉴别提供心理学证据。

4. **制定康复计划**：依据功能优势与困难确定训练、补偿和环境支持方案。

5. **监测变化**：重复评估疾病进展、治疗效果和康复结果，并注意练习效应。

常用评估方法包括：

1. **筛查测验**：用较短工具快速判断是否需要进一步检查，优点是经济，局限是诊断特异性有限。

2. **成套测验**：系统评估多个功能领域，资料全面但施测时间较长、对被试和主试要求较高。

3. **针对性测验**：依据临床假设选择记忆、执行、语言等特定任务，适合进一步验证功能缺损。

综上，神经心理评估应结合病史、医学检查、行为观察和多项测验，综合判断认知损害及其现实影响。

# 第六章 人格评估

## 一、人格评估的方法与解释【★★】

### 押题1【论述】论述人格评估的主要方法，并比较自陈量表与投射测验。

人格评估是采用标准化测验、投射材料、访谈和行为观察等方法，对个体相对稳定的人格特点和适应方式进行描述与解释的过程。

人格评估的主要方法如下：

1. **临床访谈**：了解个体的自我认识、关系模式、应对方式和成长经历，能够获得情境化资料，但容易受到回忆和主试判断影响。

2. **行为观察**：记录真实或模拟情境中的行为，较接近实际表现，但耗时且行为可能受到观察情境影响。

3. **自陈量表**：向受测者呈现结构化问题，由其报告自己的感受、态度和行为倾向。（常见工具包括MMPI、16PF和EPQ。）【名词解释：自陈量表】

4. 投射测验是向被试提供**未经组织的刺激情境**，让其在不受限制的情况下自由表现，然后分析其反应，从而推断人格结构。（常用的投射测验包括**罗夏墨迹测验和主题统觉测验**。）【名词解释：投射测验】

自陈量表与投射测验的联系和区别如下：

1. **联系**：二者都通过受测者对刺激的反应间接推断人格，结果均需结合其他临床资料解释。

2. **刺激结构不同**：自陈量表题目和反应方式结构化，投射测验刺激模糊、反应自由度较高。

3. **计分解释不同**：自陈量表多采用客观计分和常模比较，投射测验更依赖编码系统、临床训练和综合判断。

4. **反应偏差不同**：自陈量表容易受到社会赞许、掩饰和自知力影响；投射测验目的较隐蔽，但也可能受到主试解释偏差影响。

5. **测量证据不同**：自陈量表通常更容易获得稳定的信效度证据；部分投射测验的标准化和效度争议较大。

人格评估的解释原则如下：

1. **检查效度指标和作答态度**，先判断结果是否可信，再解释人格分数。

2. **结合文化、年龄和临床情境**，避免把单一高分直接等同于人格障碍或精神诊断。

3. **进行多方法整合**，通过访谈、行为和知情者资料交叉验证测验结论。

综上，自陈量表重在标准化和效率，投射测验重在开放反应和人格动力假设，临床使用应以评估目的和证据质量为依据。

## 二、常用人格量表【★★】

### 押题1【简答】比较MMPI、16PF和EPQ的编制取向与结构特点。

MMPI、16PF和EPQ都是常用人格自陈量表，但三者在理论取向、编制方法和结构特点上各有侧重。

1. **MMPI**：由哈撒韦和麦金利采用经验效标法编制，主要用于临床人格与精神病理特征评估。（量表包括效度量表和临床量表，解释前必须先检查作答可信性。）【名词解释：MMPI】

2. **16PF**：由卡特尔依据人格特质理论，运用因素分析法形成16种人格因素，重在描述正常人格的多维特质。（不同因素的组合构成个体独特的人格侧面。）【名词解释：16PF】

3. **EPQ**：由艾森克夫妇编制，以外向性E、神经质N、精神质P为核心人格维度，并设置掩饰量表L。（L量表可辅助判断作答态度，但不应被简单视为“说谎分数”。）【名词解释：EPQ】

三种量表的联系和区别如下：

1. **联系**：三者都使用结构化题目收集自我报告，并通过多个分量表描述或鉴别人格特点。

2. **编制方法不同**：MMPI以经验效标区分临床组，16PF以因素分析提取特质，EPQ围绕艾森克人格维度并以因素分析筛选测题。

3. **测量目的不同**：MMPI偏重临床筛查和病理特征，16PF偏重正常人格多种特质，EPQ以少数高阶人格维度进行概括。

4. **结构特点不同**：MMPI由效度和临床量表组成，16PF结构较多元，EPQ由E、N、P、L四个分量表构成，结构相对简明。

综上，MMPI以经验效标和临床鉴别为核心，16PF以多种人格特质为核心，EPQ以高阶人格维度为核心。

# 第七章 临床评定量表

## 一、临床评定量表的性质与内容【★★★】

### 押题1【简答】简述临床评定量表的性质、种类及主要内容。

临床评定量表是对个体某种心理或行为问题的表现和严重程度进行标准化评定的工具。（它通常用于症状筛查、程度分级和疗效监测，不能脱离临床资料单独作诊断。）【名词解释：临床评定量表】

临床评定量表的性质和种类如下：

1. **评定性质**：根据行为和症状的观察或报告作数量化判断，具有实施方便、针对性强和便于重复测量等特点。

2. **自评量表**：由受评者根据自身体验作答，能够直接反映主观感受，但受理解、自知力和社会赞许影响。

3. **他评量表**：由临床人员、家属或教师依据观察评定，适合自我报告困难者，但可能受到观察机会和评分者偏差影响。

临床评定量表的主要内容包括：

1. **症状表现**：评定焦虑、抑郁、强迫、精神病性症状等是否存在及其频率、强度和持续时间。

2. **社会功能**：评定学习、工作、家庭、人际和自我照料受损程度。

3. **应激与生活事件**：了解近期压力事件及其主观影响。

4. **应对方式与社会支持**：评定个体面对压力的认知行为方式和可利用支持资源。

5. **生活质量和治疗变化**：比较治疗前后症状、功能和主观健康的变化。（重复使用同一量表时应注意练习、回归和自然波动。）

综上，临床评定量表把症状和功能转化为可比较指标，但必须结合量表性质、评定来源和临床背景解释。

## 二、常用临床评定量表及选用原则【★★】

### 押题1【简答】简述常用临床评定量表，并说明量表的选用原则。

临床评定量表应围绕具体评估目的选择，常用工具分别测量症状、应对、社会支持、应激反应和情绪调节。

1. **症状自评量表SCL-90**：从躯体化、强迫、人际敏感、抑郁、焦虑、敌对、恐怖、偏执和精神病性等方面评定近期症状。（它适合症状筛查和变化比较，不能单独用于精神障碍诊断。）【名词解释：SCL-90】

2. **应对方式评定量表**：评定个体面对压力时采用的问题解决、求助、回避等应对方式，有助于分析适应资源与风险。

3. **社会支持评定量表**：评定客观支持、主观支持和对支持的利用程度。（支持数量与个体实际感受到并能使用的支持并不完全相同。）

4. **社会性应激反应问卷**：评定社会应激情境中的情绪、认知和行为反应。

5. **认知情绪调节问卷**：评定个体在负性事件后采用的认知调节策略，如重新评价、反刍和灾难化等。

量表选用应遵循以下原则：

1. **目的匹配**：明确筛查、诊断辅助、严重程度分级还是疗效评价，选择相应内容和时间窗的量表。

2. **心理测量质量**：考察适用人群中的信度、效度、敏感性和临界值证据。

3. **常模适切**：使用与受评者年龄、文化和临床特征相符的常模或解释标准。

4. **多源验证**：结合访谈、观察和他评资料，不能仅凭某一量表总分下结论。

综上，临床量表的价值取决于工具与评估问题是否匹配，以及结果是否在多源资料中得到合理解释。

# 第八章 心理干预

## 一、心理干预的含义、种类与预防层次【★★★】

### 押题1【简答】简述心理干预的含义、主要种类及预防性干预的层次。

心理干预是在心理学理论指导下，有计划地影响个体或群体的心理活动、人格特征和行为方式，以促进心理健康和适应的过程。（其范围包括心理健康教育、心理咨询、心理治疗、危机干预和预防性干预。）【名词解释：心理干预】

心理干预的主要种类包括：

1. **心理健康教育**：向公众传播心理健康知识，帮助识别风险、增强求助意识和自我调节能力。

2. **心理咨询**：主要面向一般心理困扰和发展适应问题，通过专业关系帮助来访者认识问题、作出选择并发展能力。

3. **心理治疗**：由受过专业训练者运用心理学方法，针对心理障碍、行为问题或明显痛苦实施系统治疗。

4. **危机干预**：对处于急性心理危机的个体进行及时评估和短程帮助，优先恢复安全、稳定和现实支持。

5. **预防性干预**是在问题发生前或早期采取措施，以降低发生率、缩短病程和减少功能损害的心理干预。（按照介入阶段可分为一级预防、二级预防和三级预防。）【名词解释：预防性干预】

预防性干预通常分为以下层次：

1. **一级预防**：面向尚未出现心理障碍的人群，减少危险因素、增强保护因素，降低新发病例。（学校压力管理和普遍心理健康教育属于一级预防。）

2. **二级预防**：通过筛查和早期干预，及时发现高风险者或早期病例，缩短问题持续时间。（对产后抑郁高风险人群进行筛查和短程干预属于二级预防。）

3. **三级预防**：面向已经出现明显障碍或功能损害者，减少残疾、复发和继发问题，促进康复与社会回归。（复发预防和职业康复属于三级预防。）

综上，心理干预既包括对当前问题的咨询和治疗，也包括从普遍预防、早期发现到康复防复发的连续服务。

## 二、心理治疗的含义、过程与原则【★★★】

### 押题1【论述】论述心理治疗的基本过程及主要原则。

心理治疗是由受过专业训练的治疗者，在一定理论指导下，运用心理学方法，通过专业关系帮助来访者减轻症状、改善功能和促进人格成长的过程。（心理治疗既依赖具体技术，也依赖治疗关系、来访者资源和共同目标。）【名词解释：心理治疗】

心理治疗的基本过程如下：

1. **初始接触与评估**：澄清主诉、问题发展、治疗史和现实功能，完成风险评估并判断是否适合本机构治疗。

2. **建立治疗关系**：通过尊重、真诚、共情和稳定设置形成合作关系，说明保密、费用、时间、取消和危机处理等约定。

3. **形成个案概念化**：整合易感、诱发、维持和保护因素，解释症状如何形成和持续。（概念化是假设，应随新资料不断修正。）

4. **确定目标与计划**：与来访者协商具体、可观察和有优先顺序的目标，选择适宜取向、技术、频率和疗程。

5. **实施治疗**：围绕目标使用相应技术，持续关注治疗同盟、阻抗、家庭和环境影响。（每次会谈既处理当前材料，也应与总体概念化和目标保持联系。）

6. **监测和调整**：定期评估症状、功能、风险和目标进展，依据反馈调整方法或必要时转介。

7. **结束和随访**：共同回顾改变与有效因素，处理分离反应，制定复发预防和后续支持计划。

心理治疗应遵循以下主要原则：

1. **个体化原则**：依据来访者问题、人格、文化、资源和偏好制定方案，不能机械套用技术。

2. **关系与技术结合**：良好同盟为技术实施提供基础，具体技术又使治疗目标转化为可操作改变。

3. **保密与知情同意**：尊重隐私并事先说明保密例外、治疗方式、可能风险和替代方案。

4. **中立与尊重**：避免把治疗者价值强加给来访者，同时对危害自己或他人的高风险行为采取必要措施。

5. **专业胜任与边界**：只在训练和能力范围内工作，接受督导，避免双重关系和利用来访者。

6. **循证与评估**：把最佳研究证据、临床专长和来访者特点结合，并用持续评估检验实际效果。

综上，心理治疗是由评估、关系、概念化、目标、实施、监测和结束构成的完整过程，伦理原则和疗效反馈贯穿始终。

## 三、心理治疗的基本技术【★★★】

### 押题1【简答】简述心理治疗中倾听、提问、释义、情感反映和面质等基本技术。

心理治疗基本技术是治疗者为了理解来访者、促进表达和推动改变而使用的沟通方法，应服务于治疗目标并与关系阶段相匹配。

1. **倾听**：治疗者以开放、专注和不急于评判的方式接收来访者的言语与非言语信息。（有效倾听同时关注内容、情感、关系和未表达的意义。）

2. **提问**：开放式问题促进充分表达，封闭式问题用于澄清具体事实；提问应避免连续审问、暗示答案或满足治疗者好奇。

3. **释义**是治疗者用简明语言重新表述来访者谈话的主要内容，以核对理解、整理信息并突出重点的技术。（释义主要回应内容，不应擅自加入来访者没有表达的解释。）【名词解释：释义】

4. **情感反映**：指出并反馈来访者表达或隐含的情绪，帮助其识别、接纳和表达感受。（反映强度应与来访者实际体验相符，避免夸大。）【名词解释：情感反映】

5. **澄清**：对含糊、矛盾或跳跃的信息进一步询问，使事件、想法和感受更清楚。

6. **解释**：在足够资料和关系基础上，对行为、情感或关系模式提出新的联系和意义。（解释应以假设方式表达，并观察来访者反应。）

7. **面质**：治疗者温和、具体地指出来访者言语、情感和行为之间的不一致，邀请其共同考察。（面质的目的不是批评或击败来访者，而是增加觉察并促进整合。）【名词解释：面质技术】

8. **总结**：在会谈阶段或结束时概括主题、变化和未解决问题，帮助形成结构并过渡到下一步。

综上，基本技术应在共情和合作关系中准确使用，既促进来访者表达，也逐步推动觉察、理解和行为改变。

## 四、心理咨询与心理治疗【★】

### 押题1【简答】比较心理咨询与心理治疗的联系和区别。

心理咨询与心理治疗都是专业助人活动，均通过心理学理论、方法和关系促进个体改变，但在服务对象、问题程度和工作深度上有所侧重。

1. **共同基础**：二者都需要专业训练、伦理规范、知情同意、保密和稳定的助人关系。

2. **共同目标**：都帮助个体减轻困扰、改善适应、发展资源和提高生活质量。

3. **对象侧重不同**：心理咨询更多面向发展性、适应性和一般心理困扰；心理治疗更多面向心理障碍、持续症状和明显功能受损。

4. **工作深度不同**：咨询常围绕现实问题、选择和能力发展，治疗可能更系统地处理症状机制、人格结构和长期关系模式。

6. **实际连续性**：现实工作中服务对象和技术高度重叠，应根据问题严重度、风险、功能损害和专业胜任确定服务形式。（出现精神病性症状、高自杀风险或严重功能损害时，应及时联合医疗或转介。）

## 一、潜意识理论【★★★】

### 押题1【简答】简述精神分析的潜意识理论及其临床意义。

潜意识是心理活动过程中正常而不可避免的层次，每一种心理活动起初都可能处于意识之外；被压抑且难以进入意识的动力性观念和情感构成潜意识的重要内容。（潜意识并非简单等同于暂时没有注意到的信息，而具有冲突和动力性质。）【名词解释：潜意识】

1. **意识层次**：精神分析把心理活动区分为意识、前意识和潜意识；意识是当下觉察的内容，前意识内容在适当线索下可以进入意识。

2. **压抑作用**：某些欲望、记忆和情感因与自我或社会要求冲突而受到压抑，难以直接进入意识。（抵抗进入意识的对抗性力量体现了压抑。）

3. **动力性质**：潜意识内容不会消失，而会持续寻求表达，并影响情绪、选择、人际关系和症状。

4. **间接表现**：梦、口误、遗忘、自由联想中断和症状可成为潜意识冲突的间接表达。（同一表现可能有多种意义，不能机械套用象征解释。）

5. **临床目标**：通过自由联想、梦的分析、移情和阻抗处理，使潜意识冲突逐步进入觉察并得到理解和整合。

6. **治疗态度**：治疗者需要在稳定关系中帮助来访者承受和理解冲突，而不是简单告知一个所谓“隐藏真相”。

综上，潜意识理论强调意识之外的动力性冲突对症状和关系的影响，其临床意义在于通过安全关系促进觉察、领悟和整合。

## 二、焦虑与心理防御机制【★★★】

### 押题1【论述】论述心理防御机制的含义、作用及常见形式。

**心理防御机制**是自我为了对抗本能冲动及其诱发的焦虑，保护自身不受潜意识冲突困扰而形成的自动心理手段。（防御通常在意识之外运行，可以暂时维持心理平衡，但僵化使用会妨碍现实检验和适应。）【名词解释：心理防御机制】

心理防御机制具有以下基本作用：

1. **减轻焦虑**：改变个体对内在冲突或外部现实的体验，使难以承受的情绪暂时降低。

2. **维持自我**：保护自尊、自我连续性和基本功能，使个体能够继续应对现实任务。

3. **形成症状风险**：防御不能真正消除冲突，长期僵化使用可能造成认知歪曲、人际困难和心理症状。

常见心理防御机制如下：

1. **压抑**：把不能接受的欲望、记忆或情感排除在意识之外。（童年经历严重冲突后完全不记得相关情景，可体现压抑。）【名词解释：压抑】

2. **否认**：拒绝承认已经发生或明显存在的痛苦现实。（收到严重诊断后坚持认为检查绝不可能有问题，可能体现否认。）

3. **投射**：把自己不能接受的冲动、情感或特征归于他人。（自己对同事有敌意，却坚信同事一直针对自己。）

4. **反向形成**：把不能接受的冲动转化为性质相反、过度突出的态度和行为。（对某人有强烈敌意，却表现出过分热情。）

5. **置换**：把指向危险对象的情绪转移到较安全对象上。（受到上级批评后回家对家人发火。）

6. **合理化**：用看似合理的理由解释由其他动机造成的行为或失败，以保护自尊。（考试准备不足却只归因于题目偏。）

7. **退行**：在压力下退回到较早发展阶段的行为方式。（成人在挫折后以哭闹和依赖方式要求照顾。）

8. **升华**：把不能直接满足的冲动转化为社会认可、具有建设性的活动。（把攻击性能量投入竞技运动或创作。）

9. **隔离与抵消**：隔离把事件认知与情感分开；抵消则用某种象征性行为取消先前不能接受的想法或行为。

综上，防御机制既具有暂时保护功能，也可能在过度、僵化时维持问题；临床工作应考察防御的情境、弹性和现实代价，而非简单贴上好坏标签。

精神分析及心理动力治疗通过稳定的治疗设置、自由联想和治疗关系，探索潜意识冲突、早期经验及重复性人际模式，促进来访者获得领悟并形成新的适应方式。

其治疗过程主要包括以下环节：

1. **介绍程序与目的**：初步评估来访者的心理功能、动机和现实条件，说明治疗方式、频率、费用、保密和可能疗程，形成共同约定。（明确设置有助于建立安全、稳定和可观察关系模式的空间。）

2. **节制与自由联想**：自由联想是来访者尽量说出当下浮现的想法、感受和联想，不加筛选和整理的精神分析技术。（治疗者保持节制、减少直接指令并更多倾听，使潜意识联系有机会呈现。）【名词解释：自由联想】

3. **建立治疗同盟**：治疗同盟是治疗者与来访者围绕治疗目标、任务和情感联结形成的合作关系。（稳定同盟使治疗在触及痛苦内容或出现分歧时仍能继续。）【名词解释：治疗同盟】

5. **处理移情**：移情是来访者把过去重要关系中的情绪、期待和互动方式转移到治疗者及当前治疗关系中的现象。（治疗者通过帮助其区分过去与现在，使重复性关系模式能够被体验和理解。）【名词解释：移情】

6. **觉察反移情**：反移情是治疗者在与来访者互动中产生的情感、认知和行为倾向。（它既可能来自治疗者自身问题，也可能反映来访者的人际模式，应通过自我觉察和督导加以理解而非直接行动化。）【名词解释：反移情】

7. **梦的分析**：把梦视为理解潜意识冲突、愿望和移情的材料，结合来访者个人联想考察象征、凝缩、移置和二次加工。（梦的意义应由个案联想产生，不能依靠固定符号表。）

8. **解释与修通**：在合适时机把当前情感、关系模式与过去经验联系起来，并在反复出现的现实和治疗关系中持续理解、体验和改变。（一次领悟并不足以产生稳定改变，修通强调反复加工。）【名词解释：修通】

9. **结束治疗**：共同回顾症状、关系和应对方式的变化，处理分离情绪，识别未完成问题并制定结束后的自我观察和求助计划。

综上，精神分析和心理动力治疗以治疗同盟为基础，通过自由联想、阻抗与移情工作以及反复修通，把潜意识关系模式转化为可理解和可改变的经验。

## 四、精神分析取向案例解释【★★★】

### 押题1【论述】如何运用精神分析理论对一个具有焦虑、人际冲突和重复失败模式的案例进行解释？

精神分析取向案例解释不应只给症状贴标签，而要围绕潜意识冲突、早期关系、人格结构、防御和当前重复模式形成可以验证的个案假设。

1. **当前症状及功能**：先描述焦虑出现的情境、表现、持续时间和功能损害，并考察症状是否同时具有回避冲突、获得照顾或维持关系等功能。

2. **早期经验与客体关系**：了解主要照料者的回应、分离丧失、控制与忽视等经历，分析其如何形成对自己、他人和关系的内在表征。

3. **潜意识冲突**：考察依赖与独立、亲近与害怕受伤、表达攻击与担心惩罚等相互冲突的愿望。（冲突假设必须由多项材料支持，不能只凭单一经历推断。）

4. **人格结构和自我功能**：评估现实检验、冲动控制、情绪调节、关系维持和反思能力，判断个体在压力下如何协调本我、现实与超我要求。

5. **焦虑性质**：分析焦虑主要来自现实危险、本能冲动威胁还是严厉超我评价，并联系其具体诱因。

6. **防御方式**：识别压抑、否认、投射、反向形成、合理化等防御如何暂时减轻焦虑，又如何维持人际困难。

7. **重复性关系模式**：概括来访者在家庭、伴侣、工作和治疗关系中反复出现的期待、行为及他人反应。（例如，因害怕被抛弃而过度控制，反而使他人疏远并证实原有信念。）

8. **移情与反移情线索**：观察来访者如何体验治疗者以及治疗者被引发的感受，用于理解其核心关系模式，但需通过督导避免主观误判。

9. **治疗方向**：以稳定关系和支持性工作增强自我功能，再逐步澄清防御、解释关系模式并修通潜意识冲突。

综上，精神分析案例解释应把症状放在个体发展史、内在冲突和当前关系模式中理解，并把所有解释视为需要在治疗中持续验证和修正的假设。

## 一、行为治疗的理论、特点与过程【★★★】

### 押题1【论述】论述行为治疗的理论基础、基本特点和治疗过程。

行为治疗是依据学习理论和实验心理学原理，通过改变环境条件与行为后果，消除或矫正适应不良行为并建立适应性行为的心理治疗方法。（其理论基础主要包括经典条件作用、操作条件作用和社会学习理论。）【名词解释：行为治疗】

行为治疗的理论基础如下：

1. **经典性条件反射**：条件刺激与无条件刺激联结可以形成恐惧等反应，消退、反条件作用和暴露可用于改变条件反应。

2. **操作性条件反射**：行为的强化、惩罚和消退规律决定其出现概率，治疗可通过改变后果塑造目标行为。

3. **社会学习理论**：个体可以通过观察榜样及其结果学习行为，示范、模仿和自我效能影响行为改变。

行为治疗的基本特点如下：

1. **关注当前行为**：以现实中可观察、可测量的问题行为为主要对象，同时考察其环境功能。

2. **目标具体明确**：把“变得更好”转化为行为频率、持续时间或情境范围等可评价目标。

3. **方法可操作**：治疗步骤结构清楚，重视练习、家庭作业和现实情境中的行为改变。

4. **强调实证评价**：治疗前建立基线，治疗中持续记录，依据数据判断效果并调整方案。

行为治疗的基本过程如下：

1. **行为评估**：明确问题行为的表现、前因、后果、频率和功能，建立基线资料。

2. **功能分析**：使用刺激—有机体—反应—结果等框架，分析触发和维持行为的条件。（同一表面行为可能由不同强化关系维持。）

3. **确定目标**：与来访者共同设定具体、现实、有优先顺序且可以测量的目标。

4. **选择技术与计划**：依据功能分析选择暴露、强化、示范、技能训练等技术，规定实施步骤和评价指标。

5. **实施与监测**：在治疗室和自然情境中练习，连续记录行为变化和意外影响。

6. **巩固与泛化**：在多种情境练习目标行为，逐渐撤除外部帮助，制定复发预防计划。

综上，行为治疗把学习原理转化为行为评估、功能分析、技术实施和结果检验的完整流程，其关键是改变真正维持问题的条件。

## 二、常用行为治疗技术【★★★】

### 押题1【论述】论述系统脱敏、冲击疗法、厌恶疗法、代币法和示范法的原理与实施要点。

行为治疗技术依据经典条件作用、操作条件作用和观察学习等原理，通过暴露、反条件作用、强化和示范改变适应不良行为。

1. **系统脱敏法**：让来访者在放松状态下，按照从弱到强的焦虑等级逐步想象或接触恐惧情境，使恐惧反应与放松反应形成反条件作用。（主要步骤包括放松训练、建立焦虑等级和逐级脱敏。）【名词解释：系统脱敏法】

2. **冲击疗法**：又称满灌疗法，让来访者直接暴露于引起强烈恐惧和焦虑的想象或现实情境，并停留至焦虑自然减轻。（它依据条件反射消退原理，基本过程包括直接暴露、焦虑反应和自然消退；实施前必须充分评估、知情同意并排除禁忌。）【名词解释：冲击疗法】

3. **暴露与反应预防**：使来访者接触诱发焦虑的刺激，同时阻止其实施原有回避或强迫行为，使焦虑在没有灾难后果的情况下逐渐下降。（常用于强迫症等问题。）【名词解释：暴露与反应预防】

4. **厌恶疗法**：把需要消除的行为与不愉快刺激配对，降低该行为的吸引力和发生概率。（该方法伦理风险较高，应优先考虑伤害更小、证据更充分的替代方案。）【名词解释：厌恶疗法】

5. **代币法**：以代币作为条件强化物，个体表现目标行为后获得代币，再用代币兑换实际奖励。（需要明确目标行为、兑换规则和逐步撤除代币，避免长期依赖外部强化。）【名词解释：代币法】

6. **示范法**：让来访者观察榜样完成目标行为及其结果，再通过模仿和练习形成新行为。（榜样与观察者的相似性、示范行为难度和替代性强化会影响效果。）【名词解释：示范法】

7. **行为塑造**：对逐步接近目标行为的反应给予强化，分阶段建立复杂行为。（每一阶段标准应适中，随着行为形成逐步提高要求。）

8. **生物反馈**是把难以直接觉察的生理活动转化为可感知信号，使个体通过反馈学习调节相应生理过程的方法。（常用反馈指标包括肌电、皮肤电、心率和脑电等。）【名词解释：生物反馈】

综上，各技术的共同目标是改变行为与环境后果的关系，但具体选择必须依据问题功能、证据、伦理和来访者接受程度。

# 第十一章 人本—存在主义心理治疗

## 一、来访者中心心理治疗【★★★】

### 押题1【论述】论述来访者中心心理治疗的基本理论、治疗条件和主要特点。

来访者中心心理治疗由罗杰斯创立，认为人具有自我实现和成长倾向，治疗的核心不是由治疗者直接指导，而是提供促进人格改变的关系条件。（核心关系条件包括真诚一致、无条件积极关注和准确共情。）【名词解释：来访者中心心理治疗】

其基本理论如下：

1. **实现倾向**：有机体具有维持、发展和实现潜能的内在动力，在适宜环境中会朝更完整、成熟的方向发展。

2. **现象场**：个体依据自己体验到的主观世界行动，理解行为必须进入其独特经验框架。

3. **自我概念**：个体对“我是谁”的组织化认识；现实经验与自我概念不一致时，会产生焦虑和防御。

4. **价值条件**：重要他人只在个体满足特定要求时给予积极关注，使其否认或歪曲不符合条件的真实经验。

促进改变的核心治疗条件如下：

1. **真诚一致**：治疗者在关系中真实，其意识到的体验、表达和行为基本一致。

2. **无条件积极关注**：治疗者尊重和接纳来访者作为一个人的价值，不以其表现符合某种要求为条件。

3. **准确共情**：治疗者从来访者内部参照系理解其感受和意义，并把这种理解恰当地传达给对方。

主要治疗特点如下：

1. **非指导性**：治疗者不替来访者决定人生选择，而通过倾听、情感反映和澄清促进自我探索。

2. **关系本身具有治疗性**：在安全、不评价的关系中，来访者能够减少防御，接触被否认经验并重建更一致的自我。

3. **重视此时此地体验**：关注来访者当下如何感受自己、治疗者和关系，而非只追查过去原因。

4. **尊重自主性**：目标由来访者的成长方向产生，治疗者提供条件而不是塑造一个预定人格。

综上，来访者中心治疗以人的成长潜能为基础，通过真诚、无条件积极关注和共情促进自我概念与真实经验趋于一致。

# 第十二章 认知治疗

## 一、埃利斯理性情绪疗法【★★★】

### 押题1【论述】论述理性情绪疗法的基本理论、ABCDE模式和治疗过程。

理性情绪疗法由埃利斯创立，认为引起情绪和行为后果的关键不是事件本身，而是个体对事件持有的信念和评价。（治疗以ABCDE模式识别和辩论不合理信念，建立更合理的新观念。）【名词解释：理性情绪疗法】

其基本理论如下：

1. **ABC理论**：A是诱发事件，B是个体对事件的信念，C是情绪和行为后果；A并不直接决定C，B起核心中介作用。

2. **不合理信念**：常具有绝对化要求、过分概括和糟糕至极等特点。（“我必须得到所有人的认可，否则我就是毫无价值的人”包含绝对化和整体否定。）

3. **情绪责任**：个体不是为不利事件本身，而是为持续持有的不合理信念所困扰，因此可以通过改变信念改善情绪。

ABCDE模式及治疗过程如下：

1. **A—诱发事件**：具体澄清何时、何地发生何事，避免把评价混入事实。

2. **B—信念**：识别事件发生后自动出现的绝对化、灾难化和自我贬低信念。

3. **C—后果**：区分适度的负性情绪与过度、持续、妨碍功能的情绪和行为结果。

4. **D—辩论**：从逻辑、经验和实用性三个方面质疑不合理信念，检查它是否符合事实、逻辑以及是否有助于目标。

5. **E—新效果**：形成更合理、灵活和自我接纳的新信念，并体验更适度情绪和适应性行为。

6. **认知技术**：使用苏格拉底式提问、语义精确化、合理自我陈述和认知家庭作业。

7. **情绪与行为技术**：使用理性情绪想象、羞耻攻击练习、角色扮演和行为作业，把新信念落实到现实经验中。

综上，理性情绪疗法通过识别和辩论不合理信念，使来访者由绝对化要求转向灵活偏好，并在行为实践中巩固新的情绪反应。

## 二、贝克认知行为治疗【★★★】

### 押题1【论述】论述贝克认知行为治疗的核心概念和基本程序。

1. **自动思维**是在特定情境中迅速出现、看似可信但未经充分检验，并直接影响情绪和行为的想法。（它通常简短、自动且容易被当作事实，可通过思维记录进行识别。）【名词解释：自动思维】

2. **中间信念**：由态度、规则和假设构成，如“如果我没有做到最好，就会被否定”。

3. **核心信念**：个体关于自己、他人和世界的深层、概括性认识，如“我是无能的”。

4. **认知歪曲**：包括任意推断、选择性概括、过度概括、夸大缩小、个人化和非黑即白等系统偏差。

5. **认知三联征**是抑郁个体倾向消极看待自我、当前经验和未来的认知模式。（三方面相互加强，能够维持无助、低落和退缩行为。）【名词解释：认知三联征】

基本治疗程序如下：

1. **评估和概念化**：明确问题、触发情境、自动思维、情绪行为后果和维持循环，形成可检验的认知概念化。

2. **目标和结构**：共同设定目标，每次会谈确定议程、检查情绪和家庭作业、讨论重点并总结反馈。

3. **识别自动思维**：通过情绪变化、情境回顾和思维记录表找到关键想法，评价其可信度。

4. **检验证据**：使用苏格拉底式提问，寻找支持和反对证据，形成更平衡的替代思维。

5. **行为实验**：在现实中检验预测和信念，通过新经验修正认知。（认为“发言一定被嘲笑”的来访者可进行分级发言实验并记录实际结果。）

6. **行为激活和技能训练**：增加有价值活动、减少回避，必要时训练问题解决、社交和情绪调节技能。

7. **修正深层信念**：在症状改善和资料充分后，识别中间与核心信念，发展更灵活、现实的新信念。

8. **复发预防**：总结有效工具，识别预警信号，把来访者培养成自己的治疗者。

综上，贝克认知行为治疗通过结构化合作、认知检验和行为实验打破维持问题的认知—情绪—行为循环。

正念减压疗法由卡巴—金创立，是以正念禅修为核心、帮助个体以开放和不评判态度面对压力与身心问题的团体干预。（课程通常持续数周，通过正式练习和日常应用培养当下觉察。）【名词解释：正念减压疗法】

## 二、森田疗法【★★】

### 押题1【简答】简述森田疗法的基本观点和治疗原则。

森田疗法由森田正马创立，主要针对神经质性问题，强调**顺其自然、为所当为**，即接纳症状和情绪的存在，同时把行动投入现实生活。（其基本解释包括疑病素质、精神交互作用和思想矛盾。）【名词解释：森田疗法】

1. **疑病素质**：个体内省性强、对身心变化敏感，容易把正常感觉解释为异常并持续关注。

2. **精神交互作用**是个体越把注意集中于某种感觉，感觉越敏锐，而感觉增强又进一步吸引注意的循环过程。（它可以解释神经质症状因过度关注而持续放大的现象。）【名词解释：精神交互作用】

3. **思想矛盾**：个体希望完全控制本不能由意志直接控制的情绪和生理反应，理想状态与现实状态冲突加重痛苦。

4. **顺其自然**：不强行排斥焦虑和症状，允许其存在并理解情绪具有自然规律。（接纳不等于消极放弃，而是不再与症状进行无效斗争。）

5. **为所当为**：把注意和行动转向现实任务，按照生活目标做应做之事，而不是等待症状消失后再行动。

6. **治疗过程**：经典住院式森田疗法包括绝对卧床、轻工作、重工作和生活训练等阶段，现代应用可根据情境调整。

综上，森田疗法通过打破对症状的过度注意和控制循环，使个体在接纳情绪的同时恢复有目标的现实行动。

## 三、系统式家庭治疗【★★】

### 押题1【论述】论述系统式家庭治疗的基本观点和主要技术。

系统式家庭治疗把个体症状放在家庭互动系统中理解，认为家庭成员相互影响，症状可能承担维持系统平衡或表达关系冲突的功能。（它以整体性、循环因果、反馈、边界和家庭规则等概念解释问题。）【名词解释：系统式家庭治疗】

其基本观点如下：

1. **整体性**：家庭整体具有不同于成员简单相加的关系模式，理解个体需要考察家庭结构和互动规则。

2. **循环因果**：成员行为相互反馈、彼此维持，不把问题简单归咎于某一个“有病的人”。（一方批评导致另一方退缩，退缩又加强批评，形成循环。）

3. **稳态与改变**：家庭通过规则和反馈维持相对稳定，个体症状有时会帮助系统保持原有平衡。

4. **边界和子系统**：夫妻、亲子和手足等子系统需要适当边界；边界过度僵化或弥散都可能影响功能。

5. **代际传递**：家庭中的关系模式、情绪和信念可能跨代重复，三角关系会把两人冲突转移到第三者。

主要治疗技术如下：

1. **循环提问**：询问不同成员如何看待彼此行为及互动次序，帮助家庭看见循环模式。

2. **重构**：为问题行为提供新的、较少责备的意义，改变家庭成员的解释框架。

3. **家庭结构调整**：通过座位、任务和会谈互动改变联盟、权力和边界。

4. **悖论干预**：在严格评估和治疗关系基础上，对症状作策略性处方，打破原有控制循环。（该技术复杂且有风险，不宜机械使用。）

5. **家庭作业**：让家庭在会谈外尝试新的沟通、分工和问题解决方式，并在下次会谈复盘。

综上，系统式家庭治疗由追问“谁导致了问题”转向分析“互动如何维持问题”，并通过改变关系规则促进个体和家庭共同变化。

## 四、眼动脱敏再加工【★】

### 押题1【简答】简述眼动脱敏再加工的基本原理和实施要点。

眼动脱敏再加工是一种以创伤记忆为工作对象、在回忆创伤材料的同时进行双侧刺激的心理治疗方法。（常用双侧刺激包括左右眼动、交替轻拍或声音。）【名词解释：眼动脱敏再加工】

1. **理论假设**：创伤信息可能以功能失调方式储存，当前线索会重新激活鲜明图像、负性认知和身体反应。

2. **评估与准备**：了解创伤史、稳定能力和风险，建立安全关系并训练稳定化方法，不能在准备不足时直接暴露创伤。

3. **确定靶点**：选择具体创伤图像、负性认知、期望的积极认知、情绪强度和身体感觉。

4. **脱敏与再加工**：来访者保持对靶点的注意，同时跟随双侧刺激，让新的联想自然出现并反复处理。

5. **安装与身体扫描**：增强积极认知，检查身体是否仍有明显紧张或不适，并处理残留反应。

6. **结束与复评**：会谈结束前恢复稳定，下次评估目标记忆和新材料的变化。（复杂创伤、解离和高风险个案需要更谨慎的阶段化处理。）

综上，眼动脱敏再加工通过结构化评估、双侧刺激和创伤记忆再加工减轻痛苦，其实施依赖充分准备和风险控制。

# 第十四章 心理治疗疗效评估

## 一、心理治疗疗效的标准与评估方法【★★★】

### 押题1【论述】论述心理治疗疗效的评估标准和常用研究方法。

心理治疗疗效评估是采用系统方法判断治疗后症状、功能和生活质量是否发生可靠且具有临床意义改变的过程。（临床上常把患者功能转变到非病人或正常范围作为重要疗效标准，但还应结合个体目标和现实功能。）【名词解释：心理治疗疗效评估】

心理治疗疗效的主要评估标准包括：

1. **症状改善**：目标症状的频率、强度和痛苦程度明显下降。

2. **功能恢复**：学习、工作、人际、自我照料和社会参与得到改善。

3. **临床显著性**：变化不仅达到统计显著，还超过测量误差并进入正常或功能良好范围。（可靠变化指数可用于判断个体变化是否超过随机误差。）

4. **目标达成和主观评价**：来访者对核心目标、生活质量和治疗满意度的评价得到改善。

5. **维持与复发**：治疗效果在结束后仍能保持，复发率和再次求助风险降低。

常用疗效评估方法如下：

1. **单个案实验设计**：把个体置于有计划的基线和治疗条件中，反复测量心理功能变化，常见A-B-A-B设计和多基线设计。（例如强迫行为在治疗阶段下降、撤除后反弹、再次治疗后又下降，可支持处理效果。）

2. **非随机对照研究**：比较自然形成的治疗组与对照组，实施方便，但组间原有差异会削弱因果解释。

3. **随机临床试验**：把相对同质的来访者随机分配到不同治疗或控制条件，比较结果差异，以控制潜在额外变量。（随机化提高内部效度，但样本选择和严格程序可能限制现实推广。）【名词解释：随机临床试验】

4. **元分析**：对多项研究的统计结果进行再分析和综合，以效应量估计治疗总体效果，并考察研究间差异。（元分析结论仍受到纳入研究质量、异质性和发表偏倚影响。）【名词解释：元分析】

5. **过程—结果研究**：同时考察治疗同盟、技术实施和会谈变化等过程变量与最终疗效的关系，帮助理解“什么对谁在何种条件下有效”。

提高疗效评估质量还应注意：

1. **多时间点测量**：设置治疗前、治疗中、治疗后和随访，区分短期波动与持续改变。

2. **多来源指标**：结合自评、治疗者评定、行为任务和现实功能，避免单一来源偏差。

3. **治疗完整性**：记录治疗者是否按照方案实施，并同时关注灵活的个体化调整。

4. **不良反应与脱落**：报告症状恶化、危机、退出和依从性，不能只分析完成治疗者。

综上，心理治疗疗效评估需要同时考察统计变化、临床意义、现实功能和长期维持，并通过单个案、对照试验与元分析等互补证据作出判断。

## 二、影响心理治疗疗效的共同因素【★★】

### 押题1【简答】简述影响心理治疗疗效的主要共同因素。

共同因素是不同心理治疗取向中普遍存在、能够影响治疗结果的关系和过程条件。（强调共同因素并不意味着具体治疗技术没有作用。）【名词解释：共同因素】

1. **来访者因素**：求助动机、改变准备、心理资源、问题严重度、社会支持和对治疗的期待都会影响结果。

2. **治疗者因素**：专业胜任、真诚、共情、文化敏感性、情绪稳定和对反馈的开放程度会影响关系与技术实施。

3. **治疗同盟**：治疗者与来访者对目标、任务的共识以及情感联结，是多种治疗中稳定的疗效相关因素。

4. **可信解释与希望**：治疗提供来访者能够理解和接受的问题解释与改变路径，增强希望和参与感。

5. **情绪唤起与矫正经验**：在安全关系中接触原有痛苦经验，并产生不同于过去的新反应和关系体验。

6. **现实练习与反馈**：把会谈中的理解转化为现实行为，通过成功经验、反馈和复盘巩固改变。

7. **技术匹配**：具体方法应与问题机制、来访者特点和治疗阶段匹配，并保证基本实施质量。

综上，治疗疗效来自来访者、治疗者、关系、希望、技术和现实环境的共同作用，应同时重视共同因素与特定技术。
