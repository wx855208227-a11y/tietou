# 第一章 心理学研究的对象、方法及其学科发展

## 一、心理学的含义、诞生与研究对象【一级】【11、13、15、16、20、21年真题】【选择/简答/论述】

**真题依据**：2011、2013、2015、2016 年考查心理学定义或科学心理学诞生；2020、2021 年考查心理学史人物与事件。考纲明确要求掌握心理学研究对象。

### 押题题目

1. 【名词解释】心理学。
2. 【简答】简述心理学的研究对象。
3. 【简答·衍生】简述科学心理学诞生的标志及重要历史事件。
4. 【论述·衍生】论述心理过程与人格的构成及其关系。

### 综合答案

**【A｜名词解释必背】**

心理学是研究人的行为和心理活动规律的中间科学。1879 年，冯特在德国莱比锡大学建立世界上第一个心理学实验室，标志着科学心理学的诞生。

**【B｜简答扩展：研究对象】**

心理学的研究对象主要包括心理过程和人格。

1. **心理过程**：包括认知过程、情绪情感过程和意志过程。
   - 认知过程是对信息进行加工处理的过程，包括感觉、知觉、记忆、思维和想象。
   - 情绪情感过程是人脑对客观事物是否满足需要而产生的态度体验。
   - 意志过程是人自觉确定目的、克服困难并努力实现目的的心理过程。
   - 三者是同一心理活动的不同方面，其中认知过程是最基本的心理活动。
2. **人格**：包括心理动力和心理特征。
   - 心理动力体现人对活动对象的选择和趋向，是活动的指向性与基本动力。
   - 心理特征是人在心理活动中形成的、稳定而经常表现出来的心理特点，是个体多种心理特点的独特结合。

**【C｜论述扩展：历史线索】**

科学心理学的发展可抓住三个时间点：1879 年冯特建立世界上第一个心理学实验室；1890 年詹姆斯出版《心理学原理》；1917 年陈大齐建立中国第一个心理学实验室。心理学由此逐渐摆脱纯思辨研究，走向实验化、科学化和应用化。

## 二、现代心理学的主要流派【一级】【11、17、20、22、23、24年真题】【选择/简答/论述】

**真题依据**：2011、2017、2020、2022、2023、2024 年反复考查流派代表人物、研究对象和核心观点；考纲明确列出主要心理学流派。

### 押题题目

1. 【名词解释】构造主义、机能主义、行为主义、格式塔心理学、精神分析、人本主义或认知心理学。
2. 【简答】简述行为主义的主要观点及评价。
3. 【简答·衍生】比较构造主义与机能主义。
4. 【简答·衍生】比较行为主义、精神分析和人本主义的人性观与研究对象。
5. 【论述】论述现代心理学主要流派的发展及其贡献。

### 综合答案

**【A｜名词解释必背：看到哪个学派，就背对应一条】**

1. **构造主义**：代表人物是冯特、铁钦纳，研究对象是意识或直接经验，主张把意识分析为感觉、意象和激情等基本元素，主要采用内省法。
2. **机能主义**：代表人物是詹姆斯、杜威和安吉尔，研究心理活动及其适应功能，认为意识是个人的、变化的、连续的，并具有选择功能。
3. **行为主义**：代表人物是华生、斯金纳和班杜拉，研究可观察的外显行为，强调环境刺激及“刺激—反应”关系，主要采用实验法。
4. **格式塔心理学**：代表人物是韦特海默、苛勒和考夫卡，研究意识与认知现象，主张心理具有结构性和整体性，整体不能还原为部分之和。
5. **精神分析学派**：代表人物是弗洛伊德、荣格和阿德勒，研究无意识，强调早期经验、本能和潜意识冲突对人格与行为的影响，常用自由联想和梦的解析。
6. **人本主义心理学**：代表人物是马斯洛和罗杰斯，研究健康人格，强调人的潜能、自由选择和自我实现，被称为心理学“第三势力”。
7. **认知心理学**：代表人物有皮亚杰、奈瑟尔、纽维尔和西蒙等，研究人的认知过程及其内部加工机制，常用反应时、口语报告和计算机模拟等方法。

**【B｜简答扩展：贡献与局限】**

1. 构造主义把内省与客观刺激测量相结合，推动心理学走上实验研究道路；但研究范围较窄，主观性强、重复性差。
2. 机能主义推动心理学面向实际生活，并促进教育心理学和工业心理学发展；但存在排斥其他学派的倾向。
3. 行为主义强调以客观方法研究行为，推动心理学自然科学化；但否认或忽视意识的重要性，观点较为极端。
4. 格式塔心理学突出心理的整体性，促进认知心理学兴起，其研究至今仍有影响。
5. 精神分析重视内部动力和人格整体；但过分强调无意识和性本能，部分理论缺乏客观验证。
6. 人本主义重视人的需要、尊严和潜能；但部分概念界定不清，具体研究方法不足。
7. 认知心理学重新把内部心理机制纳入科学研究，并与神经科学结合形成认知神经科学；但部分加工模型仍需更多实证检验。

**【C｜论述收束】**

现代心理学的发展表现为研究对象从意识、行为、无意识逐渐扩展到健康人格和认知加工，研究方法也由内省走向实验、测量和计算机模拟。各流派虽有局限，但共同推动心理学形成多层次、多方法的学科体系。

## 三、观察法、相关研究法与实验法【一级】【12、13、24年真题】【选择/简答/论述】

**真题依据**：2012、2013、2024 年考查自变量、因变量、随机分配及相关系数；考纲明确要求掌握观察法、相关研究法、实验法及实验变量。

### 押题题目

1. 【名词解释】观察法、相关研究法或实验法。
2. 【简答】比较观察法、相关研究法和实验法的优缺点。
3. 【简答】简述实验研究中的自变量、因变量和控制变量。
4. 【论述·衍生】如何根据研究目的选择心理学研究方法？

### 综合答案

**【A｜名词解释必背】**

1. **观察法**：在自然情境中，对心理现象和行为表现进行有系统、有计划的观察与记录，从而认识心理活动规律的方法。
2. **相关研究法**：考察人格特质、行为或事件之间关联方向与程度的方法，通常用相关系数表示，相关系数取值在 -1.00 到 +1.00 之间。
3. **实验法**：有计划、有目的地控制条件，使被试产生某种心理活动，并分析变量之间因果关系的方法。

**【B｜简答扩展：特点与评价】**

1. **观察法**所得资料较真实，但难以重复验证和精确分析，容易受观察者效应、观察者偏差及情境干扰，也不能确定因果关系。
2. **相关研究法**可以量化变量关系的方向和程度，并用于预测心理现象；但相关不等于因果，不能仅凭相关系数作因果推断。
3. **实验法**可以主动控制研究进程、控制额外变量、重复检验并揭示因果关系；但实验情境可能降低外部效度，也不适合所有复杂行为。

**【C｜论述扩展：实验变量与控制】**

1. **自变量**是实验者主动操纵的变量。
2. **因变量**是实验者观察、测量和记录的结果变量。
3. **控制变量或无关变量**是与研究目的无关、但可能影响结果的变量。
4. 随机分配被试到实验组和控制组，主要是为了平衡个体差异等无关变量，提高实验的内部效度。
5. 选择研究方法时，应根据能否操纵变量、是否需要揭示因果关系以及研究情境的真实性综合判断：观察法重真实性，相关法重关系与预测，实验法重控制与因果。

### 铁头tips｜三种研究方法易混辨析

| 比较维度 | 观察法 | 相关研究法 | 实验法 |
| --- | --- | --- | --- |
| 核心任务 | 记录自然发生的行为 | 判断变量关系的方向与程度 | 操纵变量并检验因果 |
| 控制程度 | 低 | 中等 | 高 |
| 能否推断因果 | 不能 | 不能 | 可以 |
| 最大优势 | 资料真实 | 能量化关系并用于预测 | 控制严密、可重复 |
| 主要局限 | 易受情境和观察者影响 | 相关不等于因果 | 情境人工、外部效度可能较低 |

## 四、测验法、信效度与投射法【二级】【11、14年真题】

**真题依据**：2011 年考查信度和效度；2014 年名词解释直接考查投射法。该部分未在导论考纲中明确展开，按二级处理。

### 押题题目

1. 【名词解释】测验法、信度、效度或投射法。
2. 【简答】简述心理测验的基本要求。
3. 【简答·衍生】比较信度与效度。

### 综合答案

**【A｜名词解释必背】**

1. **测验法**：运用标准化测验工具，度量个体之间或个体内部反应差异的方法。
2. **信度**：测量结果的一致性、稳定性或可靠性。
3. **效度**：测验或研究结果能够真实测量目标心理变量或品质的程度。
4. **投射法**：向被试呈现意义模糊、结构不明确的刺激材料，要求其自由反应，再由专业人员分析其内在动机、欲望、冲突和情绪的方法，如罗夏墨迹测验和主题统觉测验。

**【B｜简答扩展】**

心理测验至少应具有良好的信度和效度。信度回答“测得是否稳定可靠”，效度回答“是否测到了想测的内容”。信度是效度的必要条件，但信度高不必然说明效度高。投射法能够了解较深层的人格动力，但解释易受主观因素影响，使用时应由专业人员结合其他资料综合判断。

## 五、心理学的主要分支【二级】【21年真题】

**真题依据**：2021 年问答题要求说明心理学定义，并至少列出三个分支及每个分支对应的科学问题；考纲未单独列出学科分支，按二级处理。

### 押题题目

1. 【简答·真题原型】简述心理学的定义，并至少写出三个分支，每个分支提出一个相关科学问题。
2. 【简答·衍生】简述心理学主要基础分支与应用分支。
3. 【论述·衍生】论述心理学分支体系及其社会价值。

### 综合答案

**【A｜答题开头】**

心理学是研究人的行为和心理活动规律的中间科学。随着研究对象与社会需要不断扩展，心理学形成了众多基础分支和应用分支。

**【B｜简答主体：考试至少写三项，建议背五项】**

1. **生理心理学**：研究心理活动的生理机制。科学问题示例：学习和记忆涉及哪些神经机制？
2. **发展心理学**：研究个体从受精卵到衰老的生命全程中心理发生和发展的规律。科学问题示例：儿童言语发展的年龄特征是什么？
3. **教育心理学**：研究教育过程中教与学的心理活动规律。科学问题示例：学生有效学习的心理规律有哪些？
4. **社会心理学**：研究群体环境下个体心理发生、发展和变化的规律。科学问题示例：影响人际关系的因素有哪些？
5. **临床心理学**：运用心理学原理评估、诊断和干预心理异常。科学问题示例：如何有效评估并干预焦虑问题？

**【C｜论述收束】**

不同分支从生理基础、个体发展、教育活动、社会关系和心理健康等层面研究人的心理与行为，既共同完善心理学理论体系，也为教育、医疗和社会治理提供科学依据。

# 第二章 心理和行为的生物学基础

## 一、神经元、神经冲动与突触【一级】【25年真题】【选择】

**真题依据**：2025 年考查神经元之间相互联系的结构；考纲要求掌握神经系统。

### 押题题目

1. 【名词解释】神经冲动、静息电位、动作电位或突触。
2. 【简答】简述神经冲动的传导方式及特点。
3. 【论述·衍生】论述神经元内与神经元之间的信息传递过程。

### 综合答案

**【A｜名词解释必背】**

1. **神经冲动**：神经元受到刺激后，由静息状态转为兴奋状态并传递信息的过程。
2. **静息电位**：神经元未受刺激时膜内外形成的外正内负电位差，主要与钾离子外流有关。
3. **动作电位**：神经元兴奋时膜电位迅速反转为外负内正的变化，主要与钠离子内流有关，并服从“全或无”规律。
4. **突触**：一个神经元与另一个神经元发生功能联系的部位，由突触前膜、突触间隙和突触后膜构成。

**【B｜简答扩展】**

神经信息传递包括电传导和化学传导。神经冲动沿神经纤维传导时主要表现为动作电位的电传导；在神经元之间则主要通过突触完成化学传导。神经递质由突触前膜释放，经突触间隙作用于突触后膜，因此突触传递通常具有单向性。

**【C｜论述收束】**

神经元通过“膜电位变化—轴突传导—神经递质释放—突触后膜反应”完成信息传递。电传导保证信息快速到达神经末梢，化学传导使不同神经元能够形成复杂网络，两者共同构成人脑信息加工的生理基础。

## 二、神经系统的构成与功能【二级】

**考纲依据**：考纲明确列出神经系统；现有华东真题未直接以完整简答题考查，按二级处理。

### 押题题目

1. 【名词解释】周围神经系统、中枢神经系统或自主神经系统。
2. 【简答】简述神经系统的构成。
3. 【简答】比较交感神经系统与副交感神经系统。
4. 【论述·衍生】论述周围神经系统与中枢神经系统如何协同调节行为。

### 综合答案

**【A｜名词解释必背】**

神经系统是由神经元构成的复杂机能系统，通常分为周围神经系统和中枢神经系统。周围神经系统负责中枢与身体各部分之间的信息传递；中枢神经系统包括脊髓和脑，负责对输入信息进行分析、整合并发出指令。

**【B｜简答扩展】**

1. **周围神经系统**包括躯体神经系统和自主神经系统。躯体神经系统主要联系感觉器官、骨骼肌与中枢；自主神经系统主要调节内脏和腺体活动，通常不受主观意志直接控制。
2. **自主神经系统**包括交感神经与副交感神经。交感神经提高机体唤醒水平，使个体应对环境变化；副交感神经帮助机体恢复、维持安静状态。二者相互制约、协调活动。
3. **中枢神经系统**中，脊髓既是简单反射中枢，也是脑与周围神经之间的信息通道；脑承担感觉整合、运动调节、情绪和高级认知等功能。

**【C｜论述收束】**

周围神经系统把内外环境刺激传入中枢，中枢对信息进行加工后，再经周围神经把指令传到效应器并产生行为。两者共同构成“输入—加工—输出”的完整调节系统。

## 三、大脑皮层主要区域及其功能【一级】【12、21、22年真题】【选择】

**真题依据**：2012 年考查听觉区和言语区；2021 年考查布洛卡区损伤；2022 年考查前额叶与认知控制。考纲要求掌握脑的结构与功能。

### 押题题目

1. 【名词解释】布洛卡区、威尔尼克区或皮层联合区。
2. 【简答】简述大脑皮层感觉区、运动区、言语区和联合区的功能。
3. 【简答·案例】根据患者的语言表现判断受损脑区。
4. 【论述·衍生】论述大脑皮层功能分区及其协同关系。

### 综合答案

**【A｜名词解释必背】**

1. **布洛卡区**又称运动性言语区，主要参与言语产生；受损后可出现表达不流畅、说不出的运动性失语。
2. **威尔尼克区**又称听觉性言语区，主要参与言语理解；受损后可出现听得见但难以理解的感觉性失语。
3. **皮层联合区**不直接接受单一感觉输入或发出简单运动指令，主要对多种信息进行综合加工，包括感觉联合区、运动联合区和前额联合区。

**【B｜简答扩展】**

1. **感觉区**：躯体感觉区主要位于中央后回，具有左右交叉、身体部位大体倒置的投射特点；视觉区位于枕叶；听觉区位于颞叶。
2. **运动区**：主要位于中央前回，负责支配和调节躯体运动，身体部位的皮层代表区也大体呈倒置排列。
3. **言语区**：除布洛卡区和威尔尼克区外，角回与阅读理解有关，相关区域受损可出现失读；书写区参与书面表达。
4. **联合区**：负责感觉整合、运动计划和高级认知。前额叶对选择性注意、工作记忆、冲突解决、抑制控制和认知灵活性具有重要作用。

**【C｜案例判断与收束】**

判断失语症时，应先看“能否理解”，再看“能否流畅表达”：理解相对正常但表达不流畅，多提示布洛卡区异常；表达流畅但内容混乱、理解困难，多提示威尔尼克区异常。各脑区存在相对分工，但复杂心理活动仍依赖多个区域协同完成。

## 四、大脑两半球的功能分工【一级】【14年真题】【选择】

1. 【名词解释】大脑半球单侧化。
2. 【简答】简述斯佩里裂脑实验的结论。
3. 【论述·衍生】论述大脑两半球的功能分工与协同关系。

### 综合答案

**【A｜名词解释必背】**

大脑半球单侧化是指左右大脑半球在某些心理功能上存在相对优势分工的现象。斯佩里的裂脑研究为半球功能不对称提供了重要证据。

## 六、脑功能的主要学说【二级】

**考纲依据**：属于“脑的结构与功能”范围；现有华东真题未直接命题，按二级处理。

### 押题题目

1. 【名词解释】定位说、整体说、机能系统说、模块说或神经网络说。
2. 【简答】比较定位说与整体说。
3. 【论述·衍生】论述脑功能学说的发展及共同趋势。

### 综合答案

**【A｜名词解释必背】**

1. **定位说**认为大脑不同区域分别承担不同心理功能。
2. **整体说**认为大脑以整体方式发挥作用，功能损失程度主要取决于皮层受损面积，而非某一固定部位；拉什利提出均势原理和总体活动原理。
3. **机能系统说**由鲁利亚提出，认为脑是复杂的动态机能系统，包括维持觉醒、加工和存储信息、调节与控制行为三个相互联系的系统。
4. **模块说**认为人脑由高度专门化、相对独立的功能模块组成，不同模块的结合保证认知活动完整。
5. **神经网络说**认为脑功能依赖大量神经元节点之间的连接方式和连接权重，认知活动是复杂网络共同作用的结果。

**【B｜简答扩展】**

定位说强调脑区分工，整体说强调脑的整体作用，二者分别抓住脑功能的两个侧面。机能系统说、模块说和神经网络说进一步指出，复杂心理活动既需要相对专门化的结构，也需要多个区域和网络动态协同。

**【C｜论述收束】**

脑功能研究的发展趋势不是简单否定定位或整体，而是从“单一区域决定功能”转向“专门化脑区参与、动态系统协同、神经网络实现”的综合解释。

# 第三章 条件反射和学习

## 一、学习、反射与高级神经活动基础【一级】【12、19年真题】【选择】

**真题依据**：2012 年考查反射弧；2019 年考查负诱导。考纲明确要求掌握学习的含义和学习理论。

### 押题题目

1. 【名词解释】学习、反射、反射弧、无条件反射或条件反射。
2. 【简答】简述学习的基本特征。
3. 【简答】比较无条件反射与条件反射。
4. 【简答·衍生】简述高级神经活动的基本过程与规律。

### 综合答案

**【A｜名词解释必背】**

1. **学习**是通过练习或经验导致行为或行为潜能发生比较持久改变的过程或结果，也是个体与环境相互作用的过程。
2. **反射**是神经系统的基本活动方式，是有机体对内外环境刺激作出的规律性反应。
3. **反射弧**是实现反射活动的神经结构，包括感受器、传入神经、神经中枢、传出神经和效应器。
4. **无条件反射**是在种系发展中形成并遗传下来的、不学而能的反射。
5. **条件反射**是在无条件反射基础上，经后天学习建立的暂时性神经联系，是高级神经活动的基本方式。

**【B｜简答扩展】**

学习具有三个特征：一是行为或行为潜能发生改变；二是变化比较持久；三是改变由经验或练习引起。无条件反射是先天的、相对固定的，条件反射是后天形成的、具有灵活性，能够帮助个体适应不断变化的环境。

**【C｜高级神经活动扩展】**

高级神经活动的基本过程是兴奋和抑制，二者相互制约并保持平衡。抑制包括先天形成的非条件性抑制和后天形成的条件性抑制。兴奋与抑制还具有扩散、集中和相互诱导规律：由抑制过程引起或加强邻近区域兴奋称为正诱导；由兴奋过程引起或加强邻近区域抑制称为负诱导。专注阅读时对周围刺激“视而不见、听而不闻”，就是负诱导的表现。

## 二、经典条件反射及其基本规律【一级】【11、12、13、17、20、25年真题】【选择/名词解释】

**真题依据**：2011—2013 年反复以生活案例考查；2017 年名词解释；2020 年考查条件刺激；2025 年考查刺激泛化。考纲将其纳入学习理论范围。

### 押题题目

1. 【名词解释】经典条件反射、条件刺激、条件反应、泛化、分化或消退。
2. 【简答】简述经典条件反射的形成过程与基本规律。
3. 【简答·案例】用经典条件反射解释广告、恐惧形成或相似刺激引发反应。
4. 【论述·衍生】论述经典条件反射原理及其在行为形成与改变中的应用。

### 综合答案

**【A｜名词解释必背】**

经典条件反射是指原本不能引起某种反应的中性刺激，与能够自然引起反应的无条件刺激多次配对后，中性刺激转化为条件刺激，并能单独引起条件反应的学习过程，其实质是刺激与刺激之间建立联结。

无条件刺激自然引起无条件反应；中性刺激在配对前不能引起目标反应；配对后，中性刺激成为条件刺激，由其引起的反应称为条件反应。

**【B｜简答扩展：基本规律】**

1. **习得**：条件刺激与无条件刺激反复配对，逐渐形成联结。通常条件刺激先出现并与无条件刺激有适当时间接近，更有利于条件反射建立。
2. **泛化**：与原条件刺激相似的刺激也引起条件反应，刺激越相似，泛化通常越明显。
3. **分化**：经过区别强化后，个体只对特定条件刺激作出反应，而不再对相似刺激反应。
4. **消退**：条件刺激反复出现而不再得到无条件刺激强化时，条件反应逐渐减弱；消退后重新给予强化，反应可能恢复。
5. **二级条件作用**：新的中性刺激与已经形成的条件刺激配对后，也获得引起条件反应的能力。
6. **第一、第二信号系统**：具体刺激构成第一信号系统，人和动物共有；言语、文字等“信号的信号”构成第二信号系统，为人类所特有。

**【C｜论述扩展：案例公式】**

分析案例时可按“配对前—配对中—配对后”作答：先找出无条件刺激和无条件反应，再找出与无条件刺激反复配对的中性刺激，最后说明该刺激如何转化为条件刺激并引起条件反应。例如，儿童吃红辣椒后产生哭闹，后来见到外形相似的番茄也哭闹，说明番茄成为引起条件反应的刺激，并出现了刺激泛化。

**【D｜应用】**

经典条件反射可以解释广告偏好、恐惧形成和情绪联结，也可通过消退、分化和建立新的积极联结来改变不适应反应。

## 三、操作条件反射：强化、惩罚与行为调控【一级】【14、16、18、20、22、23、25、26年真题】【选择/名词解释/论述】

**真题依据**：2014、2016 年名词解释操作性条件反射；2018、2020、2022、2023 年考查强化和惩罚；2025 年名词解释负强化；2026 年论述如何调控行为强度和频率。该知识点为前三章最高优先级。

### 押题题目

1. 【名词解释】操作性条件反射、强化、正强化、负强化、惩罚或强化物。
2. 【简答】比较正强化、负强化、正惩罚和负惩罚。
3. 【简答】简述连续强化与间断强化及主要强化程序。
4. 【论述·真题原型】根据操作性条件反射知识，解释并举例说明如何调控行为的强度和频率。

### 综合答案

**【A｜名词解释必背】**

操作条件反射又称工具性条件反射，是指在一定刺激情境中，个体的某种自发反应产生了能够满足需要的结果，该反应得到强化，因而以后出现频率增加的学习过程。其实质是建立“反应—结果”的联结。

**【B｜简答扩展：强化与惩罚】**

1. **强化**是增加目标行为发生频率的程序。
   - **正强化**：行为之后呈现愉快刺激，使行为增加。例如认真写作业后可以看电视。
   - **负强化**：行为之后撤除厌恶刺激，使行为增加。例如认真写作业后可以不做家务。
2. **惩罚**是降低目标行为发生频率的程序。
   - **正惩罚**：行为之后施加厌恶刺激，使行为减少。例如不认真写作业就增加家务。
   - **负惩罚**：行为之后撤除愉快刺激，使行为减少。例如不认真写作业就不能看电视。

判断时先看行为频率是“增加还是减少”，再看刺激是“呈现还是撤除”：增加行为是强化，减少行为是惩罚；呈现刺激是“正”，撤除刺激是“负”。

**【C｜论述扩展：强化程序】**

1. **连续强化**：每次正确反应都给予强化，行为形成快，但停止强化后也较易消退。
2. **间断强化**：只对部分正确反应给予强化，行为形成较慢，但形成后较难消退。
3. **定比率强化**：达到固定反应次数后强化，如计件工资。
4. **定时距强化**：经过固定时间后强化，如每两周提交一次作业。
5. **变比率强化**：强化所需反应次数不固定，如老虎机赌博。
6. **变时距强化**：两次强化的时间间隔不固定，如等待鱼上钩。

**【D｜行为调控万能落脚】**

运用操作条件反射调控行为时，应先明确需要增加或减少的目标行为，再选择相应后果：增加适应行为可采用正强化或负强化，减少不适应行为可采用正惩罚、负惩罚或停止强化。强化与惩罚应及时、明确、一致，并结合个体需要选择有效刺激。新行为建立初期可连续强化，行为稳定后改用间断强化，以提高行为保持性；同时持续观察行为频率并及时调整方案。

### 铁头tips｜强化与惩罚四格判断

| 行为结果 | 呈现刺激 | 撤除刺激 |
| --- | --- | --- |
| 行为频率增加 | 正强化：呈现愉快刺激 | 负强化：撤除厌恶刺激 |
| 行为频率降低 | 正惩罚：呈现厌恶刺激 | 负惩罚：撤除愉快刺激 |

## 四、经典条件反射与操作条件反射的比较【一级】【简答】

**真题依据**：两类条件反射在 2011—2026 年持续以名词解释、案例和论述题考查；真题解析明确提示可能衍生比较类简答题。

### 押题题目

1. 【简答】比较经典条件反射与操作条件反射。
2. 【简答·案例】判断某一生活案例属于哪类条件反射，并说明理由。
3. 【论述·衍生】论述两类条件反射在行为形成中的共同作用。

### 综合答案

**【A｜简答必背：联系】**

两者都属于后天建立的条件反射，都需要强化，都可能出现习得、消退、泛化和分化等过程，并且在真实行为中经常相互作用。

**【B｜简答主体：区别】**

1. **提出者**：经典条件反射由巴甫洛夫系统研究；操作条件反射由斯金纳系统研究。
2. **联结性质**：经典条件反射建立“刺激—刺激”联结；操作条件反射建立“反应—结果”联结。
3. **反应性质**：经典条件反射多是不随意、反射性的应答；操作条件反射多是个体主动发出的自发行为。
4. **学习者角色**：经典条件反射中个体相对被动；操作条件反射中个体相对主动。
5. **强化时序**：经典条件反射中的无条件刺激通常在目标反应前呈现；操作条件反射中的强化结果在行为后出现。
6. **学习期望**：经典条件反射形成对后续刺激的预期；操作条件反射形成对自身行为后果的预期。

**【C｜案例判断口诀】**

若题目强调“某个刺激预示另一个刺激”，优先判断为经典条件反射；若强调“做出某个行为后得到某种结果，导致行为增减”，优先判断为操作条件反射。

### 铁头tips｜两类条件反射对比表

| 比较维度 | 经典条件反射 | 操作条件反射 |
| --- | --- | --- |
| 代表人物 | 巴甫洛夫 | 斯金纳 |
| 核心联结 | 刺激—刺激 | 反应—结果 |
| 反应性质 | 不随意、应答性 | 相对主动、操作性 |
| 学习者角色 | 相对被动 | 相对主动 |
| 强化时序 | 目标反应前出现关键刺激 | 行为后出现结果 |
| 判断抓手 | 一个刺激预示另一个刺激 | 行为后果决定行为增减 |

## 五、学习的认知理论【二级】

**考纲依据**：考纲要求掌握学习理论；现有华东真题未直接考查顿悟学习、认知地图或潜伏学习，按二级处理。

### 押题题目

1. 【名词解释】顿悟学习、认知地图或潜伏学习。
2. 【简答】简述格式塔的顿悟学习理论。
3. 【简答】简述托尔曼的目的行为学习理论。
4. 【论述·衍生】比较行为主义学习观与认知学习观。

### 综合答案

**【A｜名词解释必背】**

1. **顿悟学习**：苛勒等格式塔心理学家认为，学习是重新组织问题情境并突然领悟其内在关系的过程，而非单纯依靠试误逐步形成。
2. **认知地图**：个体根据过去经验，在头脑中形成的有关环境空间关系的内部表征。
3. **潜伏学习**：学习已经发生，但暂时没有表现为外显行为，待出现目标或强化条件后才表现出来的学习。

**【B｜简答扩展】**

托尔曼认为学习不是刺激与反应的直接联结，个体行为具有目的性，需求、认知、信念和行为空间等中介变量会影响行为。白鼠迷津实验表明，个体能够主动整合环境信息、形成认知地图；即使没有立即强化，也可能发生潜伏学习。

**【C｜论述收束】**

行为主义强调外部刺激、反应和强化，认知理论则强调个体对情境关系的理解、内部表征和目标。两种理论分别揭示学习的外部条件与内部加工，共同说明学习并非单一机制。

## 六、观察学习【一级】【14、24年真题】【名词解释/选择】

**真题依据**：2014 年名词解释观察学习；2024 年考查观察学习四阶段。考纲将其纳入学习理论范围。

### 押题题目

1. 【名词解释】观察学习。
2. 【简答】简述观察学习的四个过程。
3. 【简答】简述影响观察学习的因素。
4. 【论述·衍生】用观察学习理论解释榜样示范如何影响行为。

### 综合答案

**【A｜名词解释必背】**

观察学习由班杜拉提出，是指个体通过观察榜样的行为及其结果，形成该行为的认知表征，并在适当条件下表现出来的学习，也称替代学习。个体并非被动模仿，而会结合已有知识和经验对榜样信息进行分析、比较和评价。

**【B｜简答扩展：四个过程】**

1. **注意过程**：观察者首先关注榜样及其行为，受榜样吸引力、行为显著性和观察者经验等影响。
2. **保持过程**：把榜样行为编码为言语或表象等符号形式并存入记忆。
3. **动作复现过程**：把记忆中的符号表征转化为自己的实际行为，并通过练习不断修正。
4. **动机过程**：判断是否值得表现该行为，受到外部强化、替代强化和自我强化影响。

**【C｜论述扩展】**

观察学习效果取决于榜样、观察者和行为结果。榜样越有吸引力、权威性和示范价值，观察者认知能力与知识经验越充分，榜样行为获得的奖赏越明显，观察学习越容易发生。因此，教育和行为干预中应选择清晰、积极、可模仿的榜样，并及时反馈和强化观察者的正确复现。

## 七、补充内容：格雷的强化敏感性理论【二级】【21年真题】

**真题依据**：2021 年论述题直接要求运用格雷强化敏感性理论解释冲动者为什么对奖励更敏感。该内容不在导论速背前三章和现行考纲的明确条目中，作为真题补丁按二级处理。

### 押题题目

1. 【名词解释】强化敏感性理论、行为趋近系统或行为抑制系统。
2. 【简答】简述行为趋近系统与行为抑制系统。
3. 【论述·真题原型】根据格雷强化敏感性理论，分析冲动者为什么对奖励更敏感。

### 综合答案

**【A｜名词解释必背】**

格雷的强化敏感性理论认为，中枢神经系统中存在对奖励与惩罚信号具有不同敏感性的子系统，这些系统通过强化效应调节人的行为和动机，并造成稳定的人格差异。

**【B｜简答扩展】**

行为趋近系统与冲动性相关，对奖励、非惩罚等信号较敏感，容易引发趋近行为和积极情绪；行为抑制系统与焦虑相关，对惩罚、非奖励和新奇信号较敏感，容易引发警觉、抑制和回避行为。

**【C｜论述应用】**

个体在冲动性与焦虑维度上的差异，反映了行为趋近系统和行为抑制系统活动强度的不同。高冲动个体的行为趋近系统更敏感，奖励线索更容易引起注意、积极情绪和趋近动机，因此他们比低冲动个体更容易追求即时奖励，并可能低估延迟后果或惩罚风险。
