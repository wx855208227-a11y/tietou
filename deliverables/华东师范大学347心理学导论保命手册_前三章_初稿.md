# 第一章 心理学研究的对象、方法及其学科发展

## 一、心理学的含义、诞生与研究对象【一级】

### 押题题目

1. 【名词解释】心理学。
2. 【简答】简述心理学的研究对象。
3. 【简答】简述科学心理学诞生的标志及重要历史事件。
4. 【论述】论述心理过程与人格的构成及其关系。

### 综合答案

**【题①②④】** ++心理学是研究人的行为和心理活动规律的中间科学，其研究对象主要包括心理过程和人格。++

**【题③】** 1879 年，冯特在德国莱比锡大学建立世界上第一个心理学实验室，标志着科学心理学的诞生。

1. **【题②④】心理过程**：包括认知、情绪情感和意志过程。认知过程负责感觉、知觉、记忆、思维和想象等信息加工；情绪情感过程是人脑对客观事物是否满足需要而产生的态度体验；意志过程是个体自觉确定目的、克服困难并实现目的的过程。
2. **【题②④】人格**：包括心理动力和心理特征。心理动力体现个体对活动对象的选择和趋向；心理特征是人在心理活动中形成并稳定表现出来的独特心理特点。
3. **【题②④】二者关系**：心理过程是动态展开的心理活动，人格是稳定的心理倾向与特征；人格影响心理过程的方向和方式，心理过程的反复进行又会塑造人格。
4. **【题③】发展线索**：1890 年詹姆斯出版《心理学原理》，1917 年陈大齐建立中国第一个心理学实验室。心理学由此逐渐摆脱纯思辨研究，走向实验化、科学化和应用化。

**【题④】** ++因此，理解心理学既要把握心理过程与人格的相对分工，也要看到二者在现实行为中的统一。++

## 二、现代心理学的主要流派【一级】

### 押题题目

1. 【名词解释】构造主义、机能主义、行为主义、格式塔心理学、精神分析、人本主义或认知心理学。
2. 【简答】简述行为主义的主要观点及评价。
3. 【简答】比较构造主义与机能主义。
4. 【简答】比较行为主义、精神分析和人本主义的人性观与研究对象。
5. 【论述】论述现代心理学主要流派的发展及其贡献。

### 综合答案

**【题⑤】** ++现代心理学各流派围绕“研究什么、怎样研究以及如何理解人”形成不同观点，既相互争论，又共同推动心理学发展。++

1. **【题①③⑤】构造主义**：冯特、铁钦纳以意识或直接经验为对象，主张用内省法把意识分析为感觉、意象和激情等元素。它推动心理学走上实验道路，但主观性强、重复性较差。
2. **【题①③⑤】机能主义**：詹姆斯、杜威和安吉尔关注心理活动的适应功能，认为意识具有连续性和选择性。它推动心理学面向教育、工业等实际生活，但理论体系较为松散。
3. **【题①②④⑤】行为主义**：华生、斯金纳和班杜拉强调研究可观察行为及环境与行为的关系，主要采用实验法。它促进心理学客观化和自然科学化，但早期观点忽视意识和内部心理过程。
4. **【题①⑤】格式塔心理学**：韦特海默、苛勒和考夫卡强调心理的结构性与整体性，认为整体不能还原为部分之和，对知觉和认知研究影响深远。
5. **【题①④⑤】精神分析**：弗洛伊德等强调无意识、早期经验和内在冲突对人格与行为的作用，常用自由联想和梦的解析。它重视内部动力，但部分观点过分强调本能且难以客观验证。
6. **【题①④⑤】人本主义**：马斯洛和罗杰斯关注健康人格、人的潜能、自由选择与自我实现，被称为心理学“第三势力”。它凸显人的尊严与主动性，但部分概念和方法不够精确。
7. **【题①⑤】认知心理学**：奈瑟尔、纽维尔和西蒙等研究信息加工及内部认知机制，常用反应时、口语报告和计算机模拟。它使内部心理过程重新成为科学研究对象，并推动认知神经科学发展。

**【题⑤】** ++现代心理学由单一学派竞争走向多种视角互补，研究对象从意识、行为和无意识扩展到健康人格与认知加工，研究方法也日益客观化、多元化。++

## 三、观察法、相关研究法与实验法【一级】

### 押题题目

1. 【名词解释】观察法、相关研究法或实验法。
2. 【简答】比较观察法、相关研究法和实验法的优缺点。
3. 【简答】简述实验研究中的自变量、因变量和控制变量。
4. 【论述】如何根据研究目的选择心理学研究方法？

### 综合答案

**【题②④】** ++观察法、相关研究法和实验法的核心差异，在于研究者对变量的控制程度以及能否作出因果推断。++

1. **【题①②④】观察法**：在自然情境中有计划地观察并记录心理和行为。其优势是资料真实、生态效度较高；局限是控制程度低，易受观察者偏差和情境干扰，不能确定因果关系。
2. **【题①②④】相关研究法**：考察两个或多个变量关联的方向和程度，通常用 -1.00 至 +1.00 的相关系数表示。它可以量化关系并用于预测，但相关不等于因果，可能存在方向不明或第三变量问题。
3. **【题①②③④】实验法**：研究者操纵条件并观察结果，以检验变量之间的因果关系。它控制严密、可以重复，但人工情境可能降低外部效度，也不适合研究所有复杂行为。
4. **【题③④】实验变量与控制**：自变量是实验者主动操纵的变量，因变量是被观察和测量的结果变量，无关变量是可能干扰结果的其他因素。随机分配主要用于平衡个体差异，提高内部效度。
5. **【题④】方法选择**：研究自然发生的行为优先用观察法；考察关系和预测优先用相关法；需要检验因果且能够操纵变量时优先用实验法，复杂问题还可采用多方法相互验证。

**【题②④】** ++因此，心理学研究不存在适用于所有问题的单一最佳方法，应根据研究目的、控制条件和真实性要求进行选择。++

## 四、测验法、信效度与投射法【二级】

### 押题题目

1. 【名词解释】测验法、信度、效度或投射法。
2. 【简答】简述心理测验的基本要求。
3. 【简答】比较信度与效度。

### 综合答案

**【题②③】** ++测验法通过标准化工具度量个体差异，一项合格的心理测验至少要做到结果稳定，并且真正测到目标心理品质。++

1. **【题①②】测验法**：运用标准化测验工具，度量个体之间或个体内部反应差异的方法。
2. **【题①②③】信度**：测量结果的一致性、稳定性或可靠性，回答“测得是否稳定”。
3. **【题①②③】效度**：测验能够真实测量目标心理变量的程度，回答“是否测到了想测的内容”。信度是效度的必要条件，但信度高不等于效度必然高。
4. **【题①②】投射法**：向被试呈现意义模糊、结构不明确的刺激，要求其自由反应，再分析其内在动机、冲突和情绪，如罗夏墨迹测验和主题统觉测验。它有助于了解深层人格动力，但解释主观性较强。

**【题②③】** ++因此，心理测量应兼顾标准化、信度和效度，投射结果还必须由专业人员结合其他资料综合判断。++

## 五、心理学的主要分支【二级】

### 押题题目

1. 【简答】简述心理学的定义，并至少写出三个分支，每个分支提出一个相关科学问题。
2. 【简答】简述心理学主要基础分支与应用分支。
3. 【论述】论述心理学分支体系及其社会价值。

### 综合答案

**【题①②③】** ++心理学是研究人的行为和心理活动规律的中间科学；随着研究对象和社会需要扩展，逐渐形成基础研究与实际应用相互联系的分支体系。++

1. **【题①②③】生理心理学**研究心理活动的生理机制，例如：学习和记忆涉及哪些神经机制？
2. **【题①②③】发展心理学**研究个体毕生心理发展的规律，例如：儿童言语发展的年龄特征是什么？
3. **【题①②③】教育心理学**研究教育过程中教与学的心理规律，例如：怎样提高学生的学习效果？
4. **【题①②③】社会心理学**研究社会情境中个体和群体的心理与行为，例如：哪些因素影响人际关系？
5. **【题①②③】临床心理学**运用心理学原理评估、诊断和干预心理问题，例如：怎样有效评估并干预焦虑？

**【题③】** ++这些分支从生理基础、毕生发展、教育活动、社会关系和心理健康等层面共同解释人的心理与行为，并为教育、医疗和社会治理提供科学依据。++

# 第二章 心理和行为的生物学基础

## 一、神经元、神经冲动与突触【一级】

### 押题题目

1. 【名词解释】神经冲动、静息电位、动作电位或突触。
2. 【简答】简述神经冲动的传导方式及特点。
3. 【论述】论述神经元内与神经元之间的信息传递过程。

### 综合答案

**【题②③】** ++神经信息在单个神经元内主要以电信号传导，在神经元之间主要通过突触进行化学传递。++

1. **【题①②③】静息电位**：神经元未受刺激时，膜内外呈外正内负的电位差，主要与钾离子外流有关。
2. **【题①②③】动作电位与神经冲动**：神经元受到足够刺激后，膜电位迅速反转为外负内正，主要与钠离子内流有关，并服从“全或无”规律。动作电位沿轴突连续传播，形成神经冲动。
3. **【题①②③】突触传递**：突触由突触前膜、突触间隙和突触后膜构成。神经冲动到达末梢后促使神经递质释放，递质穿过突触间隙并作用于突触后膜，因此化学突触传递通常具有单向性。
4. **【题②③】完整链条**：神经信息依次经历“膜电位变化—轴突传导—递质释放—突触后膜反应”，再由下一个神经元继续加工和传递。

**【题③】** ++电传导保证信息快速到达神经末梢，化学传导使神经元能够组成复杂网络，两者共同构成人脑信息加工的生理基础。++

## 二、神经系统的构成与功能【二级】

### 押题题目

1. 【名词解释】周围神经系统、中枢神经系统或自主神经系统。
2. 【简答】简述神经系统的构成。
3. 【简答】比较交感神经系统与副交感神经系统。
4. 【论述】论述周围神经系统与中枢神经系统如何协同调节行为。

### 综合答案

**【题②④】** ++神经系统通常分为周围神经系统和中枢神经系统，二者分别承担信息传递与信息整合，并共同调节人的心理和行为。++

1. **【题①②④】周围神经系统**：包括躯体神经系统和自主神经系统。躯体神经联系感觉器官、骨骼肌与中枢；自主神经主要调节内脏和腺体活动，通常不受主观意志直接控制。
2. **【题①②③④】自主神经系统**：包括交感神经和副交感神经。交感神经提高机体唤醒水平，使个体应对环境变化；副交感神经帮助机体恢复并维持安静状态，二者相互制约、协调活动。
3. **【题①②④】中枢神经系统**：包括脊髓和脑。脊髓既是简单反射中枢，也是脑与周围神经之间的信息通道；脑承担感觉整合、运动调节、情绪和高级认知等功能。
4. **【题④】协同过程**：周围神经把内外刺激传入中枢，中枢分析、整合信息并形成指令，再由周围神经把指令传到效应器并产生行为。

**【题④】** ++周围与中枢神经系统共同构成“输入—加工—输出”的完整调节系统，任何复杂行为都依赖两者协同。++

## 三、大脑皮层主要区域及其功能【一级】

### 押题题目

1. 【名词解释】布洛卡区、威尔尼克区或皮层联合区。
2. 【简答】简述大脑皮层感觉区、运动区、言语区和联合区的功能。
3. 【简答】根据患者的语言表现判断受损脑区。
4. 【论述】论述大脑皮层功能分区及其协同关系。

### 综合答案

**【题④】** ++大脑皮层具有相对明确的功能分区，但复杂心理活动并非由单一区域独立完成，而是依赖多个脑区协同。++

1. **【题②④】感觉区**：躯体感觉区主要位于中央后回，具有左右交叉和身体部位大体倒置的投射特点；视觉区位于枕叶，听觉区位于颞叶。
2. **【题②④】运动区**：主要位于中央前回，负责支配和调节躯体运动，身体部位的皮层代表区也大体呈倒置排列。
3. **【题①②③④】言语区**：布洛卡区参与言语产生，受损可出现表达不流畅的运动性失语；威尔尼克区参与言语理解，受损可出现表达流畅但理解困难的感觉性失语；角回与阅读理解有关，书写区参与书面表达。
4. **【题①②④】联合区**：不直接承担单一感觉输入或简单运动输出，主要负责感觉整合、运动计划和高级认知。前额叶对选择性注意、工作记忆、冲突解决和抑制控制尤其重要。
5. **【题③】案例判断**：先判断患者“能否理解”，再判断“能否流畅表达”。理解较好但表达困难提示布洛卡区异常；表达流畅却内容混乱、理解困难提示威尔尼克区异常。

**【题④】** ++因此，回答脑区功能题既要写清局部功能定位，也要强调神经网络和脑区协同，避免把复杂行为简单归因于单一脑区。++

## 四、大脑两半球的功能分工【一级】

### 押题题目

1. 【名词解释】大脑半球单侧化。
2. 【简答】简述斯佩里裂脑实验的结论。
3. 【论述】论述大脑两半球的功能分工与协同关系。

### 综合答案

**【题①②③】** ++大脑半球单侧化是指左右半球在某些心理功能上存在相对优势分工的现象，斯佩里的裂脑研究提供了重要证据。++

1. **【题②③】实验条件**：裂脑患者连接两半球的胼胝体被切断，呈现给一个半视野的信息主要由对侧半球加工，难以正常传递到另一半球。
2. **【题②③】左半球优势**：通常在言语、逻辑分析和顺序加工方面相对占优势。
3. **【题②③】右半球优势**：通常在空间知觉、图形加工和整体加工方面相对占优势。
4. **【题③】功能协同**：正常情况下，胼胝体等结构保证两半球交换信息，语言、记忆、情绪和问题解决都需要两半球共同参与。

**【题③】** ++半球单侧化是相对分工而非绝对割裂，完整心理活动建立在优势分工与信息协同的统一之上。++

## 五、丘脑、下丘脑与边缘系统【一级】

### 押题题目

1. 【名词解释】丘脑、下丘脑、边缘系统、海马或杏仁核。
2. 【简答】简述边缘系统主要结构及功能。
3. 【简答】分析海马损伤或杏仁核功能异常可能造成的表现。
4. 【论述】论述皮层下结构在感觉、动机、情绪和记忆中的作用。

### 综合答案

**【题②④】** ++皮层下结构通过感觉中继、内稳态调节以及情绪和记忆加工，共同为复杂心理活动提供生理基础。++

1. **【题①④】丘脑**：是重要的感觉信息中转站，除嗅觉外，多种感觉信息在到达大脑皮层前需经其加工和传递。
2. **【题①④】下丘脑**：调节内分泌、体温、摄食、饮水等基本生理需要，并参与动机和情绪活动，是维持内稳态的重要中枢。

5. **【题①②③④】杏仁核**：参与情绪识别、情绪控制和情绪记忆，尤其与威胁和恐惧加工有关；相关功能异常可造成恐惧反应或情绪记忆异常。

**【题④】** ++丘脑、下丘脑和边缘系统并非孤立工作，而是通过神经网络把感觉、需要、情绪和记忆整合起来并共同调节行为。++

**【题②④】** ++从反射到学习，个体把先天神经活动与后天经验结合起来，从而更灵活地适应不断变化的环境。++

## 二、经典条件反射及其基本规律【一级】

### 押题题目

1. 【名词解释】经典条件反射、条件刺激、条件反应、泛化、分化或消退。
2. 【简答】简述经典条件反射的形成过程与基本规律。
3. 【简答】用经典条件反射解释广告、恐惧形成或相似刺激引发反应。
4. 【论述】论述经典条件反射原理及其在行为形成与改变中的应用。

### 综合答案

**【题①②④】** ++经典条件反射是中性刺激与无条件刺激反复配对后，中性刺激转化为条件刺激并单独引起条件反应的学习过程，其实质是建立“刺激—刺激”联结。++

1. **【题①②④】形成过程**：无条件刺激自然引起无条件反应；中性刺激在配对前不能引起目标反应；多次配对后，中性刺激成为条件刺激，由它引起的反应称为条件反应。
2. **【题①②④】习得**：条件刺激与无条件刺激反复配对并逐渐形成联结。通常条件刺激先出现，且二者在时间上适当接近，更有利于条件反射建立。
3. **【题①②④】泛化与分化**：泛化是相似刺激也引起条件反应；分化是经过区别强化后，个体只对特定条件刺激反应。二者分别体现反应范围的扩展与精确化。
4. **【题①②④】消退与恢复**：条件刺激反复出现而不再伴随无条件刺激时，条件反应逐渐减弱；消退后重新强化，反应还可能恢复。
5. **【题①②④】二级条件作用与信号系统**：新的中性刺激与已有条件刺激配对后，也可获得引起反应的能力。具体刺激构成第一信号系统；言语、文字等“信号的信号”构成第二信号系统，为人类所特有。
6. **【题③④】案例公式**：按“配对前—配对中—配对后”作答，依次找出无条件刺激、无条件反应、中性刺激、条件刺激和条件反应，再判断是否出现泛化、分化或消退。
7. **【题④】实际应用**：该原理可以解释广告偏好、恐惧形成和情绪联结，也可以通过消退、分化或建立新的积极联结来改变不适应反应。

**【题④】** ++经典条件反射说明环境中的刺激可以通过联结获得新的信号意义，其规律既能解释行为形成，也能指导行为矫正。++

## 三、操作条件反射：强化、惩罚与行为调控【一级】

### 押题题目

1. 【名词解释】操作性条件反射、强化、正强化、负强化、惩罚或强化物。
2. 【简答】比较正强化、负强化、正惩罚和负惩罚。
3. 【简答】简述连续强化与间断强化及主要强化程序。
4. 【论述】根据操作性条件反射知识，解释并举例说明如何调控行为的强度和频率。

### 综合答案

**【题①④】** ++操作条件反射是个体自发行为受到结果影响而改变发生频率的学习过程，其实质是建立“反应—结果”联结。++

1. **【题①②④】强化与惩罚**：强化使行为频率增加，惩罚使行为频率降低。正强化是在行为后呈现愉快刺激；负强化是在行为后撤除厌恶刺激；正惩罚是在行为后呈现厌恶刺激；负惩罚是在行为后撤除愉快刺激。
2. **【题②④】判断顺序**：先看行为是增加还是减少，再看刺激是呈现还是撤除。增加行为属于强化，减少行为属于惩罚；呈现刺激为“正”，撤除刺激为“负”。
3. **【题③④】强化程序**：连续强化是每次正确反应都强化，行为形成快但也易消退；间断强化只强化部分反应，形成较慢但更耐消退。间断强化又包括定比率、定时距、变比率和变时距四种程序，分别依据固定或变化的反应次数、时间间隔给予强化。
4. **【题④】行为调控步骤**：先把目标行为界定为可观察、可记录的行为，再确定需要增加还是减少；增加适应行为可用正强化或负强化，减少不适应行为可用正惩罚、负惩罚或停止强化。强化与惩罚应及时、明确、一致，并根据个体需要选择真正有效的后果。
5. **【题④】保持与调整**：新行为建立初期可连续强化，行为稳定后转为间断强化，以增强保持性；同时持续记录行为频率，根据效果及时调整刺激、频率和程序。

**【题④】** ++操作条件反射调控行为的关键，不是简单“奖励或处罚”，而是让明确、及时、一致的行为后果稳定改变目标行为的发生频率。++

### 综合答案

**【题①③】** ++经典条件反射和操作条件反射都属于后天学习，都可能出现习得、消退、泛化和分化，但二者建立的联结和行为后果不同。++

1. **【题①③】代表人物**：经典条件反射由巴甫洛夫系统研究；操作条件反射由斯金纳系统研究。
2. **【题①③】联结性质**：经典条件反射建立“刺激—刺激”联结；操作条件反射建立“反应—结果”联结。

5. **【题①③】关键时序**：经典条件反射中的无条件刺激通常在目标反应前出现；操作条件反射中的强化或惩罚结果在行为后出现。
6. **【题①③】学习期望**：经典条件反射形成对后续刺激的预期；操作条件反射形成对自身行为后果的预期。
7. **【题②】案例判断**：题目强调“一个刺激预示另一个刺激”时，优先判断为经典条件反射；强调“行为之后出现结果并使行为增减”时，优先判断为操作条件反射。

**【题③】** ++真实行为往往同时受到刺激联结和行为后果影响，因此两类条件反射既有明确区别，也会在行为形成与改变中共同作用。++

## 七、格雷的强化敏感性理论【二级】

### 押题题目

1. 【名词解释】强化敏感性理论、行为趋近系统或行为抑制系统。
2. 【简答】简述行为趋近系统与行为抑制系统。
3. 【论述】根据格雷强化敏感性理论，分析冲动者为什么对奖励更敏感。

### 综合答案

**【题①②③】** ++格雷的强化敏感性理论认为，中枢神经系统存在对奖励和惩罚信号敏感性不同的子系统，这些系统通过强化效应调节行为和动机，并形成稳定的人格差异。++

1. **【题①②③】行为趋近系统**：与冲动性相关，对奖励和非惩罚信号较敏感，容易引发注意、积极情绪和趋近行为。
2. **【题①②③】行为抑制系统**：与焦虑相关，对惩罚、非奖励和新奇信号较敏感，容易引发警觉、抑制和回避行为。
3. **【题③】个体差异**：冲动性和焦虑差异反映了两个系统活动强度不同。高冲动者的趋近系统更敏感，奖励线索更容易引起注意和趋近动机，因此更偏好即时奖励，并可能低估延迟后果或惩罚风险。

**【题③】** ++因此，冲动者对奖励更敏感，并非单纯缺乏自控，而是其奖励趋近系统对强化线索反应更强。++
