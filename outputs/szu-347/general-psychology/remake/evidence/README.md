# 深圳大学347普通心理学一本通重制：证据层

## 目的

本目录先固定题型、真题、考纲和教材证据，再据此校订现有一本通。现有一本通是可用底稿，不是内容权威；每个条目按`保留/微调/重写/合并/移动/补充/删除`处理。

## 权威材料

1. 彭聃龄《普通心理学》第6版：正文结构、术语、定义、关键词、关键关系和印刷页码的主要依据。
2. 深圳大学2019—2026年347初试真题册：目标院校题型、真实命中和一级判断的首要依据。
3. 深圳大学2026年官方考纲：确定必须覆盖的知识簇；“心理学基础”共10节、67个终端条目。
4. 312和头部347公共题库：只用于辅助判断可考性和强二级，不作为深大真题标注。
5. 其他正式出版教材或学术文献：仅在考纲/真题要求而指定教材缺项时，用作可追溯补充来源。

## 层级口径

- 一级：按名词解释、简答、论述、案例等主观题完整输出，属于必背内容。深大主观题直接命中的最小答案点默认一级。
- 二级：做到准确再认，主要服务深大实际存在的单选、判断、填空等客观题。深大客观题命中默认至少二级，不机械升一级。
- 三级：保留最低限度识别，用于低概率冷门题；2026考纲明确覆盖的非中国背景条目不得降为三级。
- 强二级：成品正文仍标二级，在审核表单列，由人工决定是否升一级。

## 考纲口径

- 67个终端条目必须100%实质覆盖，不能用相同标题替代正文覆盖。
- 宽泛条目继续拆成定义、构成、机制、分类、特点、程序、优缺点、应用或比较等最小可考单元。
- 考纲决定“必须写到什么”；真题、教材核心性和题型适配决定“写到什么程度、标哪一级”。
- 考纲直接覆盖且非中国背景的知识点原则上至少二级，但并非全部一级。

## 当前风险

- 教材PDF共589页且无文本层，后续人名、定义、实验、页码必须回原页复核，不能用固定PDF偏移推算印刷页码。
- 真题册属于机构汇编/回忆稿，不能把解析文字当作官方评分标准；残缺题干和科目归属须单独标低置信度。
- 实验设计题若只是借用普心题材，不能据此把相应普心知识点自动升为一级。
- 智力测量、人格测评等跨科内容须保留主归科目、次归科目和归属理由，防止重复真题标注。

## 证据文件

- `exam_profile.tsv`：2019—2026年题型变化及普心命中概况。
- `outline_coverage.tsv`：67个考纲终端条目的教材定位、覆盖状态和等级下限。
- `question_evidence.tsv`：逐题/逐知识点的深大普心真题证据；主归普心的交叉题同样收录，避免逐题表漏项。
- `cross_subject_evidence.tsv`：人格测评/心理测量等交叉题的主归、次归、理由和去重标注策略；它是跨科归属与成品标注的权威记录。
- `level_decisions.tsv`：证据层复审通过后生成，用于记录知识点层级、依据和正文准备方式。
- `strong_secondary_review.tsv`：仅列需要主管升降级判断的强二级。
- `baseline_audit.md`：教材与现有一本通的结构差异、代表性问题及逐条校订边界。
