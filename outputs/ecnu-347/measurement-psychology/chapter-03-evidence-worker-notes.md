## 5. 层级建议

### 一级

1. 智龄、比率智商和离差智商：含公式、缺陷、优势、韦氏/斯比相关应用。
2. 比奈-西蒙、斯坦福-比奈与智商概念发展：1905、年龄量表、推孟和智商概念。
3. SB4 理论框架和特点：流体/晶体理论 + 认知能力测验、三层次模型、四领域、适应性测验、词汇定线、年龄跨度和分数体系。
4. 韦克斯勒儿童智力量表：发展、言语/操作结构、WISC-III/IV/V 主要结构、离差智商、全量表和指数分数。
5. 瑞文测验：非文字、渐进矩阵、受文化语言限制小、可个别/团体施测。
6. 现代智力因素分析理论：斯皮尔曼、瑟斯顿、吉尔福特、卡特尔、弗农、CHC。
7. 智力认知理论：斯腾伯格三重理论、PASS 模型。

### 二级

1. 什么是智力测验：定义、标准化量表、行为样组、测量过程。
2. 智力分布和分类标准：推孟、韦克斯勒分类和常态分布。
3. SB5 变化和特色。
4. WISC-R、WISC-V 细部内容和分测验说明。
5. KABC/KABC-II：与 PASS/CHC 的理论联系。
6. 智力测验的价值、优点、教育应用和局限性。
7. 智力测验新发展：元认知测量、智力培训程序、组合测量工具评价。

### 三级

1. 各量表版本年份、出版机构、修订者等细节，除真题直接相关外不宜展开。
2. SB4/SB5、WISC、KABC 分测验逐项长描述可压缩为表格或关键词。
3. 智力分类表英文标签、比例数字可作为表格，不必全文背诵化。
4. 传统智商测验批评中的人物叙述和长篇论证可压缩。

### 强二级

1. WISC-IV/WISC-V 指数量表和能力因素：华东2024 + 312 公共题库支持。
2. 瑞文测验优势和适用范围：华东2020 + HF 多源支持，可按一级主题、强二级细节处理。
3. KABC 与 PASS/CHC 理论基础：教材篇幅较大，HF 零散覆盖。
4. 智力测验局限和斯腾伯格批评：考纲列发展与局限，教材有完整第五节。
