# 华东导论前三章：自然答题单元重构表

## 一、重构原则

- 保留速背手册的三章顺序，以自然答题逻辑而非原小节边界划分综合答案。
- 同一套评分点可以自然回答多个问法时合并；需要不同定义、不同论证链或不同容量时拆分。
- 题型和容量继续以 `analysis/华东导论前三章_命题容量与表述证据.md` 为证据底表。
- 例句只在能帮助辨析或应用时添加，统一标为 `（例如：……；可替换）`。
