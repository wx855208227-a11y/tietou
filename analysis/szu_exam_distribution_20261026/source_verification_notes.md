# 深大四科真题章节复核：教材核证记录

## 资料范围

- 《普通心理学》第6版：589个PDF页，扫描版，无可用全文文本层。
- 《实验心理学》第2版：685个PDF页，扫描版，无可用全文文本层。
- 《心理与教育测量》第4版：367个PDF页，扫描版，无可用全文文本层。
- 《现代心理与教育统计学》第5版：463个PDF页，绝大多数正文页有文本层。
- 深大普心一本通用户上传DOCX：作为检索辅助；发生冲突时仍以教材PDF为准。

扫描教材按每批2—3页做本地OCR，未批量向模型载入页面图像。

## 关键争议的教材位置

- 研究伦理/知情同意：实验心理学第一章，印刷页38—40。第一章目录直接列“实验心理学的研究伦理”；正文讲知情同意权、退出自由和免遭伤害。因此2019单选5主归实验第一章。
- 归因及其对情绪的影响：普通心理学第九章，印刷页346—347。教材在“动机的归因理论”下定义归因、区分内外因，并说明不同归因产生满意、自豪、内疚、羞愧等情绪。因此2026简答3主归动机，不归情绪。
- 外部归因、海德归因理论：同在普通心理学第九章印刷页346，纳入普心动机章。
- 基本归因错误/基本归因偏差：深大普心一本通未检出；教材第九章该处只讲成败归因、内外因及韦纳三维度，不等同于社会知觉中的基本归因偏差，继续按四本教材外处理。
- 马斯洛与人格发展：普通心理学第十二章印刷页432在人本主义人格理论下讲马斯洛自我实现理论、自我实现者特征；第九章也讲自我实现需要。题干若明确问“人格发展”，主归第十二章并标中置信。
- 行为遗传学方法/双生子设计：普通心理学第十一章印刷页416在“影响智力的因素”中列双生子、收养与追踪研究思路；主归智力章，第十四章遗传与环境为交叉内容。
- 横断/纵向研究设计：普通心理学第十四章印刷页495—499讲个体发展、横向/纵向观察视角及遗传环境，但未形成横断/纵向研究设计定义、优缺点的直接作答条目。相关三题不纳入四本教材分章统计，并在内部复核表保留判断。
- 构念：心理与教育测量第五章印刷页64—66在结构效度部分定义“构想或结构”为抽象、假设性的心理概念或特质；将题干“构念”视为同义术语，主归测量效度并标中置信。
- 标准误与标准差：统计教材在第六章抽样分布中定义标准误并说明它与总体标准差、样本容量的关系，第七章再用于参数估计；按概念主讲位置归第六章。
- ABAB设计：实验心理学第二章印刷页82—84的小样本设计部分以“ABA设计”为标题，并用A-B-A-B四阶段图示完整反转程序；归第二章并保留术语差异提示。

## 逐题归类原则

1. 先判断题目要求调用的核心理论或方法，再查其在指定教材中的集中讲授位置。
2. 题干中的应用情境、结果变量或干扰项不作为章节关键词。例如“归因如何影响情绪”的核心仍是归因理论。
3. 每题只设一个主章节用于统计；确有跨章时记录次要章节和置信度。
4. 四本教材没有直接作答条目的题不进入用户版工作簿；全部255题仍保留在内部复核TSV中，避免漏审。
