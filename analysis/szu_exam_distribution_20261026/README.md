# 深大历年真题章节题型分布统计

## 统计口径

- 来源：HF `深圳大学/真题/汇总/深大初试真题册.docx` 的原题部分，年份为 2019—2026。
- 一道题按一个顶层题号计数；案例题中的（1）（2）等子问附属于该题，不拆分重复计数。
- 每题只指定一个“主科目”和一个“主章节”参与汇总，保证总数与原卷题数一致。
- 跨科目或跨章节考点另记在“次要考点”，不增加题目数量。
- 章节名称优先采用深大四本指定教材的章名；教材未覆盖的旧题明确标为“跨教材拓展”，不强行归入错误章节。

## 教材证据

- 《普通心理学（第6版）》：PDF 第 9—12 页目录。
- 《实验心理学（第2版）》：PDF 第 11—19 页目录。
- 《心理与教育测量（第4版）》：PDF 第 7—9 页目录。
- 《现代心理与教育统计学（第5版）》：PDF 第 10—13 页目录（文本层）。

扫描教材仅在本地按页提取目录；没有向模型批量加载教材页面。

## 输出文件

`analysis/深圳大学2019-2026历年真题_科目章节题型分布表.xlsx` 包含：

- `统计说明`：统计口径与逐年题型总数；
- `逐题明细`：255道原题的唯一归类与归类依据；
- `四维长表`：年份×科目×章节×题型的非零计数；
- `完整矩阵`：所有年份×所有教材章节，包含零值；
- `有题汇总`：剔除全零行后的重点分布；
- `年度科目汇总`、`章节目录`、`核对结果`。

所有汇总合计均为255，2019—2026各年题数依次为103、22、22、22、18、25、19、24。

## 用户样例版

用户补充的样例采用“每门科目一张表，左侧按章节累计、右侧按年份累计”的简洁结构。对应输出为：

`analysis/深圳大学2019-2026历年真题分布表_简明版.xlsx`

- 工作表保留 `统计`、`实验`、`测量`、`普心` 四张汇总表，并增加一张可筛选的 `真题明细`；
- 题型按样例的简化逻辑合并为“选择/判断/填空”“名词解释”“简答/论述题”“实验/案例/综合题”；
- `真题明细` 可按年份、科目、教材章节和题型筛选，直接查看完整真题原文；
- 按用户要求删除超出四本教材的社会、变态与咨询、管理与组织及跨科目综合题：不统计、不展示；
- 四本教材范围内合计215道，逐年题量为83、21、18、17、16、19、17、24。
