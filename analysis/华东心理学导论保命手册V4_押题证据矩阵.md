# 华东心理学导论保命手册V4押题证据矩阵

## 使用边界

- 本表是编制端证据账本，不进入学生版。
- 目标院校直接信号只使用本轮可在题库正文中逐条检索的2018—2020华东题目；其他年份没有原题可逐条核实时，不补造年份或题型。
- “术语检出”只能证明题库存在相关考查线索，不能等同于同题、同题型或目标院校直接考过；最终题型还须结合现行核心度、采分结构和华东风格判断。
- 既往题型不是预测上限，但辅助题库的大题也不会被无条件移植。
