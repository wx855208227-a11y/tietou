# 深大保命手册V10语义层级与分页审计记录

## V9问题复现

- 合订版V9第22页出现“深度知觉”第3点后大段页底空白，第4、5点被整体推至下一页。
- DOCX检查显示，第4点、第5点、两个独立扩容段与总结段形成连续 `keep-with-next` 链。
- 原因不是章节分页符，而是渲染器在遇到独立扩容段和“综上”总结时，反向给前文连续设置 `keep-with-next`。

## 语义层级复核规则

- 形式层级校验不足以证明语义隶属正确；每题还要核对题干任务模块和来源材料中的父子关系。
- 上位类别使用 `1. 2. 3.`，其下分类使用 `（1）（2）`，再下位项目使用 `①②`，第四层使用 `a. b.`。
- 章节标题另起页；父模块标题只与首个子项同页，不把整组子项、独立扩容段和总结反向串联。
- 调整层级时不得删除采分点、改变来源归属或添加无来源理论点。

## 已识别的V10语义修订

- 深度知觉：调节、辐合归入肌肉线索；遮挡、透视、相对关系等归入单眼线索；双眼视差归入双眼线索。
- 催眠：角色扮演理论归入非特殊状态理论。
- 记忆机制：突触、长时程增强、反响回路归入生理机制；整合论、定位说归入脑机制观点。
- 遗忘：衰退、干扰、压抑、提取失败归入原因；遗忘曲线、材料与学习因素、系列位置效应归入规律和影响因素。
- 发展量表：年龄常模、年级当量归入主要形式；解释限制另列模块。
