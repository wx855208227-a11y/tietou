# 华东导论前三章 V7 题答同构黑白版质检

## 一、版本目标

- 以 V6 的综合答案和标准定义为正文底稿，不另造一套答案。
- 押题区不再单列名词解释，只保留简答、论述等需要调用综合答案的题目。
- 题干中的加粗考查词与综合答案中的同名小标题直接对应，不增加调用编号或对应表。
- 全文按黑白打印设计，不使用彩色、灰色底纹或下划线。

- 章节与单元：3 章，33 个母题单元。

- 题答同构检查：逐单元提取押题中的全部加粗考查词，并在对应综合答案中检查同名内容；缺失 0 处。
- 元标记检查：学生版未加入答题思路、停笔提示、题号调用公式、背诵主线或下划线。

## 三、定义与 V6 一致性

## 四、黑白打印与成品核验

- PDF 文字颜色：全部为黑色；线条全部为黑色；逐页栅格检查非灰度像素为 0。
- PDF 文字层完整：19 页均有可提取文字；页面图像块为 0。
- 页面边界检查：越界文字块 0；目录页码与正文 17 页的单元起始页一致。
