# 华东导论前三章V3双源核对报告

## 核对来源与范围

- 速背手册：`27_.docx`，第一章至第三章正文对应转换文本第138—683行；另按需要回查后文信度、效度和投射法定义。
- 华东一本通：HF实体Word `ecnu_yibentong.docx`，文件大小约3.6 MB，不是Git LFS指针；第一章至第三章正文对应转换文本第137—1083行、一本通正文第1—48页。
- 目标院校证据：沿用既有华东真题命题容量分析，只决定母题保留和重要性，不替代速背手册与一本通的正文口径。
- 成品底稿：V2直背综合答案版，共3章、33个母题单元、93道押题。

## 双源使用原则

1. 速背手册控制定义、核心判断、背诵顺序和学生最终调用口径。
2. 一本通用于核对专业术语、补足被速背手册压缩过度的必要限定语，并判断哪些角度适合作为就近加分项。
3. 两份材料均支持的内容直接保留；表述详略不同时，保留速背手册的简洁性，同时吸收一本通中会影响概念边界或采分完整性的限定语。
4. 一本通中的低价值叙述、长实验过程和无真题支撑的三级内容不机械搬入，以免增加背诵负担。
5. 来源存在明显笔误或学科性问题时，以规范心理学表述纠正，不为追求字面一致而复制错误。

## V3实质调整

- **心理学的学科性质**：在原有“中间科学”基础上补入一本通的“边缘科学或中间科学”，仍作为定义后的就近加分项。
- **神经冲动**：补足“实质是神经元内部产生生物电变化”，使定义与一本通的生理机制表述闭合。
- **学习**：将定义校准为“行为或行为潜能发生比较持久改变”，避免只写外显行为。
- **反射**：补入“在中枢神经系统参与下”，恢复定义的必要条件。
- **经典条件反射**：按一本通补足“原中性刺激—无条件刺激反复配对—中性刺激获得反应功能”的完整过程；两处重复定义同步替换。
- **泛化、分化和消退**：补全发生阶段、刺激范围、反应精确化和停止强化等限定语。
- **第一、第二信号系统**：恢复为“以具体事物及其属性／言语文字作为条件刺激而建立的条件反射系统”，避免过度概括。
- **操作条件反射与行为后果**：补入“工具性条件反射”别称和“反应结果满足需要”的完整逻辑；两处重复定义同步替换。正强化、负强化、正惩罚和负惩罚的定义均补足“行为之后—呈现或撤除刺激—行为频率变化”的判断链。
- **观察学习**：补足“不直接参与—观察榜样行为及结果—仿照表现—习得行为”的完整链条。

- 心理学目标、个案法、调查法和内分泌系统虽在一本通中出现，但不是当前33个高价值母题的必要采分点，本轮不新增独立单元。
