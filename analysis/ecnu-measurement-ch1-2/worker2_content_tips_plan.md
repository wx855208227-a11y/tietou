## 二、总体改写原则

1. 保持教材章节顺序，但按“可答题知识点”重组句子。第一章以历史线索和人物贡献为主，第二章以定义、构成要素、分类和辨析为主。
2. 第二章是本次正文质量重点，应写成可直接应对选择、名词解释、简答的“定义 + 要素 + 辨析 + 例子”结构。
3. 只保留能支撑答题的历史事实、定义句、分类标准、判断边界和例子。教材中的长背景、政策性评述、量表名单、函数推导、重复举例要大幅压缩。
4. 信度、效度、难度、鉴别力在第二章只作概念入口。详细估计方法、公式、效度证据、项目分析细节留给第六至八章，避免本章正文过重。
5. Tips 用于解决易混点，不为每个知识点强行添加。表格和图示优先服务第二章一级/强二级点，尤其是四种量表、测量三要素、心理测验三要素、测验分类。

## 四、第二章正文结构建议

第二章建议按“测量的一般问题 -> 心理测量 -> 心理测验 -> 测验分类 -> 测验应用”组织。现有样例顺序基本可用，但要压缩长解释并强化易考辨析。

### 1. 测量的基本问题

| 知识点 | 建议正文写法 | 必保留内容 | 压缩/删除 |
|---|---|---|---|
| 测量的定义 | 先给史蒂文斯定义，再给本书综合定义，最后列三要素 | “测量是按照法则给事物指派数字”；“按照一定法则，用数字方法对事物属性进行描写的过程”；对象、法则、结果三要素 | 教材中“仪器不是测量基本特征”“数的同一性/等级性/等距性/可加性”“函数/集合对应”压缩为理解性说明，不进主干。 |
| 测量三要素 | 用 3 点固定表述 | 对象是事物属性/特征；法则是分派数字依据；结果是数字或符号 | 不与“参照点和单位”混同。 |
| 参照点 | 绝对零点与相对零点对比 | 绝对零点表示“无”；相对零点是人为起点；非绝对零点不能作倍数解释 | 海拔、摄氏温度例子保留其一即可。 |
| 单位 | 定义 + 理想单位两条件 | 有确定意义；有相等价值 | “单位种类繁多”的叙述删去。 |
| 四种测量水平和量表 | 必须做成主表格 | 类别/等级/等距/等比的区分功能、是否等距、是否绝对零点、可用运算/统计、例子 | 各量表生活例子不必每类单独一段，统一放表中。 |
| 直接/间接测量 | 二级或三级短点 | 心理测量一般属于间接测量 | 曹冲称象、温度计例子最多保留一个。 |
| 测量方法 | 一句话 | 广义心理测量包括实验/观察等，狭义心理测量主要用测验法 | 不展开方法论。 |
| 误差和精确程度 | 过渡到后续理论 | 误差越大，精确程度越低；影响因素为对象属性、工具、目的 | 详细误差类型留给经典测验理论，不在本章展开。 |

### 2. 心理测量的基本概念

| 知识点 | 建议正文写法 | 必保留内容 | 压缩/删除 |
|---|---|---|---|
| 心理测量定义 | 名词解释式 | 根据一定法则，用数字对人的行为加以确定；依据心理学理论和操作程序，给行为和心理属性确定数量化价值 | 不要改写成“测心灵”，避免俗化。 |
| 心理测量可能性 | 只保留两个原则 | 桑代克：凡物之存在必有其数量；麦柯尔：凡有数量的东西都可以测量 | 删除长篇哲学说明和“工具未发明不等于不可测”的重复论证。 |
| 心理测量特点 | 建议列“间接性 + 相对性”两点 | 间接性：通过外显行为推论心理特质；相对性：无绝对标准/无绝对零点，只比较序列位置 | 特质理论可保留一两句，例子不宜过长。 |
| 心理测量水平 | 单独突出 | 心理测量只具有等级量表特征；多数心理特征可将原始分转为标准分后当作等距量表处理；不能作绝对零点/倍数解释 | 与四种量表表格相互引用，不重复展开。 |

### 3. 心理测验的基本概念

| 知识点 | 建议正文写法 | 必保留内容 | 压缩/删除 |
|---|---|---|---|
| 心理测验与心理测量关系 | 对比式 | 心理测验是工具，偏名词；心理测量是活动，偏动词；规范测验是科学测量前提 | 删除概念重叠的长铺垫。 |
| 心理测验定义 | 以阿纳斯塔西定义为核心 | 心理测验实质上是对行为样组的客观和标准化的测量 | 其他学者定义可作为脚注式补充，不占正文主干。 |
| 行为样组 | 定义 + 代表性要求 | 选择一部分有代表性的行为，推论所测心理特性；测题要能引发代表性行为 | 保留词汇测验例子即可。 |
| 标准化 | 分条列条件 | 测验编制、实施、记分、分数解释程序一致；内容、施测条件、评分规则、常模标准化 | 现有样例把常模放在标准化下可保留；但常模细节勿过量。 |
| 客观性 | 定义 + 与前两要素关系 | 方法可重复，实施/记分/解释客观；行为样组和标准化共同保证客观性 | 删除抽象评价句。 |
| 客观性指标 | 概念入口 | 信度、效度、难度、鉴别力；信度/效度最重要 | 信度种类、效度种类、项目分析仅作概览，详细留后章。 |

### 4. 信效度、难度、鉴别力的本章处理

| 指标 | 本章应写到的程度 | 避免写过头 |
|---|---|---|
| 信度 | 可靠程度；多次测量接近；可用相关系数表示；重测/复本/内在一致性作为名称入口 | 不展开斯皮尔曼-布朗公式、影响因素、标准误。 |
| 效度 | 真正确实测到欲测内容的程度；首要指标；内容/结构/效标关联效度名称入口 | 不展开效度证据收集、验证性因素分析等。 |
| 难度 | 测题难易水平；通常以通过率估计；过易/过难应调整或删除 | 不展开难度公式与校正难度。 |
| 鉴别力 | 区分不同水平被试的程度；通常看高低水平组通过率差 | 不展开项目-总分相关、D 值计算。 |
| 难度与鉴别力关系 | 一般中等难度项目鉴别力最高；好测验以中等难度为主，辅以少量较难/较易项目 | 不把“0.5 左右”绝对化，表述为一般原则。 |

### 5. 测验分类和应用

| 模块 | 建议呈现 | 备注 |
|---|---|---|
| 按测量对象 | 认知测验 vs 人格测验 | 认知测验下列智力、能力倾向、教育/成就、创造力；人格测验列性格、情绪、需要、动机、兴趣等。 |
| 按人数 | 个别测验 vs 团体测验 | 做对比表，含优缺点和适用对象。 |
| 按材料 | 语言/文字测验 vs 非语言/操作测验 | 做对比表，强调文化/语言限制与适用人群。 |
| 其他分类 | 客观/非客观、选择反应/结构反应、常模参照/标准参照、筛选/诊断 | 作为三级压缩点，避免展开。 |
| 测验应用 | 个别差异、诊断/预测/评价、甄选/分类/安置、心理辅导咨询、科研辅助手段 | 每项 1-2 句，保留功能逻辑即可。 |

## 六、关键词加粗与关键句下划线原则

- 概念名：**测量**、**心理测量**、**心理测验**、**参照点**、**单位**、**类别量表**、**等级量表**、**等距量表**、**等比量表**、**行为样组**、**标准化**、**客观性**、**信度**、**效度**、**难度**、**鉴别力**。
- 人名/量表/年份：**史蒂文斯**、**桑代克**、**麦柯尔**、**高尔顿**、**卡特尔**、**比奈**、**西蒙**、**比奈-西蒙量表**、**1905 年量表**、**S-B 量表**、**陆军 A/B 式量表**。

### 2. 下划线对象

下划线选择能直接构成答案的短句，不超过 1-1.5 行。建议优先下划线以下句类：

- 定义句：如“测量是按照法则给事物指派数字”“心理测验实质上是对行为样组的客观和标准化的测量”。
- 判断边界：如“心理测量一般属于间接测量”“心理测量只具有等级量表的特征”“等距量表可加减但不能乘除”。
- 要素关系：如“测量包括对象、法则和结果三个要素”“理想单位必须有确定意义和相等价值”。
- 易错限制：如“相对零点不能以倍数方式解释”“信度高不等于效度高，效度是首要指标”。

### 3. 避免事项

- 不要把整段历史叙述全部加粗或下划线；历史章只突出人物、年份、贡献和量表名称。
- 四种量表表格中，行标题和核心判断加粗即可，不要每个统计方法都加粗。
- 信效度、难度、鉴别力在第二章只突出定义和关系，详细方法在后续章节再加粗/下划线。
