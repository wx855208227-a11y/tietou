## Review Brief
### Original Request
根据负责人最新反馈重新生成华东导论保命手册前三章：不再按原小节强行合并综合答案，而按概念、题型与答题逻辑的自然适配度拆分答题单元；在适合处加入简短贴切的括号例子并标注可替换；关键词执行不可替换性、可还原性和最小充分原则，关键句标记不可缺失的关系与判断；继续以速背手册为主要表述依据、一本通为扩充依据，并用华东真题为主、其他347和312真题为辅控制题型与容量，最终交付新版Word。

- 重构导论前三章全部答题单元，保持速背章节顺序但不受原小节边界限制。
- 使用“不可替换性＋可还原性＋最小充分”标准重新划分关键词，并仅给不可缺失的关系或判断标关键句。
- 在适合辨析或应用的地方加入简短、贴切且明确标注“可替换”的括号例句。
- 继续按速背手册、一本通、华东真题、其他 347 与 312 真题的既定证据优先级控制表述、题型和容量。
