## Review Brief
### Original Request
重新对深圳大学347普心、实验、测量160道题建立无零项的完整来源采分点清单；速背主体、一本通辅助，逐点检查正文或扩容去向并反查无来源新增，修订后重新生成合订Word与PDF并完成结构和排版质检。

### Assigned Scope
- 对普心90题、实验25题、测量45题共160题全量重审，不允许任何题以“0项独立清单”跳过。
- 每题分别记录速背手册主体采分点、一本通辅助采分点、正文去向、扩容去向和新增表述来源。
- 对答案执行反向来源核查，排除无来源理论点、跨章误配和术语不一致。
- 按审计结果修订三科分册，重新生成普心—实验—测量合订版。

### Deliverables
- 三科新版Markdown、DOCX和PDF。
- 深圳大学347心理学保命手册合订版Word与PDF。
- 160题无零项的逐题完整来源台账及审计报告。
- 结构、名词解释一致性与排版质检报告。

### Validation Plan
- 断言160/160题均有非空的速背主体点清单和去向记录。
- 断言所有来源点均进入正文或圆括号扩容，且答案中的理论点均能局部回溯。
- 统一检查重复名词解释、人物—理论配对、公式和专业术语。
- 运行内容结构验证、完整来源审计、页码稳定性检查和合订版排版QA。

### Constraints And Non-Goals
- 速背手册为主，一本通为辅；不凭空新增采分点。
- 简答题因容量移出的有效点必须进入整点扩容，不得无痕删除。
- 一本通或教材补充原则上放入圆括号，结构性总起、比较和总结允许重组已有信息。
- 不设置要求考生现场设计实验的题目，不改变用户已确认的星级、关键词和黑白排版规则。
