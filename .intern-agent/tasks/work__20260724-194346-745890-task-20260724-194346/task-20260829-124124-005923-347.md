## Review Brief
### Original Request
重新编制深圳大学347保命手册：删除全部实验设计押题；基于深大历年主观题提炼概念比较、关系辨析、举例应用等院校风格；逐题进行采分点正向完整性与反向来源审计；按采分容量校准简答和论述；普心、实验、测量顺序合订并输出DOCX、PDF及质检报告。

### Assigned Scope
- 重编普通心理学、实验心理学、心理与教育测量三科学生版，并按该顺序合订。
- 删除要求考生完成研究方案的实验设计押题；实验设计、被试间设计等理论知识仍在现行范围内保留。
- 用深大2019—2026主观题归纳概念比较、关系辨析、举例应用等风格，作为预测问法的独立证据。
- 新增逐题正向完整性与反向来源双审计，并按基础答案的任务负荷校准简答／论述。

### Deliverables
- 三科新版Markdown、DOCX、PDF。
- 普心—实验—测量合订版DOCX、PDF。
- 押题风格与逐题双向采分点审计报告、来源审计报告、排版质检报告。
- 可重复执行的重编、校验、合订及质检脚本。

### Validation Plan
- 检查全册不存在“请完成／设计一项实验”等实验设计任务。
- 检查每道题题型、基础采分点容量、比较题联系与区别、举例题例子位置。
- 检查答案采分点可回溯到速背手册／一本通，并检查相关来源点到答案的正向覆盖。
- 检查三科及合订本章节、星级、题数、名解唯一表述、关键词密度、字号、字距、分页、目录、空白页和页面越界。

### Constraints And Non-Goals
- 不扩张深大现行考纲、速背手册、一本通及指定教材的知识边界。
- 不为了题型容量删减必需采分点，也不为了凑字数新增无来源采分点。
- 不将实验设计题纳入本册；不改动无关院校成品。
- 黑白打印；正文与题型／名解标记统一12磅；每科、每章另起一页。
