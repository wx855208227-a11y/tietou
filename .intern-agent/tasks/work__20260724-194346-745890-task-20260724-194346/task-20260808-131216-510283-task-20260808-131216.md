## Review Brief
### Original Request
用户要求在发现偏见模块并非来自速背手册或一本通后，重新生成华东师范大学347心理学导论保命手册全本。必须逐项核验来源，以速背手册为主、一本通为辅；目标院校真题缺口可以保留，但须按补充来源处理并明确来源边界；同时保持逐题直背、关键词、名词解释句末标注、同行扩容、总分总、简答与论述容量均衡等既定标准，输出DOCX、PDF及质检报告。

### Assigned Scope
- 以现有全本V1为底稿，逐项复核速背手册、一本通和华东347真题题库的来源边界。
- 重编所有“主体材料缺失但由华东真题要求补齐”的模块，学生答案保持可直接背写，编校报告明确补充来源。
- 复核名词解释唯一表述、共享采分点、重点等级、题型容量、扩容位置和黑白打印格式。

### Deliverables
- 全本来源严格版V2 Markdown、DOCX、PDF。
- V2来源与结构质检报告。
- 可复现的构建、来源审计和格式质检脚本或脚本更新。

### Validation Plan
- 校验输入资料哈希并检索全部名词解释与真题锚点。
- 对主体材料缺失模块生成明确清单，禁止仅以题目存在冒充答案来源。
- 运行结构校验、来源审计、DOCX/PDF构建与PDF页面清点。
- 抽查2018、2020年偏见真题答案：重合模块逐字一致，简答与论述容量合理，扩容就近对应。

### Constraints And Non-Goals
- 不改动用户既有V1文件，新增V2文件。
- 不虚构教材来源、华东真题年份、计时手写结果或独立审查结果。
- 不引入与华东真题无关、且双源未覆盖的新知识模块。
- 不处理仓库中的无关文件。
