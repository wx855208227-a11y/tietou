## Review Brief
### Original Request
用户反馈测量保命手册中的名词解释普遍只有简短定义，容量不足。按核心定义句后标注名解，并紧跟与该概念对应的扩容项；结合新上传的测量一本通，对全本名解统一核查，重复名解及其扩容保持一致，生成修订版。

### Assigned Scope
- 以测量保命手册V1的题目、分级、基础答案和关键词为冻结基线，只修订名词解释的选用扩容与相关呈现规则。
- 逐一核查60个唯一名解及81处调用，确保每处名解标签后立即出现与该概念对应的标准扩容。
- 以最新版测量速背手册为主、用户新上传的测量一本通为辅，避免范围外扩写。

### Deliverables
- 测量保命手册名解完整扩容版V2（Markdown、DOCX、PDF）。
- 名解唯一表及全本内容、排版质检报告。
- 更新后的保命手册编制标准与可复现构建／验证脚本。

### Validation Plan
- 自动验证11章、39单元、45题以及V1基础正文不变。
- 验证60个唯一名解、81处调用全部具备同行扩容，定义与标准扩容均零异文。
- 验证扩容位置、标点、黑白打印、无斜体／下划线／底纹、目录页码和页面越界。

### Constraints And Non-Goals
- 不改变押题、一级二级、基础采分点、关键词和答案结构。
- 题干明确要求的内容继续作为基础作答，不得为补名解容量而移入扩容。
- 不声称已完成真实学员计时手写测试。
