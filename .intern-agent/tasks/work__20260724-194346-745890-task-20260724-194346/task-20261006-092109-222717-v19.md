## Review Brief
### Original Request
以V19为冻结底稿，按普心、实验、测量顺序逐题核查并修正：题型与答案容量匹配；题干符合深大真题风格且避免机械堆叠；速背采分点无遗漏且新增点归入扩容；扩容均有一本通或教材来源；继承速背Word真实加粗下划线关键词并合理补标；正文以速背为主体、一本通和教材用于扩容，适合举例处补充简短典型例子。不得沿用V20过度重构，不得批量改写，每题单独形成审核记录后再进入下一题，V19原文件不得覆盖。

### Assigned Scope
- 以三科V19 Markdown为冻结底稿，按普通心理学1—90、实验心理学91—115、心理与教育测量116—160逐题复核。
- 每题核查题型与主体容量、题干自然度与深大风格、速背采分点完整性、扩容来源、Word关键词继承、速背主体与一本通/教材扩容边界及典型例子。
- 仅作有明确来源和明确必要性的保守修改；V20及其衍生版本完全禁用，不得读取、比较、调用、复制，也不得作为问题线索或审核依据。
- V19的题目体系、答案组织和语言风格保持稳定；无明确问题的题目保持不动，有问题的题目只修正对应问题，不借机整体重写。

### Deliverables
- 三科“V19原标准逐题校正版”Markdown、DOCX、PDF。
- 按普通心理学—实验心理学—心理与教育测量顺序合订的“V19原标准逐题校正版”DOCX、PDF。
- 160题逐题审核台账和最终排版/结构质检报告。

### Validation Plan
- 每题对照速背Word正文及真实加粗/下划线run，再以一本通/指定教材核验圆括号扩容。
- 统计圆括号外主体容量，参考名解100—200字、简答200—400字、论述400—800字，但以任务复杂度和真实题型证据为准。
- 检查速背点去向、无来源正文点、无来源扩容、关键词漏标、题干机械并列、层级错置及孤立子序号。
- 生成后运行三科和合订版QA，检查题数、标题、字号、分页、异常留白、DOCX/PDF一致性。

### Constraints And Non-Goals
- 不覆盖V19；不读取或沿用V20及其衍生版本；不为追求形式统一而改动已通过的题目。
- 正文采分点以速背为主体；一本通和教材新增的知识性采分点只作圆括号扩容或争议核验；真题、考纲和题库只用于题干、题型及可考性判断。
- 不凭空增加或删除采分点；正文删减的速背点必须转入圆括号扩容。
- 知识性扩容只能来自速背、一本通或教材；例子是唯一明确例外，不强求材料原文出处，但必须简短、准确、易懂并置于圆括号内。
- 保留V19成熟、自然的答案表达，只需保证概念、采分点和判断与材料一致，不要求逐字还原材料，也不得因某句话不是材料原句就机械删除。
- 比较结论、总起、模块提示语和总结等结构性归纳可自行组织，但不得借此增加材料之外的知识采分点。
- 序号使用1.→（1）→①→a.，不得出现没有同级后续项的孤立下级序号。

### Claimed Output
- 先前生成的V21误用了V20文本与判断，已判定为作废版本，不能作为交付成果或后续参考。
- 新成果尚在逐题复核中；最终只接受以V19和原始来源直接核对形成的“V19原标准逐题校正版”。

### Artifacts And Evidence

- 答案来源仅限三科速背Word、一本通Word和指定教材；命题判断另参照深大真题、考纲、312题库与347题库。
- 所有文件名含“V19基线逐题保守精修版V21”的产物及V21报告、台账均为作废版本，不得用于新稿。
