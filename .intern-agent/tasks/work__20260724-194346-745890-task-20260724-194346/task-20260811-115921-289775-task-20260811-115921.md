## Review Brief
### Original Request
用户反馈华东测量保命手册排版中存在很多不必要空白，影响观感。保持V6知识正文、题目、编号、关键词、名解和扩容不变，定位并压缩答案内部无意义段落留白，保留章题、单元题、押题间必要层次和题间分隔，重新生成Word/PDF并完成页面质检后发送飞书。

### Assigned Scope
- 以V6为唯一内容基线，只调整Word/PDF排版密度和分页，不改45道题的正文、题型、星级、编号、关键词、名解或扩容。
- 取消正文各章强制另起一页，保留章标题、单元标题和押题标题的必要层次留白。
- 压缩答案内部段后距，解除总结前四段的过长分页绑定，并修复紧凑排版后可能出现的页尾孤立任务模块标题。

### Deliverables
- V7 Markdown、DOCX、PDF。
- V7构建、内容验证、页码更新、制品质检脚本和PDF页面清单。
- 将“避免无效留白、章节连续排版、模块标题不孤立”写入长期编制标准。

### Validation Plan
- 对比V6／V7 Markdown，确认除内部副标题版本号外逐字一致。
- 复核章节强制分页数、PDF总页数、正文页数、稀疏页、页底大面积空白、页尾孤立模块标题和目录页码。
- 继续执行字号、字距、黑白、溢出、图片、斜体、题间距、名解一致性和任务编号检查，并回归验证V6制品质检不受影响。

### Constraints And Non-Goals
- 不通过缩小正文字号或牺牲题间分隔压缩页数；正文仍为12磅，押题间距仍不低于320 twips。
- 不改变知识内容和押题判断，不重新进行来源编制。
- 不虚构真实学员计时手写结果；无需部署或重启。
