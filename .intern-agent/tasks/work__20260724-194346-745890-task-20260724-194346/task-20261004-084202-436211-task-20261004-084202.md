- 三科重编Markdown与Word分册。
- 按普通心理学—实验心理学—心理与教育测量顺序合订的完整Word。
- 全量来源范围审计、结构容量审计和排版质检报告。

- 校验三科共160题，题目、章节、知识单元和名解调用数量符合预期。

- 校验总起/总结不编号，任务模块从1.开始，层级按1.→（1）→①→a.展开；扩容紧邻对应采分点。
