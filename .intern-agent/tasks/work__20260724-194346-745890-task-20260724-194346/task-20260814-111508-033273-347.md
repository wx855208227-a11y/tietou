## Review Brief
### Original Request
按已定稿的新标准，基于用户提供的深圳大学347普通心理学、实验心理学、心理与教育测量速背手册和一本通，并结合深大真题、现行考纲、指定教材及辅助真题分析，重新编制三科逐题直背保命手册，按普心—实验—测量合订为一本；要求题干任务分块、比较/实验/应用题型适配、名解准入与完整扩容、关键词齐全、星级合理、简答论述容量校准、章节另起一页、黑白统一排版。

### Assigned Scope
- 以用户提供的深大普通心理学、实验心理学、心理与教育测量最新版速背手册为答案表述主源，一本通为补充源；指定教材用于争议核对。
- 以深大历年真题和2026现行考纲为命题与分级的核心证据，312及其他347真题仅辅助判断知识点可考性和可形成的题型，不作为扩张答案范围的依据。
- 沿用华东合订精校版已经确认的新标准，逐题执行题干任务分块、题型适配、名解准入与完整扩容、关键词齐全、简答／论述容量校准和重复表述零异文。
- 普心、实验、测量分别形成可独立使用的成品，并按“普通心理学→实验心理学→心理与教育测量”合订为一本。

### Deliverables
- 深大普通心理学、实验心理学、心理与教育测量三科精校版Markdown、DOCX和PDF。
- 深圳大学347保命手册三科合订版DOCX和PDF。
- 来源边界、命题分级、答案结构、名解、关键词、容量与排版质检报告。

### Validation Plan
- 对每个编号采分点和名解标签进行速背／一本通来源覆盖审计，阻止超范围内容进入背诵主体。
- 检查每道题覆盖题干任务词；比较题含必要分述、联系和逐维度区别，实验设计题含假设、变量、操作、控制、程序、统计与结果解释。
- 检查同名名解“核心定义＋紧邻扩容＋标签”零异文，扩容不串位且不独立成段；名解仅标注具有独立命题可能的规范概念。
- 检查题干任务模块从1连续编号，总起和总结不编号；简答与论述容量分布稳定，论述明显多于简答；后半册关键词密度不下降。
- 生成PDF后核对目录页码、各章另起一页、黑白、统一12磅正文、正常名解字距、空白页、稀疏页、孤立标题、段间异常留白和文字溢出，并小批量视觉抽查。

### Constraints And Non-Goals
- 不机械复制华东题目或答案；相同知识表述可复用，但押题、星级和范围必须重新服从深大证据。
- 不引入深大速背手册／一本通与现行考纲边界外的知识；结构性比较结论和任务归纳允许基于既有正文应试化重组。

- 真实学员计时手写未执行前，不虚构测试结果，只进行理论容量校准。
