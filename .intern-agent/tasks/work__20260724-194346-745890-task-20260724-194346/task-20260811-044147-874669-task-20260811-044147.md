- 层级固定为`1.`→`（1）`→`①`→`a.`，不使用生硬的“一、二”模块标题。
- 保留现有名解、圆括号扩容、星级、关键词、题量和来源边界，不借结构优化增加新理论。
- 同步更新编制标准、生成Word/PDF并完成内容与制品质检。
