- 保命手册正文以速背手册为主体；一本通仅用于有依据的扩容或来源核验；不得凭空补点。

- 人工逐题勾核160题，前一题形成审核记录后才进入下一题。

- 运行现有结构QA并补充V20专用校验；自动校验仅用于发现遗漏，不替代人工逐题判断。

- 不通过统一规则批量重写题干、批量判定题型或批量重组答案。

- 不覆盖V19，不修改无关文件，不处理其他院校资料。
