# 铁头一本通编制要求及细则

This reference distills the local PDF titled `一本通编制要求及细则`. Follow it for 铁头一本通 compilation and review. If a rule conflicts with a direct user instruction, project-specific material, or subject-matter accuracy, ask the leader for confirmation before proceeding.

Source PDF: `docs/yibentong/一本通编制要求及细则.pdf` in the `agiamason/tietou` project repository. Agents should use this distilled reference first; consult the PDF only for exact wording, screenshots, examples, or unresolved detail checks.

## Materials

- 主体材料: 铁头一本通. If the subject has no existing 一本通, use the electronic textbook as the主体材料.
- 辅助材料: official/electronic reference textbook, target院校官方考纲, target院校历年真题, optional 312历年真题, optional 泛347历年真题库, and strong external materials such as 高分秘籍 or 大纲解析 when the leader provides them.
- Use external material for comparison, not blind copying. Use the textbook as the authority for wording, definitions, structure, and source verification.
- Evidence priority for 347 school-specific work: target-school true questions > target-school official outline > assigned textbook structure and wording > auxiliary 312/泛347 true-question evidence > other external materials.

## Compilation Process

1. Compare主体材料 with external materials and classify importance.
   - 条目一致: keep主体材料 content and its existing importance level.
   - 主体材料 has an item but external material does not: if 一级, keep but downgrade to 二级; if 二级, keep but downgrade to 三级; if 三级, delete. If no level is marked, judge from the parent item.
   - External material has an item but主体材料 does not: locate it in the textbook. If present, rewrite the textbook content by these content rules and add it. If not present, add it as `补充内容`, verify its source against mainstream textbooks, cite the source if found, or mark that no source was found.
2. Compare the revised主体材料 with the textbook.
   - For every item, check whether points, terms, keywords, and meaning match the textbook.
   - If inconsistent, replace with a rewritten version based on textbook content and these content rules.
3. Compile content.
   - Split and layer long prose.
   - Bold keywords and underline key sentences.
   - Check typos.
4. Check past-exam questions.
   - If a target-school paper contains multiple subjects, first classify questions by subject and keep only the relevant subject questions for this 一本通 chapter. Use the answer substance, not surface keywords, to decide the subject.
   - Find all knowledge points touched by target院校历年真题.
   - Record each relevant question's year, type, score if available, subject, textbook chapter, and tested knowledge point.
   - Add true-question markers at the matching title or location.
   - If a true-question point is missing, locate it in the textbook, add it as正文, and mark it 一级.
   - All true-question knowledge points are 一级.
   - Use 312 and 泛347真题 only as auxiliary evidence for examability, common question forms, and 强二级 review; they do not create target-school真题 markers.
5. Final format and typo pass.

## Textbook-Based 347 一本通 Compilation Standard

When no existing 一本通 is available and the official textbook is the主体材料, compile according to the textbook's chapter order. Do not reorganize the document by official exam outline headings. Official outlines are usually broad and may span multiple textbook chapters; use them to judge importance only.

The target is an exam-facing考点筛选稿. 一本通 should stay close to textbook concepts and scoring language, but it should not preserve all textbook narration. A chapter output that is close to the length and narrative density of a textbook summary is too verbose.

### Screening Before Rewriting

For each textbook section, first decide whether the material is a testable knowledge point:

- Keep: definitions, classifications, core elements, processes, theories, representative figures, years, named tests/scales, key findings, advantages/disadvantages, applications, limitations, and points touched by true questions or official outlines.
- Compress: historical background, development context, author evaluation, transitional prose, long case descriptions, repeated explanations, and broad social/policy discussion.
- Delete: decorative narration, duplicated examples, low-yield lists with no exam value, details that do not help answer a likely question, and textbook paragraphs that only connect ideas without adding a scoring point.
- Keep as brief examples only: named examples that identify a category or make an abstract concept understandable.

### Structure Standard

After screening, rebuild the section around answerable layers rather than textbook paragraphs:

- Use `人物/事件/概念 -> 核心贡献/定义 -> 必要细节/例子` for history and development sections.
- Use `定义 -> 要素/分类 -> 特点/适用范围 -> 例子/评价` for concepts and theories.
- Use `步骤 -> 操作要点 -> 注意事项/评价` for procedures.
- Use tables or comparison structures when the textbook contrasts types, theories, tests, or indexes.

Each numbered point should carry one memorisable scoring point. If a paragraph contains several answer points, split it into `1.` / `（1）` / `①` layers. If a paragraph only explains background, compress it to one short sentence or remove it.

### Compression Benchmark

Use supplied high-quality 一本通 samples as the benchmark. For textbook history/development chapters, aggressive compression is expected: preserve people, years, named works/tests, and contributions; remove most story-like narration. If a compiled section is more than about twice the density of the human sample for the same source, review for over-retention.

### Example: History Chapter Screening

For a textbook chapter such as `心理测量和测验的历史回顾`, the expected output is not a full historical summary. Keep points like:

- 中国古代心理测量的三个前提;
- 孔子、孟子、刘劭、《学记》《礼记·本命》、科举、周岁试儿、七巧板、九连环 and their testable contributions;
- 艾斯克罗、塞甘、冯特、高尔顿、卡特尔、克雷丕林、艾宾浩斯 and their core contributions;
- 比奈—西蒙量表、1905年量表、斯坦福—比奈量表;
- 个别测验 vs 团体测验, 陆军甲种/乙种测验;
- 我国发展概述 only as high-level examinable features unless specific events are likely or真题-covered.

Remove or heavily compress long accounts of social context, institutional history, broad reflections, and policy discussion unless the user explicitly asks for a detailed history version.

For psychology考研 materials, `中国/中国古代/我国历史发展` content is non-core by default when there is no target-school true-question evidence. Process it conservatively: mark as 二级/三级, compress to high-level clues, or delete low-yield details according to examability. If the target school has tested the exact point, mark that point 一级 and add the true-question marker.

## Importance Levels

- Importance levels describe estimated exam frequency and probability, not whether a point is absolutely testable. 一级 means a high-frequency point that is very likely to appear in real exams; 二级 means a medium-frequency point that is reasonably likely to appear; 三级 means a low-frequency point that can still be tested, but would usually feel偏、怪、难, or beyond the normal core scope.
- Prefer marking importance on second-level titles.
- Determine an upper-level item's importance from its lower-level content. For example, if most lower items are 一级, the parent should be 一级.
- If a third-level title has the same importance as its second-level parent, omit the repeated third-level mark.
- True-question knowledge points must be 一级.
- Summary principle: only mark exceptions when lower-level importance differs from the parent.

### Importance Evidence For 347 School-Specific Work

- 一级: high-frequency points that are very likely to appear in real exams, including points directly tested in target-school true questions and concrete core knowledge points inside the official outline scope, especially definitions, core classifications, major theories, representative scales/tests, procedures, formulas, reliability/validity indexes, and high-yield comparisons.
- 二级: medium-frequency points that are reasonably likely to appear in real exams, including important textbook content that supports 一级 clusters or has clear examinability, but is not directly true-question-covered and is less central than core definitions/classifications/theories.
- 强二级: a manual-review subset inside 二级. Use this label in compilation notes, not necessarily in the正文 title, for points that are close to 一级 but lack decisive evidence. Typical cases include: official-outline-covered points with a stable question form but no direct true-question hit; textbook major subpoints that strongly support a 一级 cluster; points adjacent to repeated true-question themes; and points that could plausibly be upgraded to 一级 based on the leader's school-specific judgment.
- 三级: low-frequency points that can still be tested but would usually be偏、怪、难, or near the edge of the normal scope, including background, low-frequency history, broad development overview, minor scale descriptions, or content mainly for understanding.
- 中国/中国古代/我国历史发展类内容在没有目标院校真题支撑时，默认不作为重点。可按教材地位和可考性压缩为二级或三级；弱可考的细节可删除。只有被目标院校真题实质考过的具体点才升为一级。
- Official outline evidence identifies important clusters. Do not automatically mark every subpoint under an outline-covered chapter as 一级.
- True-question evidence must be substantive. Only mark `【xx年真题】` when that exact knowledge point or its answer substance was tested; do not mark because the same person, school, or general topic appeared in another context.
- A lower-level title can be more important than its parent. For example, a parent history section may be 三级 while a specific figure/test inside it is 二级 or 一级.
- Every compilation delivery should separately list all 强二级 points for leader review. The list should include: knowledge point, textbook page/chapter location, current suggested level, reason for 强二级, possible question type, and whether it is a candidate for upgrade to 一级.

### Official Outline Three-Ring Rule

Official outline coverage means the knowledge cluster is important, but the outline is usually broad and does not make every subpoint 一级. For each outline-covered cluster, split textbook content into three rings before assigning levels:

- Core ring -> usually 一级: the cluster's definitions, core classifications, basic principles, important theories, formulas/indexes, procedures, representative tests/scales, high-yield comparisons, and any point that can independently form a stable exam question.
- Support ring -> 二级 or 强二级: important textbook subpoints that support the core ring, can appear as smaller short-answer/choice/judgment points, or sit close to repeated true-question themes but lack direct target-school evidence.
- Background ring -> 三级 or compressed/deleted: historical context, social background, author evaluation, transition paragraphs, minor details, long examples, and content that only helps understanding but has weak normal exam value.

Use this rule together with target-school preference. If the target school repeatedly tests history, application, calculation, or case analysis, upgrade matching support-ring points to 强二级 or 一级 when evidence is strong enough.

### True-Question Profiling And Subject Filtering

Before judging importance for a school-specific 一本通, build a compact question profile from the provided true questions:

- Classify each question by subject. For a mixed 347 paper, include only questions whose answer substance belongs to the current subject. For 心理测量, include items such as psychological tests, measurement levels, reliability, validity, norms, item analysis, test construction, test ethics, classical test theory, modern measurement theory, and representative scales/tests.
- Mark cross-subject questions by dominant answer source. For example, a question using statistics to evaluate reliability can belong to 心理测量 if the scoring focus is reliability interpretation; a general hypothesis-testing calculation belongs to 统计心理学.
- Record question type: choice, judgment, term explanation, short answer, essay, case/material analysis, experiment design, calculation/application, or other observed forms.
- Map each relevant question to the smallest textbook knowledge point that supplies the answer. Use substantive match, not shared words.
- Use target-school true-question hits as decisive 一级 evidence and true-question markers. Do not create target-school true-question markers from 312 or other-school 347 questions.

### Question-Type Fit And Examability

When a point is not directly tested by the target school, judge examability by the question forms it can naturally support:

- Term explanation: named concepts, theories, scales, indexes, effects, methods, and representative tests.
- Choice/judgment: concept boundaries, category membership, people/years, key features, advantages/disadvantages, and common misconceptions.
- Short answer: definitions plus elements, classifications, characteristics, influencing factors, functions, steps, applications, and contributions.
- Essay: theory comparisons, development logic, relationship辨析, integrated evaluation, and multi-part frameworks.
- Case/material analysis: test use, reliability/validity interpretation, norm interpretation, test construction decisions, ethics, and applied judgment.
- Calculation/application: score transformation, norms, item difficulty/discrimination, reliability coefficients, validity evidence, and measurement-level/statistical-method matching.

A knowledge point's level rises when it has stable question forms, clear scoring points, textbook emphasis, outline coverage, and target-school style fit. It falls when it is mostly narrative, lacks independent scoring points, or only appears as a remote background detail.

### Auxiliary 312 And 泛347 True-Question Evidence

Use 312 and 泛347真题库 to improve examability and question-type judgment, especially when the target school has few years of data:

- 312真题: good evidence for common psychology exam core concepts, standardized question forms, measurement/statistics/experiment applications, and stable high-yield definitions or comparisons.
- 泛347真题: good evidence for self命题院校 preferences, common applied/case/essay forms, and knowledge points repeatedly tested across schools.
- Auxiliary evidence can upgrade a point from ordinary 二级 to 强二级, or support a recommendation to upgrade to 一级 when it is also outline-covered and textbook-core.
- Auxiliary evidence should not override the target school's own true questions, should not reorganize the textbook, and should not be marked as target-school真题 evidence.

## Content Rewriting

- Avoid large unbroken paragraphs. Each paragraph should be no more than two lines; split and layer anything longer.
- Preserve textbook keywords and key sentences while reorganizing the expression into concise points.
- For textbook adaptation, reduce verbosity, keep the core meaning, and avoid adding unsupported claims.
- Do not treat external materials as authoritative when they conflict with the textbook.
- Rewrite after screening, not before screening. First remove low-yield material, then polish the retained points.
- Prefer concise formal answer language over continuous exposition. Good 一本通 paragraphs often look like answer outlines.
- Preserve exact names, years, works, scale names, theory names, and textbook judgments when they are likely scoring points.
- Do not add Tips, examples, or explanations merely to fill space. Add them only when they improve understanding or prevent common mistakes.

## Bold And Underline

- Bold `keywords`: word-level or term-level scoring points, such as concepts, names, theories, scale names, methods, indexes, years, and fixed expressions.
- Underline `key sentences/key phrases`: answer-bearing sentence parts, clauses, or short sentences. A key sentence does not have to be a complete grammatical sentence; it can be the most important half sentence or phrase group inside a sentence.
- The practical test is extraction: if only the bolded keywords and underlined key phrases are read together, they should basically recover the paragraph's core content and answer logic.
- Do not include adjacent punctuation in bold or underline marks.
- If keywords are too dense in one sentence, do not bold every keyword; underline the key phrase/sentence segment that carries the complete point instead.
- Underlines should not be too long; keep each underline within about 1.5 lines. Avoid reflexively underlining whole sentences when a shorter clause is enough.
- Do not mix bold and underline randomly. Use bold for isolated terms; use underline for relational judgments, definitions, causal links, contribution statements, steps, or comparison conclusions.

## Tips

- For every knowledge point, if the textbook includes relevant experiments, adapt the experiment into a `Tips` block and mark the page number.
- Experiment tips should be concise, ideally no more than half a page. Include an image if genuinely useful and available.
- If no experiment applies, create a `Tips` example that fits the knowledge point and is easy to understand in daily life.
- Avoid obscure examples, irrelevant examples, or explaining one unfamiliar concept with another unfamiliar concept.
- Tips should be either `textbook experiment adaptation` or `concrete example for understanding`. Do not use Tips for true-question reminders, answer strategies, broad summaries, motivational notes, or loose chapter-level comments. Put those in正文, 易混点, or delivery notes when needed.
- For history/factual points, do not force a generic Tips block if it cannot produce a concrete, useful example. Forced Tips lowers quality.
- Tips spacing and style:
  - Leave one blank line before and after a Tips block.
  - If Tips has a title, bold and center it; if not, no title treatment is needed.
  - Examples should use `例如` and leave two spaces after it when the final document style requires it.
  - If two Tips blocks are adjacent, leave two blank lines between them.
  - If a Tips block is based on a textbook experiment, mark the lower-right page reference as `【科目+Pxx】`.
  - Leave two blank lines between tables and Tips.

## Supplementary Content

- Content not from the current textbook should be placed in a supplement box.
- Use a double-line box around supplementary content.
- Mark the upper-left label `补充内容：`.
- Supplementary content also needs key-point marking.
- If the source cannot be verified in mainstream textbooks, mark the uncertainty and ask the leader when it affects correctness.

## Title Levels And Numbering

- 一级标题: `第X 章 ×××××`; one space between chapter number and title; 宋体三号加粗居中.
- 二级标题: `一、×××××`; use 顿号, no extra space; 宋体四号加粗.
- 三级标题: `（一）×××××`; no 顿号 and no extra space; 宋体小四加粗.
- Deeper numbering:
  - `1.××××`: digit plus period; usually bold; leave one blank line before the next same-level item unless the content is very short or has no lower level.
  - `（1）××××`: no indent; no blank line between same-level titles.
  - `①`: indent one level.
  - `A.`: use only if the hierarchy needs another level; indent two levels.
  - `a.`: if `A.` is used, indent three levels.

## Punctuation And Sentence Layering

- Use Chinese punctuation: Chinese parentheses, comma, period, semicolon, and related marks.
- For layered knowledge points, use semicolons in earlier layers and a period at the final layer.

## Title Annotations

- Title annotation order: title + textbook page reference + importance level + true-question marker.
- Mark second- and third-level title page references to the textbook where applicable.
- True-question marker format: `【xx年真题】`.
- Do not include question type in the true-question marker.
- If the same knowledge point appears in multiple years, list the years in order.

## Overall Formatting

- After compiling正文, Tips, and supplementary content, adjust format and apply title levels before final review.
- Recommended final order: apply title levels, mark second/third-level page references, mark true-question markers, mark importance levels, add page numbers, generate catalog, add cover.
- Cover should follow previous-year materials; verify school, year, subject, and reference textbooks.
- Full document line spacing: 1.5.
- Body font: 宋体小四.
- Follow Chinese line-breaking habits and use proper first-line indentation.
- Each chapter starts on a new page.
- Page numbers begin from the first正文 page, excluding the catalog; page number font 宋体四号.
- Catalog title: 宋体一号居中.
- Catalog body: 宋体11号; first-level catalog entries bold; leave one blank line between chapters.
- Tips and supplementary content should avoid crossing pages. If only a short fragment spills over, move the whole block to the next page or adjust spacing if it does not hurt readability.

## Review Checklist

- Source materials are identified and missing inputs are listed.
- Each external-only item is located in the textbook or explicitly marked as supplementary with source status.
- Textbook keywords and key sentences are preserved.
- Long paragraphs are split into layered points.
- True-question knowledge points are present, marked, and 一级.
- Importance levels follow parent/child rules and repeated lower-level marks are omitted when appropriate.
- Tips are relevant, concise, and page-marked when based on textbook experiments.
- Supplementary content uses the required box and label.
- Title levels, numbering, punctuation, page references, true-question markers, page numbers, catalog, chapter page breaks, and cross-page tips/supplements are checked.
