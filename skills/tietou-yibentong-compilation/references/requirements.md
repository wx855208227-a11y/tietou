# 铁头一本通编制要求及细则

This reference distills the local PDF titled `一本通编制要求及细则`. Follow it for 铁头一本通 compilation and review. If a rule conflicts with a direct user instruction, project-specific material, or subject-matter accuracy, ask the leader for confirmation before proceeding.

Source PDF: `docs/yibentong/一本通编制要求及细则.pdf` in the `agiamason/tietou` project repository. Agents should use this distilled reference first; consult the PDF only for exact wording, screenshots, examples, or unresolved detail checks.

## Materials

- 主体材料: 铁头一本通. If the subject has no existing 一本通, use the electronic textbook as the主体材料.
- 辅助材料: official/electronic reference textbook, target院校官方考纲, target院校历年真题, optional 312历年真题, optional 泛347历年真题库, and leader-provided published textbook/academic literature sources. Online文库、咨询号、无出处网络总结, and unsourced notes cannot be used as authoritative supplementary sources.
- Use external material for comparison, not blind copying. Use the textbook as the authority for wording, definitions, structure, and source verification.
- Evidence priority for 347 school-specific work: target-school true questions > target-school official outline > assigned textbook structure and wording > auxiliary 312/泛347 true-question evidence > other external materials.
- HF 中已上传的一本通只作为格式参考，不作为内容参考。除非负责人明确要求做内容比对或审核，否则不得借鉴、学习、复刻或迁移 HF 一本通中的正文内容、层级判断、真题标注、Tips 内容、语言组织和取舍逻辑。新编一本通的内容依据只能来自指定教材、目标院校考纲、目标院校真题，以及有明确出处的出版教材或学术文献。
- 格式参考以 `27深大普心一本通（最新版）(1).docx` 为整体文档标准，重点参考封面、目录、页码、标题、正文、表格、字体、间距、logo/标签、边框和底色等格式，不参考其内容质量。Tips 呈现形式以负责人确认的 `references/format-samples/chapter-01-yibentong-v11-selective-tips.docx` 为固定标准；编制或审核 Tips 前同时读取 `tips-format-standard.md`。

## Compilation Process

1. Compare主体材料 with external materials and classify importance.
   - 条目一致: keep主体材料 content and its existing importance level.
   - 主体材料 has an item but external material does not: if 一级, keep but downgrade to 二级; if 二级, keep but downgrade to 三级; if 三级, delete. If no level is marked, judge from the parent item.
   - External material has an item but主体材料 does not: locate it in the textbook. If present, rewrite the textbook content by these content rules and add it. If not present, add it as `补充内容` only after verifying it in published textbooks or academic literature. Cite the source textbook/literature and page when available, or mark that no traceable source was found.
2. Compare the revised主体材料 with the textbook.
   - For every item, check whether points, terms, keywords, and meaning match the textbook.
   - If inconsistent, replace with a rewritten version based on textbook content and these content rules.
3. Compile content.
   - Split and layer long prose.
   - Bold keywords and underline key sentences.
   - Check typos.
   - Do not place editor rationale or task-process wording in the student-facing正文, such as “无真题支撑”“正文保留主线即可”“细节了解即可”“了解即可”“后续章节再展开”“本章先掌握”. These belong in the review file, internal notes, or should be expressed only through level marks and content compression.
4. Check past-exam questions.
   - If a target-school paper contains multiple subjects, first classify questions by subject and keep only the relevant subject questions for this 一本通 chapter. Use the answer substance, not surface keywords, to decide the subject.
   - Find all knowledge points touched by target院校历年真题.
   - Record each relevant question's year, type, score if available, subject, textbook chapter, and tested knowledge point.
   - Add true-question markers at the matching title or location.
   - If a true-question point is missing, locate it in the textbook, add it as正文, and mark it 一级.
   - All true-question knowledge points are 一级.
   - Use 312 and 泛347真题 only as auxiliary evidence for examability, common question forms, and 强二级 review; they do not create target-school真题 markers.
5. Final format and typo pass.

## Textbook-Based 347 一本通 Compilation Standard

When no existing 一本通 is available and the official textbook is the主体材料, compile according to the textbook's chapter order. Do not reorganize the document by official exam outline headings. Official outlines are usually broad and may span multiple textbook chapters; use them to judge importance only.

The target is an exam-facing考点筛选稿. 一本通 should stay close to textbook concepts and scoring language, but it should not preserve all textbook narration. A chapter output that is close to the length and narrative density of a textbook summary is too verbose.

### Screening Before Rewriting

For each textbook section, first decide whether the material is a testable knowledge point:

- Keep: definitions, classifications, core elements, processes, theories, representative figures, years, named tests/scales, key findings, advantages/disadvantages, applications, limitations, and points touched by true questions or official outlines.
- Compress: historical background, development context, author evaluation, transitional prose, long case descriptions, repeated explanations, and broad social/policy discussion.
- Delete: decorative narration, duplicated examples, low-yield lists with no exam value, details that do not help answer a likely question, and textbook paragraphs that only connect ideas without adding a scoring point.
- Keep as brief examples only: named examples that identify a category or make an abstract concept understandable.

### Structure Standard

After screening, rebuild the section around answerable layers rather than textbook paragraphs:

- Use `人物/事件/概念 -> 核心贡献/定义 -> 必要细节/例子` for history and development sections.
- Use `定义 -> 要素/分类 -> 特点/适用范围 -> 例子/评价` for concepts and theories.
- Use `步骤 -> 操作要点 -> 注意事项/评价` for procedures.
- Use tables or comparison structures when the textbook contrasts types, theories, tests, or indexes.

Each numbered point should carry one memorisable scoring point. If a paragraph contains several answer points, split it into `1.` / `（1）` / `①` layers. If a paragraph only explains background, compress it to one short sentence or remove it.

### Compression Benchmark

Use the compilation rules, textbook structure, target-school evidence, and leader-confirmed standards as the content benchmark. HF 一本通 samples are not content-quality benchmarks and must not be used to learn wording, level decisions, or取舍逻辑. For textbook history/development chapters, aggressive compression is expected: preserve people, years, named works/tests, and contributions; remove most story-like narration. If a compiled section reads like a cleaned textbook summary, review for over-retention.

### Example: History Chapter Screening

For a textbook chapter such as `心理测量和测验的历史回顾`, the expected output is not a full historical summary. Keep points like:

- 中国古代心理测量的三个前提;
- 孔子、孟子、刘劭、《学记》《礼记·本命》、科举、周岁试儿、七巧板、九连环 and their testable contributions;
- 艾斯克罗、塞甘、冯特、高尔顿、卡特尔、克雷丕林、艾宾浩斯 and their core contributions;
- 比奈—西蒙量表、1905年量表、斯坦福—比奈量表;
- 个别测验 vs 团体测验, 陆军甲种/乙种测验;
- 我国发展概述 only as high-level examinable features unless specific events are likely or真题-covered.

Remove or heavily compress long accounts of social context, institutional history, broad reflections, and policy discussion unless the user explicitly asks for a detailed history version.

For psychology考研 materials, `中国/中国古代/我国历史发展` content is non-core by default when there is no target-school true-question evidence. Process it conservatively: mark as 二级/三级, compress to high-level clues, or delete low-yield details according to examability. Do not add student-facing process reminders such as `了解即可` or `不展开背诵`; let the level mark and concise content selection carry the learning signal. If the target school has tested the exact point, mark that point 一级 and add the true-question marker.

## Importance Levels

- Importance levels describe estimated exam frequency and probability, not whether a point is absolutely testable. 一级 means a high-frequency point that is very likely to appear in real exams; 二级 means a medium-frequency point that is reasonably likely to appear; 三级 means a low-frequency point that can still be tested, but would usually feel偏、怪、难, or beyond the normal core scope.
- Prefer marking importance on second-level titles.
- Determine an upper-level item's importance from its lower-level content. For example, if most lower items are 一级, the parent should be 一级.
- If a third-level title has the same importance as its second-level parent, omit the repeated third-level mark.
- True-question knowledge points must be 一级.
- Summary principle: only mark exceptions when lower-level importance differs from the parent.

### Importance Evidence For 347 School-Specific Work

- 一级: high-frequency points that are very likely to appear in real exams, including points directly tested in target-school true questions and concrete core knowledge points inside the official outline scope, especially definitions, core classifications, major theories, representative scales/tests, procedures, formulas, reliability/validity indexes, and high-yield comparisons.
- 二级: medium-frequency points that are reasonably likely to appear in real exams, including important textbook content that supports 一级 clusters or has clear examinability, but is not directly true-question-covered and is less central than core definitions/classifications/theories.
- 强二级: a manual-review subset inside 二级. Use this label in the manager review file, not in the finished正文 title; in the finished product it remains marked 二级 unless the leader confirms upgrade. Typical cases include: official-outline-covered points with a stable question form but no direct true-question hit; textbook major subpoints that strongly support a 一级 cluster; points adjacent to repeated true-question themes; and points that could plausibly be upgraded to 一级 based on the leader's school-specific judgment.
- 三级: low-frequency points that can still be tested but would usually be偏、怪、难, or near the edge of the normal scope, including background, low-frequency history, broad development overview, minor scale descriptions, or content mainly for understanding.
- 中国/中国古代/我国历史发展类内容在没有目标院校真题支撑时，默认不作为重点。可按教材地位和可考性压缩为二级或三级；弱可考的细节可删除。正文不写“了解即可”“不展开背诵”等学习提示或编制过程话术；通过层级标注与内容压缩体现重要性。只有被目标院校真题实质考过的具体点才升为一级。
- Official outline evidence identifies important clusters. Do not automatically mark every subpoint under an outline-covered chapter as 一级.
- Official-outline-covered content should be at least 二级 by default. The main exception is 中国/中国古代/我国发展史等中国背景类内容: when there is no target-school true-question evidence, these can be marked 三级 or compressed according to examability.
- True-question evidence must be substantive. Only mark `【xx年真题】` when that exact knowledge point or its answer substance was tested; do not mark because the same person, school, or general topic appeared in another context.
- A lower-level title can be more important than its parent. For example, a parent history section may be 三级 while a specific figure/test inside it is 二级 or 一级.
- Every compilation delivery should separately list all 强二级 points for leader review. The list should include: knowledge point, textbook page/chapter location, current suggested level, reason for 强二级, possible question type, and whether it is a candidate for upgrade to 一级.

### Official Outline Three-Ring Rule

Official outline coverage means the knowledge cluster is important, but the outline is usually broad and does not make every subpoint 一级. For each outline-covered cluster, split textbook content into three rings before assigning levels:

- Core ring -> usually 一级: the cluster's definitions, core classifications, basic principles, important theories, formulas/indexes, procedures, representative tests/scales, high-yield comparisons, and any point that can independently form a stable exam question.
- Support ring -> 二级 or 强二级: important textbook subpoints that support the core ring, can appear as smaller short-answer/choice/judgment points, or sit close to repeated true-question themes but lack direct target-school evidence.
- Background ring -> usually 二级 if it is clearly inside the official outline, but heavily compressed. Mark 三级 only for 中国/中国古代/我国发展史等中国背景类内容 without target-school true-question support, or for content that is not truly covered by the outline after substantive mapping.

Use this rule together with target-school preference. If the target school repeatedly tests history, application, calculation, or case analysis, upgrade matching support-ring points to 强二级 or 一级 when evidence is strong enough.

### True-Question Profiling And Subject Filtering

Before judging importance for a school-specific 一本通, build a compact question profile from the provided true questions:

- Classify each question by subject. For a mixed 347 paper, include only questions whose answer substance belongs to the current subject. For 心理测量, include items such as psychological tests, measurement levels, reliability, validity, norms, item analysis, test construction, test ethics, classical test theory, modern measurement theory, and representative scales/tests.
- Mark cross-subject questions by dominant answer source. For example, a question using statistics to evaluate reliability can belong to 心理测量 if the scoring focus is reliability interpretation; a general hypothesis-testing calculation belongs to 统计心理学.
- Record question type: choice, judgment, term explanation, short answer, essay, case/material analysis, experiment design, calculation/application, or other observed forms.
- Build a target-school question-type inventory from all provided years before adding any question-type hint. The inventory is a boundary for the finished product: if the target school has never used a form such as case analysis, experiment design, or material analysis in the relevant paper/subject, do not label any knowledge point with that form in the成品正文. Recent years are the primary basis for probability and wording, but older observed question types must still be considered and can appear in hints, because schools often continue or revive old forms unless an official notice clearly cancels them.
- Map each relevant question to the smallest textbook knowledge point that supplies the answer. Use substantive match, not shared words.
- Use target-school true-question hits as decisive 一级 evidence and true-question markers. Do not create target-school true-question markers from 312 or other-school 347 questions.

### Chapter Evidence Table Before Drafting

Before writing the chapter正文, create an internal chapter evidence table. Use it to make level decisions visible and to reduce unsupported guessing. Include these fields when available:

- Knowledge point and textbook page/chapter location.
- Whether the point is in the official outline, and which outline cluster it belongs to.
- Target-school true-question evidence: year, question type, and answer substance.
- Auxiliary 312/泛347 evidence: source, frequency clue, and whether it only supports 强二级.
- Likely question type: choice, judgment, term explanation, short answer, essay, material/case analysis, experiment design, or calculation/application.
- Suggested level: 一级, 二级, 强二级 candidate, or 三级, with one short reason.
- Treatment decision: expand, keep concise, compress, delete, supplement, table, visual, or Tips.
- Uncertainty: source gap, ambiguous outline mapping, possible cross-subject point, or leader-confirmation need.

Use this table as the basis for the manager review file. The student-facing finished DOCX should not expose internal uncertainty notes.

### Question-Type Fit And Examability

When a point is not directly tested by the target school, first constrain possible question-type hints by the target school's observed true-question profile, then judge examability by the question forms it can naturally support. A natural question type that the target school has never used can support internal examability judgment or 强二级 discussion, but it should not appear as a finished正文 question-type hint.

- Term explanation: named concepts, theories, scales, indexes, effects, methods, and representative tests.
- Choice/judgment: concept boundaries, category membership, people/years, key features, advantages/disadvantages, and common misconceptions.
- Short answer: definitions plus elements, classifications, characteristics, influencing factors, functions, steps, applications, and contributions.
- Essay: theory comparisons, development logic, relationship辨析, integrated evaluation, and multi-part frameworks.
- Case/material analysis: test use, reliability/validity interpretation, norm interpretation, test construction decisions, ethics, and applied judgment.
- Calculation/application: score transformation, norms, item difficulty/discrimination, reliability coefficients, validity evidence, and measurement-level/statistical-method matching.

A knowledge point's level rises when it has stable question forms, clear scoring points, textbook emphasis, outline coverage, and target-school style fit. It falls when it is mostly narrative, lacks independent scoring points, or only appears as a remote background detail.

For example, if 深圳大学历年真题没有出现过案例分析题, then 深大一本通 should not mark non-true-question points as `案例分析`; choose among the school's observed forms such as选择、名词解释、简答、论述等, according to the actual paper profile. Keep absent-but-theoretically-possible forms in the manager review file only when they materially affect judging examability.

Use the likely question type to shape the正文 unit:

- Term explanations should include definition, core features, and one boundary/representative example only when useful.
- Short-answer points should be written as numbered scoring points, usually 3-5 points when the textbook supports them.
- Essay/material-analysis points should include logic chains, conditions, applications, advantages/disadvantages, or interpretation steps.
- Choice/judgment points should preserve exact people, years, scale names, first/representative status, category boundaries, and common misconceptions.
- Calculation/application points should preserve formulas, interpretation rules, prerequisites, and common error traps.

### Auxiliary 312 And 泛347 True-Question Evidence

Use 312 and 泛347真题库 to improve examability and question-type judgment, especially when the target school has few years of data:

- 312真题: good evidence for common psychology exam core concepts, standardized question forms, measurement/statistics/experiment applications, and stable high-yield definitions or comparisons.
- 泛347真题: good evidence for self命题院校 preferences, common applied/case/essay forms, and knowledge points repeatedly tested across schools.
- Auxiliary evidence can upgrade a point from ordinary 二级 to 强二级, or support a recommendation to upgrade to 一级 when it is also outline-covered and textbook-core.
- Auxiliary evidence should not override the target school's own true questions, should not reorganize the textbook, and should not be marked as target-school真题 evidence.

## Content Rewriting

- Avoid large unbroken paragraphs. Each paragraph should be no more than two lines; split and layer anything longer.
- Preserve textbook keywords and key sentences while reorganizing the expression into concise points.
- For textbook adaptation, reduce verbosity, keep the core meaning, and avoid adding unsupported claims.
- Do not treat external materials as authoritative when they conflict with the textbook.
- Rewrite after screening, not before screening. First remove low-yield material, then polish the retained points.
- Prefer concise formal answer language over continuous exposition. Good 一本通 paragraphs often look like answer outlines.
- Preserve exact names, years, works, scale names, theory names, and textbook judgments when they are likely scoring points.
- Do not add Tips, examples, or explanations merely to fill space. Add them only when they improve understanding or prevent common mistakes.

## Active Comparison And Visual Learning

- During compilation, actively scan for同类概念、相似概念、易混概念, not only concepts explicitly compared by the textbook.
- Apply an importance gate before adding any table or visual: the table/visual should normally contain and serve at least one 一级 knowledge point. 二级 points can be included when they help compare, support, or distinguish the 一级 point. 三级 points should only appear as necessary contrast labels/details; never create a standalone table, chart, or visual for pure 三级 content.
- If a candidate table/visual has no 一级 point, default to not making it. Keep ordinary 二级 material in concise正文; only consider a pure 二级 table/visual when it is 强二级, clearly compresses repeated prose, and the leader has reason to emphasize it. List such cases for manual review when unsure.
- Add comparison tables, flowcharts, or simple visual summaries when they help students compare and remember. Use tables for conceptual distinctions; use flowcharts for development sequences, procedures, and causal chains; use images only when they clarify spatial, process, or structure relations better than text.
- Present summary visuals, flowcharts, timelines, and comparison tables as `铁头tips` extensions placed directly after the relevant knowledge point. They are learning aids for梳理 and辨析, not standalone正文 sections.
- Good comparison candidates include: similar definitions, paired methods, scale/test variants, adjacent theories, people with overlapping historical contributions, formulas/indexes with similar uses, and concepts that target-school or auxiliary true questions often confuse.
- A comparison table should include stable comparison dimensions such as `核心含义`, `关键词`, `适用对象/场景`, `代表人物/量表`, `易混点`, and `记忆抓手`. Keep cells short and exam-facing.
- Prefer a table when the content is parallel and comparable across stable dimensions, such as concept distinctions, theory/person/scale comparisons, method advantages and disadvantages, applicable scenes, representative examples, formulas, indexes, or likely compare-and-contrast exam questions.
- Prefer a visual, flowchart, timeline, tree diagram, or model diagram when the content is sequential, hierarchical, causal, procedural, structural, or spatial, such as development stages, scale/test编制流程, classification systems, theory mechanisms, decision paths, or multi-step application procedures.
- If a section is labeled `图示`, `流程图`, `时间线`, or `图片`, render it as an actual image, Word drawing, or diagram-style object. Do not use a normal table under a `图示` heading. If the content is best rendered as a table, label it as `易混辨析`, `对比表`, or another table-appropriate heading instead.
- Design every visual for final black-and-white printing. Use grayscale or pure black/white, large readable type at the final inserted Word size, thick borders/arrows, clear numbering, and sufficient spacing. Do not rely on color differences alone. Before delivery, inspect the visual itself and confirm it remains legible when scaled to the document width.
- Do not add a separate image caption below inserted visuals unless the leader explicitly requests one. The Tips title should carry the function of the visual.
- Do not make a table or visual for a single standalone point, a simple one-dimensional list, a linear paragraph that is already clear, too many low-yield rows, or any format that would visually overemphasize low-frequency details.
- Do not add decorative tables. A comparison must reduce confusion, compress repeated prose, or improve answer organization.

## Bold And Underline

- Bold `keywords`: word-level or term-level scoring points, such as concepts, names, theories, scale names, methods, indexes, years, and fixed expressions.
- Underline `key sentences/key phrases`: answer-bearing sentence parts, clauses, or short sentences. A key sentence does not have to be a complete grammatical sentence; it can be the most important half sentence or phrase group inside a sentence.
- The practical test is extraction: if only the bolded keywords and underlined key phrases are read together, they should basically recover the paragraph's core content and answer logic.
- Do not include adjacent punctuation in bold or underline marks.
- If keywords are too dense in one sentence, do not bold every keyword; underline the key phrase/sentence segment that carries the complete point instead.
- Underlines should not be too long; keep each underline within about 1.5 lines. Avoid reflexively underlining whole sentences when a shorter clause is enough.
- Do not mix bold and underline randomly. Use bold for isolated terms; use underline for relational judgments, definitions, causal links, contribution statements, steps, or comparison conclusions.
- If a unit is an answer-bearing definition, judgment, boundary, cause-effect relation, or short scoring phrase, prefer underline. Use bold only for isolated terms, names, theories, scales, methods, years, indexes, and fixed labels.
- Self-check by reading only the bold and underlined fragments: they should reconstruct the core meaning of the paragraph without including process commentary or decorative noise.

## Tips

- Tips are selective learning aids, not mandatory blocks for every knowledge point. Do not add Tips merely to fill space.
- Tips priority 1: textbook experiments, small experiments, demonstrations, cases, or concrete research descriptions. If the relevant knowledge point has such content in the textbook, adapt it into a Tips block and mark the textbook page. This is the strongest and normally required Tips type.
- Tips priority 2: supplementary content. Use this when the target school has tested a knowledge point that is absent from the current reference textbook, or when a missing point is judged highly important. Check available HF/reference textbooks, cite the source textbook and page when available, and start the block with `补充内容：xxxx`. Compile the supplement with the same 一本通 standards: layered structure, concise wording, bold keywords, underlined key phrases, and only necessary examples.
- Tips priority 3: life-close examples. Add examples only when the concept is genuinely hard for normal Chinese undergraduate-level students without psychology background. Prefer 一级 points, then 二级 points; avoid tips for ordinary 三级 points unless the point is clearly difficult to understand.
- Life-close examples should use experiences most Chinese students have lived through, such as school exams, class ranking, choosing courses, family communication, shopping, social media, commuting, job interviews, or everyday interpersonal situations. Use exaggeration, metaphor, or contrast when it strengthens memory, but keep the psychological meaning accurate.
- Avoid obscure examples, irrelevant examples, forced analogies, or explaining one unfamiliar concept with another unfamiliar concept. If a knowledge point does not suit a clear example, skip the example.
- Tips should be `textbook experiment adaptation`, `supplementary content in Tips form`, `summary visual/comparison aid`, or `concrete example for understanding`. Do not use Tips for true-question reminders, answer strategies, broad summaries, motivational notes, or loose chapter-level comments. Put those in正文, 易混点, or delivery notes when needed.
- For history/factual 三级 points, usually do not create Tips. Keep the正文 concise, and avoid adding explicit process reminders such as `了解即可`.
- Tips spacing and style:
  - Leave one blank line before and after a Tips block.
  - The sample uses a visual `铁头tips` label, often implemented with a small textbox/shape; when generating DOCX programmatically, use a consistent visible `铁头tips` label and keep the content immediately below it.
  - If Tips has a title, bold and center it; if not, no title treatment is needed.
  - Examples should use `例如` and leave two spaces after it when the final document style requires it.
  - If two Tips blocks are adjacent, leave two blank lines between them.
  - If a Tips block is based on a textbook experiment, mark the lower-right page reference as `【科目+Pxx】`.
  - Leave two blank lines between tables and Tips.
- Tips visual format must match the leader-confirmed `chapter-01-yibentong-v11-selective-tips.docx` sample as closely as possible, while staying compatible with the broader 深大普心一本通 document style: upper-left `铁头 tips` identity, independent block body, centered bold Tips title when needed, border/fill/background, font size, spacing, and page-fit behavior are part of the requirement, not optional decoration. A plain table label is not enough when generating DOCX.
- Summary tables and visual comparisons should appear inside Tips-style blocks unless the leader explicitly requests a standalone正文 table.

## A4 Print Layout

- 一本通 final delivery is assumed to be A4 black-and-white double-sided printing unless the leader says otherwise.
- Avoid orphan headings: do not leave a title at the bottom of one page with its正文 starting on the next page.
- Keep each image, comparison table, Tips block, and supplement box together on one page when feasible. If it cannot fit, move the whole block to the next page rather than splitting it across pages.
- Anchor image text size to正文 readability after insertion into Word, not to the original PNG canvas size. If the image is hard to read at document width, simplify the text, enlarge the type, or change the layout before delivery.

## Supplementary Content

- Content not from the current textbook should be placed in a supplement box.
- Supplementary sources must be traceable, authoritative, and preferably published textbooks. Academic journal articles can be used when they are the best source for a tested or important point.
- Do not use online文库、咨询号、unverified web summaries, or unsourced notes as supplement sources.
- For common course areas, use same-domain textbook families when possible. For example, 普通心理学类 supplements should come from published textbooks such as `普通心理学`, `心理学导论`, or `心理学与生活`-type sources, rather than loose online explanations.
- Use a double-line box around supplementary content.
- Mark the upper-left label `补充内容：`.
- Supplementary content also needs key-point marking.
- If the source cannot be verified in mainstream textbooks, mark the uncertainty and ask the leader when it affects correctness.

## Title Levels And Numbering

- 一级标题: `第X 章 ×××××`; one space between chapter number and title; 宋体三号加粗居中.
- 二级标题: `一、×××××`; use 顿号, no extra space; 宋体四号加粗.
- 三级标题: `（一）×××××`; no 顿号 and no extra space; 宋体小四加粗.
- Deeper numbering:
  - `1.××××`: digit plus period; usually bold; leave one blank line before the next same-level item unless the content is very short or has no lower level.
  - `（1）××××`: no indent; no blank line between same-level titles.
  - `①`: indent one level.
  - `A.`: use only if the hierarchy needs another level; indent two levels.
  - `a.`: if `A.` is used, indent three levels.

## Punctuation And Sentence Layering

- Use Chinese punctuation: Chinese parentheses, comma, period, semicolon, and related marks.
- For layered knowledge points, use semicolons in earlier layers and a period at the final layer.

## Title Annotations

- Title annotation order: title + textbook page reference + importance level + true-question marker if any + question-type hint for 一级 points.
- Mark second- and third-level title page references to the textbook where applicable.
- True-question marker format: `【xx年真题】`.
- Put question-type hints in separate brackets after the true-question marker or after the level marker when there is no true-question marker. Example: `【20、23年真题】【选择/名词解释】`.
- Finished products should retain question-type hints for all 一级 knowledge points. If the point has target-school true-question evidence, use the actual true-question type. If the 一级 point has no target-school true-question evidence, use the judged likely question type according to examability and the target school's observed question-type boundary; do not add forms absent from that school's true-question profile.
- 二级/三级 likely question types should not appear in the finished正文 by default; keep them in the manager review file.
- If the same knowledge point appears in multiple years, list the years in order.

## Overall Formatting

- After compiling正文, Tips, and supplementary content, adjust format and apply title levels before final review.
- Recommended final order: apply title levels, mark second/third-level page references, mark true-question markers, mark importance levels, add page numbers, generate catalog, add cover.
- Cover, catalog, and page-number standards should follow the user-provided human sample `27深大普心一本通（最新版）(1).docx` when available; verify school, year, subject, and reference textbooks for the current project.
- Full document line spacing: 1.5.
- Body font: 宋体小四.
- Follow Chinese line-breaking habits and use proper first-line indentation.
- Each chapter starts on a new page.
- Page numbers begin from the first正文 page, excluding the catalog; page number font 宋体四号.
- Catalog title: 宋体一号居中.
- Catalog body: 宋体11号; first-level catalog entries bold; leave one blank line between chapters.
- Tips and supplementary content should avoid crossing pages. If only a short fragment spills over, move the whole block to the next page or adjust spacing if it does not hurt readability.
- Tables should follow the sample's font, border, fill, alignment, and compactness; they should be readable in A4 black-and-white printing and should not split across pages unless unavoidable.

## Self-Check And Two-File Delivery

Every delivery should go through self-check first, then provide two files unless the leader asks for a different format.

### File 1: Self-Checked Finished Product

Default format: DOCX. This is the student-facing 一本通成品 and should be clean enough for direct review or later排版合稿.

- Keep only student-facing content: title levels,正文, importance levels, true-question markers, retained question-type hints, Tips, tables/visuals, supplement blocks, and page references.
- Do not include internal notes such as `待确认`, `我判断`, `可能`, `无真题支撑`, `正文保留主线即可`, evidence scoring, or review comments inside正文 unless they are meant to appear in the final material.
- Before delivery, check source fidelity, no unsupported content, concise layering, keyword/key-phrase marking, Tips priority, table/visual placement, A4 print layout, and cross-page risks.

### File 2: Manager Review File

Default format: XLSX. Use DOCX/MD only when the leader requests it or when the chapter is too small to justify a spreadsheet. The review file exists to let the leader audit quickly without rereading the whole textbook.

The first/main sheet should make the leader's decision fast. For 一本通 level review, it should focus on 强二级候选是否升为一级/保留二级, not a flat dump of every 一级/二级/三级 item. Use supporting sheets for full evidence mapping and self-check details.

Include these sections:

- Materials used and missing materials.
- Chapter evidence table: knowledge point, page, outline mapping, target-school true-question evidence, auxiliary evidence, likely question type, suggested level, and treatment decision.
- 一级依据表: all 一级 points and whether the basis is target-school true question, outline core, textbook core, or leader-confirmed rule.
- 强二级复核表: all strong 二级 candidates, current正文位置, current level, why it is 强二级, target-school evidence, outline evidence, auxiliary evidence if used, likely question type, suggested decision, confidence, and manager confirmation column.
- Tips/visual/supplement decision log: type, location, reason, source/page, and skipped borderline candidates.
- Deletion/compression/downgrade notes: especially long background, 中国背景类 content, and low-yield historical details.
- Self-check results: pass/fail or short notes for evidence mapping, level logic, core正文 compilation quality, wording concision, bold/underline extraction, Tips, visual/table rules, supplement sources, formatting, and unresolved assumptions.
- Open confirmations: only issues that cannot be resolved from provided materials or HF sources.

### Self-Check Procedure

Run these checks before sending files:

- Source check: every retained substantive point can be traced to the target textbook, target-school true question, official outline, or cited supplementary source.
- Evidence check: target-school true-question points are 一级 and accurately marked; official-outline-covered content is at least 二级 except eligible 中国背景类 content.
- Subject check: mixed-paper true questions are assigned by answer substance, not superficial keywords.
- Question-type check: finished正文 question-type hints stay within the target school's observed true-question forms; absent forms such as 案例分析、实验设计、材料分析 are not used unless that school has actually tested them in the relevant paper/subject.
- Level check: 一级/二级/三级 reflect exam probability; all 强二级 points are listed for leader review.
- Structure check: textbook chapter order is preserved, but low-yield prose is compressed or deleted.
- Core正文 quality check: confirm the正文 has been compiled to the best attainable quality under the current materials and rules, not merely made compliant. Re-read each section for four failure modes: deletable content left in, splittable content not layered, awkward textbook language not rewritten, and answerable scoring points not made clear enough. Also check whether any 一级/二级 point would benefit from a better comparison, Tips, table, or visual, and whether any current expansion overstates a low-yield point.
- Writing check: paragraphs are short, layered, answer-like, and not simply cleaned textbook prose.
- Bold/underline check: reading only bold keywords plus underlined key phrases can recover the core answer logic.
- Tips check: Tips follow priority order and are not added merely to fill space; ordinary 三级 points usually have no Tips.
- Visual/table check: tables and visuals serve at least one 一级 point unless listed for review; diagrams are actual diagrams, readable in black-and-white, and placed inside Tips.
- Supplement check: missing but important/tested points are added as `补充内容：xxxx`, with traceable published textbook or academic literature source and page when available.
- Format check: title levels, page references, true-question markers, retained question-type hints, line spacing, cover/catalog/page-number sample standards, Tips logo/label, border/fill/background, table font/borders/fill, grouping, and cross-page risks are checked.
- Assumption check: any nontrivial guess is moved into the manager review file instead of silently entering the finished product.
