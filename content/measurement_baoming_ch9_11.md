# 第九章 量表与常模

## 一、原始分数、导出分数与测验量表【一级】

### 押题1【简答】简述原始分数、导出分数、测验量表和常模之间的**关系**。

测验实施后得到的原始分数本身缺少统一的参照点和单位，通常需要借助测验量表和常模转换为可以解释、比较的导出分数。

1. **原始分数**：原始分数是**实施测验后**，**根据测验指导书计算的分数**。【名词解释：原始分数】

2. **导出分数**：导出分数是**从原始分数转换而来的、具有一定参照点和单位的数值**。【名词解释：导出分数】

3. **转换目的**：导出分数既能指示个体在标准化样组中的位置，**也能为不同测验分数提供可以比较的量度**。

4. **测验量表**：测验量表是**根据测验的性质、用途和目标**，将某一标准化样组的原始分数转换为具有**单位、参照点和连续体**的导出分数。【名词解释：测验量表】

5. **常模**：常模是**标准化样组的测验作业情况**，**一般指常模团体的平均分数**。【名词解释：常模】它为导出分数的转换和**解释提供参照**。

6. **常模表**：常模表是用表格形式显示标准化样组的测验分数与量表分数之间对应关系的**工具**。【名词解释：常模表】

7. **解释方式**：导出分数既可以描述个体已经达到的发展水平，也可以**说明其在特定团体中的相对位置**。【扩容（选用）：**同一原始分数参照不同常模时**，可能转换成不同的导出分数。】

综上，原始分数是测验的直接结果，测验量表借助标准化样组和常模把它转换为有参照点和单位的导出分数，从而实现解释和比较。

## 二、常模与标准化样组【一级】

### 押题1【简答】简述标准化样组的**含义和基本条件**。

标准化样组是抽取具有研究特征的、能够**代表总体的一部分样组**。【名词解释：标准化样组】它的测验作业情况构成**解释个体分数的常模基础**。

1. **成员定义明确**：应清楚规定常模团体**包括哪些人**，使常模具有确定的适用对象。

2. **具有总体代表性**：标准化样组必须是**全域的代表性样组**，样本的重要特征应与所代表总体相符。

3. **取样过程清楚**：**应详细描述取样方法和过程**，以便判断样组是否存在系统偏差。

4. **样本规模适当**：样组应达到与总体和测验用途相适应的规模，**不能因样本过小造成不稳定**。

5. **具有时空限制**：标准化样组是**一定时间和空间的产物**，社会环境和群体特征变化后需要更新常模。

6. **常模类型结合**：既要考虑**适用范围**较广的一般常模，也要根据实际需要建立特殊常模。【扩容（选用）：地方性常模通常更能代表本地受测者的**实际情况**。】

综上，标准化样组必须定义清楚、具有代表性、取样透明、规模适当并说明时空范围，才能为测验分数提供可靠参照。

### 押题2【简答】简述常模的**相对性**，并比较常模与标准。

常模是**标准化样组的测验作业情况**，**一般指常模团体的平均分数**。【名词解释：常模】常模**反映特定群体在一定时空条件下的实际成绩**，因而**具有相对性**。

1. **依赖特定测验**：**测验分数必须伴随测验名称**，分数只能指代特定测验中的表现。

2. **依赖常模团体**：不同测验的内容、量表单位和标准化样本可能不同，**常模缺乏可比性时**，直接比较相对位置会得出错误结论。

3. **注意纵向比较**：个体不同时期的成绩只有在测验和常模**具有可比性时才能进行纵向比较**。

4. **重视特殊常模**：**一般常模未必适合所有地区和群体**，地方性常模可能更能代表本地情况。【扩容（选用）：解释分数时应同时说明常模团体、建立时间和**适用范围**。】

5. **常模与标准**：标准是**希望达到**的目标；常模是**某一群体的实际成绩**，可作为区别学生表现的参照。【扩容（选用）：常模回答“**与他人相比处于什么位置**”，标准回答“**是否达到预定要求**”。】

综上，常模不是绝对尺度，其解释依赖具体测验、常模群体和建立时间；标准表示目标要求，常模则表示群体实际表现。

## 三、发展性常模与发展量表【一级】

### 押题1【简答】比较智龄、年级当量和比率智商的**含义及局限**。

发展性常模用个体达到的年龄或年级发展水平解释测验成绩，常见形式包括智龄和年级当量；比率智商则进一步比较智龄与实龄。

1. **智龄**：**测题按年龄分组**，儿童通过相应测题所得分数代表其智力年龄；**智龄可以与实龄比较以衡量智力水平**，**但只能表示智力的绝对水平**，不能比较不同实龄儿童的智力高低。【名词解释：智龄】【扩容（选用）：智龄单位在不同年龄阶段并不**保持恒等**。】

2. **智龄的局限**：把题目分到不同年龄组的标准不统一，而且智龄单位不能**保持恒等**。

3. **年级当量**：年级当量是指**学生的成绩相当于某一年级学生的平均水平**。【名词解释：年级当量】年级常模可**由各年级学生在某测验上的平均原始分数得到**，并**用年级和月份表示**。

4. **年级当量的局限**：它容易被误解为学生可以完成相应年级的**全部学习任务**；跨领域比较同一学生的**年级当量也可能造成误解**。【扩容（选用）：年级间增长由少数测量点估计，连线**解释隐含了发展连续的假设**。】

5. **比率智商**：**由斯腾提出、推孟推广**，以**智龄与实龄的比率乘以100**表示智力的**相对水平**。【名词解释：比率智商】【扩容（选用）：**其公式为IQ＝MA／CA×100**。】

6. **比率智商的局限**：**高年龄儿童的计算方式不统一**；智力生长并非直线；各年龄组标准差不等时，相同比率智商也不一定**具有相同意义**。

综上，智龄和年级当量直观表示达到的发展水平，比率智商比较智龄与实龄，但三者都受到发展单位不等和适用范围有限的制约。

### 押题2【简答】简述发展量表的**优点和缺点**。

发展量表以年龄或年级等发展水平解释个体测验成绩，便于说明儿童在发展序列中的位置。

1. **易于理解**：**用年龄或年级表示测验成绩**，结果直观，容易向非专业人员说明。

2. **便于直接比较**：可以比较个体达到的发展水平与其实际年龄或年级之间的**差异**。

3. **支持个人内和纵向比较**：**能够比较同一个体不同领域的发展水平**，也可追踪其随时间发生的变化。

4. **适用特质有限**：**发展量表只适用于随年龄变化的特质**，对成人和不随年龄规律变化的特质不适用。

5. **环境适用有限**：**它主要适用于典型环境下成长的儿童**，特殊教育或文化环境可能影响解释。

6. **单位不相等**：不同年龄或年级之间的发展量表单位不**保持相等**，相差一个年龄单位未必代表相同的发展量。

7. **同分含义不等**：获得相同年龄分数的个体不一定具有完全相同的**智力水平或能力结构**。【扩容（选用）：发展量表应与其他常模分数和行为资料结合解释，**避免把年龄分数当作精确等距单位**。】

综上，发展量表直观并适合儿童发展比较，但其适用对象、环境和量尺单位均有限，不能把发展年龄作绝对、等距解释。

## 四、组内常模与标准分数【一级】

### 押题1【简答】组内常模指的是什么？请**举例说明**其应用。

组内常模是把**个体原始分数与常模团体中其他成员的成绩比较**，以说明个体在团体中**相对位置**的常模。【名词解释：组内常模】

1. **标准分数**：标准分数是**以标准差为单位**，表示个体原始分数与团体平均数之间距离的**导出分数**。【名词解释：标准分数】它**使不同测验或分测验的相对位置具有可比性**。

2. **离差智商**：个体智力测验分数在**同年龄组中的标准分数**，**由韦克斯勒在儿童智力量表中首先采用**。【名词解释：离差智商】【扩容（选用）：**常用形式为IQ＝100＋15Z**，表示个体相对同龄常模团体的位置。】

3. **转换方法**：韦克斯勒测验先把原始分数转换为平均数10、标准差3的常态化标准分数，**再汇合各年龄团体分数**，转换为平均数100、标准差15的离差智商。【扩容（选用）：斯坦福—比奈量表**采用平均数100、标准差16**。】

4. **应用实例**：某儿童在同年龄常模中获得离差智商115，表示其成绩高于同龄组平均数一个标准差，而不是表示其智力是**平均儿童的1.15倍**。

5. **解释限制**：组内常模只**说明个体在特定常模团体中的相对位置**，常模团体或**建立时间改变**，分数含义也可能改变；离差智商对极端智力者的评分还可能存在偏差。

综上，组内常模通过标准分数说明个体在常模团体中的相对地位，离差智商是其典型应用，但不能作绝对倍数解释。

# 第十章 测验的编制和修订

## 一、测验编制的一般程序【一级】

### 押题1【论述】论述心理测验编制的**一般程序**。

心理测验的编制是从明确测量目的和对象出发，经过产生与筛选测题、标准化、建立常模、鉴定测量特征并编写指导书的系统过程。

1. **确定编制目的**：

（1）**明确测验用途**：确定要测量的心理结构或心理特质，并判断编制常模参照测验还是**标准参照测验**。

（2）**明确测验对象**：规定**测验适用人群及其年龄、教育和其他重要特征**。

（3）**分析测量目标**：**确定能够表征目标心理结构的行为**，并规定每类行为在测验中的项目比例。【扩容（选用）：可以借助双向细目表协调测验内容、学习结果和项目权重。】

2. **产生测题**：

（1）**确定题目形式**：根据**测量目标选择选择型题目或供应型题目**。

（2）**初步组成题库**：初选题目数量通常为测验计划题量的**2—3倍**。

（3）**检查并修改测题**：检查题目的**技术性问题、有效性和可信度**，进行初步修改。

（4）**预测和项目分析**：**在小样本中试测**，根据结果分析项目难度、鉴别力等指标并筛选题目。

（5）**选择和编排测题**：优先**选择鉴别力高的项目**，调整各类题目比例和数量，并避免相同答案选项连续排列。

3. **测验标准化**：指测验的**内容、实施、记分和分数解释的一致性**。【名词解释：标准化】

（1）**测验内容标准化**：**不同被试接受相同或等值的测验内容**。

（2）**施测条件标准化**：**保持相同的情境、指导语和时限**。

（3）**评分规则标准化**：**采用统一规则，确保评分结果客观**。

（4）**测验常模标准化**：**提供可以比较测验分数的参照点**。【扩容（选用）：标准化**使不同被试的测验分数具有可比性**。】

4. **建立测验量表和常模**：把标准化样组的原始分数转换为**具有单位和参照点的导出分数**，为测验分数建立解释依据。

5. **鉴定测验基本特征**：**考察项目鉴别力、难度分布、信度和效度**，确认测验达到预定质量要求。

6. **编写测验指导书**：说明测验目的和功用、理论背景和材料选择原则、实施方法、标准答案和记分标准、常模表和结果解释、难度与鉴别力及信效度等基本特征，以及**测验结果的应用方法**。

综上，测验编制必须使目的、项目、施测、评分和解释相互衔接，并用项目分析、信度、效度和常模证据保证成品的标准化与可用性。

# 第十一章 测验的使用

## 一、测验的施测【二级】

### 押题1【简答】简述测验施测前和施测过程中应注意的**主要事项**。

测验施测必须遵循测验手册规定的标准程序，并在准备充分、指导语统一和主试保持中立的条件下进行。

1. **熟悉测验**：主试在施测前应熟悉测验的结构、内容及**使用方法**，避免因程序不熟造成错误。

2. **准备材料**：施测前备齐题本、答卷、计时和其他测验材料，并**检查测验环境**。

3. **核对被试资料**：**认真核对被试年龄**；**对于年龄较小的儿童**，应向家长或教师询问并确认。

4. **统一指导语**：指导语是**告诉被试如何对测题作出反应**的说明。【名词解释：指导语】它帮助被试理解测验并**影响其反应态度和方式**，主试应准确呈现并**保持中立**，防止暗示。

5. **遵循施测顺序**：有效结果**依赖标准程序**，主试应按手册规定的顺序、时限和操作要求完成施测。

6. **建立协调关系**：主试与被试之间良好的协调关系有助于**获得合作和更多有效信息**，但不能以提示或诱导改变被试反应。【扩容（选用）：对儿童或特殊对象施测时，**建立合作关系尤其重要**。】

综上，规范施测要求主试做好人员、材料和程序准备，统一指导语和顺序，并在良好合作关系中保持客观中立。

## 二、测验结果的报告【二级】

### 押题1【简答】简述心理测验结果**分析、解释和报告**的基本要求。

心理测验结果受测量误差和常模参照影响，报告时应进行综合分析，用受测者能够理解的语言说明分数含义并提出适当建议。

1. **按范围解释分数**：测验分数受测量误差影响，表示一个可能的波动范围，而不是**完全确定的数值**。

2. **不绝对化单次结果**：**单次测验只能提供有限证据**，不能据此对个体能力、人格或发展作绝对结论。

3. **正确认识测验作用**：**主试不能唯分数论**，应结合测验目的、信效度和其他评价标准作出判断。

4. **综合多类资料**：分析时应参照访谈、观察、学习或工作表现等资料，同时兼顾个体间差异和个体内部不同方面的**差异**。【扩容（选用）：不同资料结论不一致时，**应查明测验情境、常模适用性和个体状态**。】

5. **报告解释而非裸分**：不宜只把测验分数直接告知受测者，而应**说明分数所代表的相对位置、可能范围和实际意义**，并给出相应建议。

6. **使用通俗语言**：尽量**避免专业术语，防止误解**；确需**使用术语时**，应同时提供通俗解释。

7. **内容简洁完整**：简洁**说明测验内容、分数含义、可能误解及运用方式**。

综上，测验报告应把分数放在误差、常模、测验目的和多种资料中综合解释，做到准确、通俗、审慎并具有实际指导意义。
