# 第一章 心理测量和测验的历史回顾

## 一、心理测量和测验的发展主线【二级】

### 押题1【简答】简述心理测量和测验发展中的**代表性事件及其意义**。

心理测量和测验的发展，是心理差异可测思想、个别智力测验和团体测验逐步走向科学化、标准化的过程。

1. **心理可测思想**：心理测量的完整实践需要**肯定心理的可测性、确定测量内容**，并在阐明心理内容的特性或差异性的基础上**形成具体测量方法**。【扩容（选用）：中国古代已经**产生了对人才进行评定和选拔的心理测量实践**。】

2. **比奈的贡献**：比奈是**心理测验鼻祖**，发表《智力的实验研究》，并与西蒙编制了世界上第一个智力测验量表——比奈—西蒙量表。【扩容（选用）：该量表**使智力差异开始通过标准化任务加以评估**。】

3. **斯坦福—比奈量表**：推孟在比奈—西蒙量表基础上发布S—B量表，**推动了智力测验的修订与推广**。【扩容（选用）：1916年第一版首次**采用智商分数的概念**。】

4. **团体测验的产生**：“**陆军A式量表**”是**文字测验**，“陆军B式量表”是非文字测验，二者推动心理测验由个别施测走向团体施测。【扩容（选用）：**团体测验可以同时施测许多人**，并简化指导语和施测程序。】

综上，比奈—西蒙量表奠定个别智力测验基础，斯坦福—比奈量表推动其标准化发展，陆军A式和B式量表则扩大了团体测验的应用范围。

# 第二章 心理测量和测验的一般介绍

## 一、测量的含义与基本要素【一级】

### 押题1【简答】简述测量的**含义、构成和基本要素**。

测量是**按照一定的法则**，用数字方法对**事物的属性进行描写**的过程。【名词解释：测量】【扩容（选用）：测量包括**对象、规则和结果三个构成部分**。】

1. **参照点**：**要确定事物的量**，**必须有一个计算的起点**，**这个起点称为参照点**。【名词解释：参照点】

（1）**绝对零点**：表示“无”的零点，如测量轻重、长短时**使用的零点**。【扩容（选用）：绝对零点**使测量结果可以进行倍数比较**。】

（2）**相对零点**：**人为规定的参照点**，不表示被测属性完全不存在。【扩容（选用）：例如，摄氏温度的零点是人为规定的相对零点（例子可灵活替换）。】

2. **单位**：单位是**测量的基本要求**，**没有单位就无法进行测量**；理想单位应当具有**确定的意义和相等的价值**。【名词解释：单位】【扩容（选用）：单位等值是对**测量结果进行数量比较的重要条件**。】

3. **误差与精确程度**：测量总有误差存在，**误差越大，精确程度越低**；测量的精确程度会受到对象属性、工具和目的影响。【扩容（选用）：因此，测量结果应结合工具条件和误差范围解释。】

综上，测量以一定法则将事物属性数量化，并以参照点和单位为基本要素，测量质量还受到误差大小的制约。

### 押题2【简答】简述四种测量水平，判断**心理量表的水平**并说明如何获得**等距性**。

量表是指把**事物的属性**表现在一个定有**参照点和单位的连续体**。【名词解释：量表】

1. **类别量表**：**根据事物的某一特点对事物属性进行分类**，**用数字或符号表示**，**只能区别不同类别**。【名词解释：类别量表】【扩容（选用）：**数字在类别量表中只起命名作用**，不能表示大小或数量。】

2. **等级量表**：根据事物某一特点将事物属性分成等级，用数字表示；既可区别类别，又可排出**等级或顺序**，但**不具有等距性**。【名词解释：等级量表】【扩容（选用）：名次只能表示先后，不能**说明相邻名次之间的差距相等**。】

3. **等距量表**：对事物属性的划分是等距的，具有**相等单位**，但**没有绝对零点**；**可以进行加减运算**，不能进行乘除运算。【名词解释：等距量表】【扩容（选用）：摄氏温度**属于等距量表**，因为相邻温度差相等而零点不表示没有温度（例子可灵活替换）。】

4. **等比量表**：**最高水平的测量**，既具有**相等单位**，又具有**绝对零点**，可以进行加减乘除运算。【名词解释：等比量表】【扩容（选用）：身高和反应时均**具有绝对零点**，可以进行倍数比较（例子可灵活替换）。】

5. **心理量表的水平**：心理测量通常只具有等级量表的特征，但可以通过把原始分数转换成**标准分数**，将其作为等距量表进行统计处理。【扩容（选用）：这种转换建立的是**分数解释上的等距单位**，并不使心理属性获得绝对零点。】

综上，四种量表依次增加顺序、等距和绝对零点等性质；心理量表通常属于等级水平，可借助标准分数转换获得统计处理所需的等距性。

## 二、心理测量的含义与特点【一级】

### 押题1【简答】简述心理测量的**含义、可能性、特点和测量水平**。

心理测量是指根据一定的法则，用数字对**人的行为加以确定**，即依据一定的心理学理论，**使用一定的操作程序**，给人的行为和心理属性确定出一种**数量化的价值**。【名词解释：心理测量】

1. **心理测量的可能性**：**任何现象只要客观存在**，**就总有数量性质**；凡有数量的现象，都可以测量。【扩容（选用）：这一观点分别**由桑代克和麦柯尔提出**，为心理属性的数量化提供了思想基础。】

2. **间接性**：心理属性不能被直接测得，只能通过个体在测验中的**代表性行为反应**加以推测。【扩容（选用）：例如，智力不能直接观察，但可以根据智力测验任务的反应推断（例子可灵活替换）。】

3. **相对性**：心理**测量没有绝对的标准和绝对零点**，测量结果必须放在一定参照系统中解释。【扩容（选用）：同一原始分数在不同常模团体中可能代表不同的**相对位置**。】

4. **测量水平**：心理测量通常只具有**等级量表**的特征，可以通过转换成标准分数，作为等距量表进行统计处理。【扩容（选用）：心理**测量结果可以比较相对高低**，但一般不能作绝对倍数解释。】

综上，心理测量通过行为对心理属性进行间接数量化，其结果具有相对性，通常处于等级测量水平。

## 三、心理测验的含义与基本条件【一级】

### 押题1【简答】简述心理测验的**含义、三要素和客观性指标**。

心理测验是对**行为样组**进行的**客观和标准化的测量**。【名词解释：心理测验】

1. **行为样组**：**选择具有代表性的部分行为进行测量**，以推论人的心理特性。【扩容（选用）：由于无法**测量所有相关行为**，行为取样必须能够代表所要解释的行为领域。】

2. **标准化**：指测验的**内容、实施、记分和分数解释的一致性**。【名词解释：标准化】

（1）**测验内容标准化**：**不同被试接受相同或等值的测验内容**。

（2）**施测条件标准化**：**保持相同的情境、指导语和时限**。

（3）**评分规则标准化**：**采用统一规则，确保评分结果客观**。

（4）**测验常模标准化**：**提供可以比较测验分数的参照点**。【扩容（选用）：标准化**使不同被试的测验分数具有可比性**。】

3. **客观性**：测验结果**不受主观因素影响**，并**具有重复性**。【扩容（选用）：客观性贯穿测题、施测、记分和**解释等环节**。】

4. **客观性指标**：信度**反映测验结果的可靠程度**，效度反映测验实际测出所测特性或功能的真实性程度，难度与鉴别力分别反映测题的难易水平和区分不同水平被试的程度。【扩容（选用）：一般而言，中等难度的项目**具有较高鉴别力**。】

综上，科学的心理测验必须以代表性行为样组为对象，遵循标准化程序，并通过信度、效度、难度和鉴别力等指标检验其客观性。

## 四、心理测验的种类与应用【二级】

### 押题1【简答】简述心理测验的**主要分类及应用**。

心理测验可以按照**测量对象、施测人数、测验材料和记分方式**进行分类，并服务于个体差异评估和实践决策。

1. **按测量对象分类**：认知测验包括**智力测验、能力倾向测验、教育测验和创造力测验等**；人格测验测量个性中除能力以外的性格、情绪等个性心理特征及其相关行为。【扩容（选用）：前者主要测量能力表现，后者主要**测量非能力人格特征**。】

2. **按施测人数分类**：个别测验由一名主试在一段时间内**测量一名被试**，便于详尽观察和控制，但费时费力、对主试要求高；团体测验由一位主试同时**测量多人**，省时省力且容易建立常模，但不易控制个别行为，容易产生测量误差。

3. **按测验材料分类**：**语言或文字测验以语言文字呈现并作答**，能够**测量高层次心理功能**，但容易受到语言、文化和教育背景影响；非语言测验以图画、符号或实物为材料，适用于语言困难者和跨文化比较，但施测较费时。【扩容（选用）：瑞文测验是典型的**非文字智力测验**。】

4. **按记分方式分类**：客观测验**具有明确记分标准**；**非客观测验没有固定标准答案**，评分容易受到评分者宽严程度影响。

5. **主要应用**：心理测验可用于**了解个别差异，诊断、预测和评价，甄选、分类和安置**，并为心理辅导、心理咨询以及心理和教育科研提供辅助。【扩容（选用）：测验结果应与访谈、观察和其他资料结合使用，**不能作为唯一决策依据**。】

综上，不同测验类型各有适用对象和条件，实际应用时应依据测量目的选择适当工具并规范解释结果。

# 第三章 智力测验

## 一、智龄、比率智商与离差智商【一级】

### 押题1【简答】比较**智龄、比率智商和离差智商**的含义及特点。

**智力测验指在一定条件下**，使用特定的**标准化测验量表**对被试施加刺激，从被试的反应中**测量其智力高低的过程**。【名词解释：智力测验】

1. **智龄**：**测题按年龄分组**，儿童通过相应测题所得分数代表其智力年龄；**智龄可以与实龄比较以衡量智力水平**，**但只能表示智力的绝对水平**，不能比较不同实龄儿童的智力高低。【名词解释：智龄】【扩容（选用）：智龄单位在不同年龄阶段并不**保持恒等**。】

2. **比率智商**：**由斯腾提出、推孟推广**，以**智龄与实龄的比率乘以100**表示智力的**相对水平**。【名词解释：比率智商】【扩容（选用）：**其公式为IQ＝MA／CA×100**。】

（1）**优点**：**能够比较不同实龄儿童的智力高低**，弥补智龄只能表示绝对水平的不足。

（2）**局限**：假定智力随年龄等速增长，但实际智力增长存在高原期，因此不适合**解释高年龄个体的智力**。

3. **离差智商**：个体智力测验分数在**同年龄组中的标准分数**，**由韦克斯勒在儿童智力量表中首先采用**。【名词解释：离差智商】【扩容（选用）：**常用形式为IQ＝100＋15Z**，表示个体相对同龄常模团体的位置。】

综上，智龄表示年龄量表上的绝对发展水平，比率智商比较智龄与实龄，离差智商则依据同龄常模中的相对位置解释智力。

## 二、斯坦福—比奈智力量表【一级】

### 押题1【简答】简述第四版斯坦福—比奈智力量表较前几版的**改进及保留的合理成分**。

第四版斯坦福—比奈智力量表在理论框架、测验内容、题型、施测程序和心理计量观念方面进行了改进，同时保留适应性测验等合理成分。

1. **理论框架改进**：**采用三层次阶梯模式**，第一层为一般智力因素，第二层包括**晶体能力、流体—分析能力和短时记忆，第三层包括语言推理、数量推理和抽象／视觉推理**。【扩容（选用）：这一框架把一般智力、较宽能力和具体能力结合起来。】

2. **测验内容改进**：测验内容更广，并**采用分测验形式**，能够评估语言推理、数量推理、抽象／视觉推理和短时记忆四大领域的技能。

3. **分数解释改进**：提供多种分数，并附有常模，**使智力评价不再局限于单一总分**。【扩容（选用）：多种分数有助于分析个体内部不同认知能力的**发展特点**。】

4. **施测方式改进**：**施测更具弹性**，主试可根据受测者表现**分阶段进行施测和计分**。

5. **保留合理成分**：保留适应性测验，**使测题能够依据被试能力水平进行调整**。【扩容（选用）：**量表适用于2岁幼儿至成人**，可用于鉴别智力落后、学习障碍和智力超常。】

综上，第四版以层次理论和多领域分测验拓展智力测量，同时保留适应性施测，兼顾测量广度与个体差异。

## 三、韦克斯勒儿童智力量表【一级】

### 押题1【简答】简述韦克斯勒儿童智力量表的**主要特点及发展变化**。

韦克斯勒儿童智力量表是以儿童为对象的个别智力测验，其发展体现了由言语—操作结构向多指数认知能力结构的变化。

1. **广泛运用**：**WISC—R常被作为标准**，对其他智力测验进行效度检验。

2. **年龄范围衔接**：**WISC—R适用于6—16岁儿童**，WPPSI适用于4—6岁儿童，WAIS适用于16岁以上个体。【扩容（选用）：三个量表共同覆盖从学前儿童到成人的**不同年龄阶段**。】

3. **结构特点**：WISC—R兼有**语言测验和操作测验**，能够从不同任务形式评估儿童智力。

4. **分数特点**：WISC—R首次在儿童个别测验中采用**离差智商**，依据同年龄组常模解释个体智力水平。

5. **后续发展**：WISC—Ⅲ建立新常模并增加分测验；WISC—Ⅳ提供超越单一IQ的信息；WISC—Ⅴ加强与CHC智力理论的统一，提供**言语理解、视觉空间、流体推理、工作记忆和加工速度**五大指数。【扩容（选用）：这种变化**使量表能够更细致地描述儿童的认知能力结构**。】

综上，韦克斯勒儿童智力量表以多任务结构和离差智商为基础，后续版本不断更新常模并加强理论化、多指数化解释。

## 四、瑞文测验【二级】

### 押题1【简答】简述瑞文测验的**性质、类型、适用范围和局限**。

瑞文测验是一种**非文字的智力测验**，**主要通过图形材料评估个体智力**。【名词解释：瑞文测验】

1. **主要类型**：瑞文测验发展出**标准型、彩色型、高级型和联合型**四种形式。

2. **测验材料**：联合型**由渐进矩阵标准型和彩色型联合而成**，难度分布较为合理。

3. **适用范围**：**适用于5—75岁个体**，**可以进行团体施测**；也适用于言语障碍者，并可作为跨文化研究工具。【扩容（选用）：**它尤其适合大规模智力筛选和初步分等**。】

4. **主要局限**：瑞文测验侧重非文字推理，**不能完全代替多面相智力测验**。【扩容（选用）：需要全面诊断智力结构时，**应结合其他智力测验和背景资料**。】

综上，瑞文测验具有非文字、适用范围广和便于筛查等特点，但不能单独反映智力的全部方面。

## 五、传统智力测验的评价与发展【一级】

### 押题1【论述】论述传统智力测验的**优点、应用和局限**，并说明智力测验的发展方向。

传统智力测验以标准化量表测量个体智力水平，在教育与临床实践中具有重要价值，但也存在测量范围和文化适用性等局限。

1. **标准化程度较高**：智力测验通过严格筛选测题、抽取标准化样组、**建立常模、检验信效度并制定统一施测手册**，保证测验程序和结果具有较好的可比性。【扩容（选用）：**标准化是智力测验能够大规模应用的基础**。】

2. **能够有效评价智力水平**：**测题可以考察多种能力**，测验分数又能与同龄常模比较，从而快速评定个体的相对智力水平。

3. **教育应用广泛**：**智力测验可用于学生的选拔和安置**，筛查学习困难、诊断原因并制定补救计划，也可用于评价教育研究和教学干预的成效。【扩容（选用）：测验结果应服务于教育决策，而**不能成为给学生贴固定标签的依据**。】

4. **量化分析的局限**：传统智力测验偏重量的分析，难以充分说明个体解决问题时采用的**认知过程**和策略。

5. **发展观点不足**：传统测验往往根据某一时点的表现评价智力，**未能充分考虑智力发展的动态变化**。【扩容（选用）：单次测验结果还会受到测量误差、动机和情境影响。】

6. **测量范围有限**：传统测验只能**反映智力的部分方面**，较多考察收敛性思维，对创造性和实践性能力关注不足。

7. **文化影响明显**：**测题可能受到语言、知识和教育经验影响**，跨文化比较时需要警惕文化偏差。【扩容（选用）：文化公平并非完全消除文化影响，而是**尽量减少与测量目标无关的文化负荷**。】

8. **理论发展方向**：现代智力测验逐步吸收流体—晶体智力理论、智力层次结构理论和CHC三层级理论，并关注三重结构理论和PASS模型，使测量由单一总智商走向**多维认知能力结构**。【扩容（选用）：新版斯坦福—比奈和韦克斯勒量表都体现了理论化、多指数化的发展。】

综上，传统智力测验的标准化和常模化使其具有较强实践价值，但必须结合发展、认知过程和文化情境解释，并通过多维理论和多种资料提高评价的全面性。
