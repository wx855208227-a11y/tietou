# HuggingFace 心理学资料库整理思路

本文档用于后续继续整理 `wx855208227/tietou` HuggingFace 数据集。目标不是单纯把文件分文件夹，而是让后续一本通编制时可以快速定位：目标院校教材、官方考纲、目标院校真题、已有一本通样例，以及公共题库辅助材料。

## 核心原则

1. 先按使用场景分类，再按院校、材料类型、科目、年份细分。
2. 院校专属材料和公共题库材料必须分开。公共 312/泛 347 题库只能辅助判断可考性和题型，不能混入目标院校真题文件夹。
3. 编制一本通时，教材是正文主体来源，考纲用于划分范围和重要性，目标院校真题用于一级考点和题型标注，已有一本通用于学习格式和风格。
4. 文件移动、删除、批量改名之前，先给主管确认整理方案。目录层级复杂时优先发图片或表格，不只发纯文本树。
5. 不为整理目录而下载大 LFS 文件。能通过文件名、目录上下文、LFS pointer、文件大小和历史路径判断的，优先用这些信息。
6. 不上传、打印或提交 HF token、GitHub token、临时 askpass 脚本等凭证。

## 标准目录

```text
院校资料库/
  347应用心理专硕/
    <院校>/
      教材/<科目>/...
      考纲/[年份]/...
      真题/<年份或范围>/...
      一本通/<科目>/...
      报考信息/...
公共题库/
  312心理学统考/...
  347应用心理专硕/...
编制规范/
  一本通编制要求/...
索引/
  资料目录.tsv
  清理记录.md
  HF资料整理思路.md
```

## 新增文件判断顺序

1. 判断是否为院校专属材料。
   - 能对应到具体院校的教材、考纲、真题、一本通、招生或报考信息，放入 `院校资料库/347应用心理专硕/<院校>/`。
   - 不区分院校、面向 312 或泛 347 的真题合集，放入 `公共题库/`。
   - 一本通编制规则、样式要求、内部流程说明，放入 `编制规范/` 或 GitHub 项目技能文档。
2. 判断材料类型。
   - `教材`：官方参考教材、电子教材、出版教材扫描件。按科目建子目录。
   - `考纲`：官方考试大纲、考试范围、招生目录中明确考试范围的文件。年份明确时放入年份目录。
   - `真题`：目标院校历年真题、真题解析、答案、回忆版。按年份或年份范围建目录。
   - `一本通`：机构已有一本通、样例、历史版本。按科目建子目录。
   - `报考信息`：招生简章、报录比、培养方案等背景资料。不能当作考纲证据。
3. 判断科目。
   - 以院校参考书或文件名中的科目为准，例如 `普通心理学`、`心理学导论`、`实验心理学`、`心理统计学`、`测量心理学`。
   - 同一本书在不同院校作为不同科目使用时，按目标院校各自保存，必要时保留重复引用。
4. 判断年份或范围。
   - 单年材料放 `2026/` 这类目录。
   - 多年合集放 `2019-2026/`、`汇总/` 或原文件明确的范围目录。
   - 年份不明确但属于某批资料的，先按上传上下文归入合理范围，并在 `索引/清理记录.md` 写明不确定点。
5. 无法可靠判断时，不硬放进正式目录。
   - 院校明确但科目或类型不明确，放 `院校资料库/347应用心理专硕/<院校>/待整理/`。
   - 院校也不明确，放顶层 `待整理/`，并在清理记录中列出需要主管确认的问题。

## 命名规则

1. 目录名使用中文全称，优先保持院校和科目标准名称稳定。
2. 文件名可以适度规范化，但不要为了整齐而丢失原始信息。
3. 教材建议格式：`<院校简称><科目>_<版本/作者/出版社信息>.<ext>`。
4. 考纲建议格式：`<院校简称><年份>347考纲` 或保留官方标题。
5. 真题建议格式：`<院校简称><年份>347真题[_解析/答案/回忆版]`。
6. 一本通建议格式：`<年份或届别><院校简称><科目>一本通[_版本说明]`。
7. 不确定是否为同一内容时，不进行覆盖式改名；保留原文件并在索引备注。

## 去重和清理规则

1. `.DS_Store`、`test.tmp`、解压残留、空临时目录可以清理，并加入 `.gitignore` 防止再次上传。
2. 删除重复文件前必须确认规范路径中仍保留同一内容。
3. 大文件优先用 `git lfs ls-files` 的 LFS object id 判断是否完全相同；必要时再比较文件大小、checksum 或抽样内容。
4. 同名但内容不确定的文件不要删除。可以保留两个版本，并在 `索引/资料目录.tsv` 或 `索引/清理记录.md` 标注差异待确认。
5. 旧路径重复项删除后，要在清理记录中写明旧路径、新路径和判断依据。

## 索引维护

每次整理后更新 `索引/资料目录.tsv`，至少保留以下信息：

```text
用途	院校	材料类型	科目/主题	年份/范围	文件路径	备注
```

填写口径：

1. `用途`：院校资料库、公共题库、编制规范等。
2. `院校`：院校全称；公共材料写 `公共`。
3. `材料类型`：教材、考纲、真题、一本通、报考信息、编制规范。
4. `科目/主题`：普通心理学、测量心理学、312统考、泛347真题等。
5. `年份/范围`：单年、年份范围、汇总或不明。
6. `文件路径`：HF 数据集内的相对路径。
7. `备注`：官方原版、批注版、答案、解析、来源不明、待确认等。

`索引/清理记录.md` 记录每轮整理动作：移动数量、删除数量、重复判断依据、保留的不确定项和后续注意事项。

## 一本通调用关系

整理目录时要服务于一本通编制流程：

1. 先定位 `院校资料库/347应用心理专硕/<院校>/教材/<科目>/`，作为正文编制主体。
2. 再读取该院校 `考纲/`，确认官方覆盖范围和二级以上考点范围。
3. 再读取该院校 `真题/`，筛出目标科目的题目，映射一级考点和实际题型。
4. 再读取该院校已有 `一本通/<科目>/`，学习格式、取舍和表达，但不能机械复刻。
5. 最后读取 `公共题库/312心理学统考/` 和 `公共题库/347应用心理专硕/`，辅助判断强二级、题型和可考性。

## 每次整理前后的流程

1. 整理前生成当前文件清单和根目录结构快照。
2. 初步分类新增文件，列出计划移动、改名、删除和待确认项。
3. 如果涉及批量移动、删除、目录结构调整或不确定归类，先把方案发给主管确认。
4. 主管确认后再执行移动、改名、清理和索引更新。
5. 执行后做验证：
   - `git status --short`
   - 文件总数前后对比
   - `.DS_Store`、`test.tmp` 数量为 0
   - `git lfs ls-files` 数量和重复对象核查
   - 根目录和院校目录结构可读
   - `索引/资料目录.tsv` 可检索、字段不乱列
6. 验证通过后提交并推送 HF 数据集。
7. 在 GitHub 项目任务记录中写明 HF commit、整理范围、验证结果和残留风险。

## 需要主管确认的情况

1. 文件无法判断院校、科目、年份或材料类型。
2. 同一文件疑似多版本，但无法确认哪个是官方原版。
3. 材料看起来像考纲，但来源只是招生信息或机构整理。
4. 真题文件同时包含多个科目，且无法从文件名判断是否需要拆分或标注。
5. 要删除的文件不是确定的上传噪声或精确重复项。
6. 新增材料类型超出当前目录体系，例如课程讲义、内部题库、速背手册、视频课配套资料等。

## 当前默认判断

1. 官方考纲、考试范围优先放入 `考纲/`；招生简章和报考说明默认放 `报考信息/`，除非文件内明确包含考试范围。
2. 目标院校真题解析和答案仍属于该院校 `真题/`，但要在备注中区分 `真题`、`解析`、`答案`。
3. 公共题库即使包含某院校真题，也先按公共资料处理，除非该文件明确作为目标院校历年真题包提供。
4. 已有一本通样例按院校和科目归档；它是风格学习材料，不是教材正文来源。
5. 编制要求类 PDF、抽取文本、学习笔记统一放 `编制规范/一本通编制要求/`，并同步到项目 skill 或 docs 中作为长期规则。
